1. 快速上手

五分钟从一张空白页面做出第一个 3D 打印零件，无需账号，无需安装。

PrintCAD 是一款直接在浏览器里运行的 3D 打印设计程序。你用简单的形状搭出零件，在它上面挖孔，把边缘变圆，然后交给切片软件。无需安装，也无需注册。你做的设计只保存在你自己的电脑上。

创建设计

打开 [the public site](the public site/)。在起始页点击 “新建 3D 设计”。编辑器会带着一个空的工作平面打开，所有东西都在这个网格上成形。

如果你已经有文件想接着做，用 “打开设计或导入几何体”。它支持 PrintCAD 设计（.lyl），也支持 STL、OBJ、3MF、STEP 或 SVG 文件。

你所有的设计随后都会出现在起始页上，并带有预览图。它们保存在浏览器的存储空间里，每次更改后自动保存，所以没有保存按钮。PrintCAD 不对保存在浏览器里的设计承担责任。 浏览器可能出故障，浏览器更新也可能带来问题，所以要不时用起始页上的 “全部备份” 备份你的设计，或者把它们保存为文件。备份可以通过 “恢复备份” 恢复。如何把设计打包成文件并转交他人，见文件与保存。 如果想要一个提醒，请在设置（功能区中的齿轮）里打开“Ask before closing the tab”：之后在关闭或刷新带有已打开设计的标签页之前，浏览器会先询问。

编辑器一览

  • 上方是功能区。它按任务分类：“剪贴板”、“历史记录”、“形状”、“可见性”、“组合”、“修改”、“排列”、“管理” 和 “帮助”。把鼠标停在图标上就能看到名称。凡是看到小问号的地方，比如形状的设置里、形状库中或工具面板里，它都会直接带你到本指南对应的章节。
  • 中间是工作平面。你在这里放置形状、把它们拉成想要的形状，并看到结果。
  • 右侧显示所选形状的设置：颜色、尺寸、位置以及组成该形状的其他内容。输入数字比拖动更精确。
  • 左侧是相机控制，上方是视图立方体。它们带你在这个场景中移动，详见视图与工作平面。
  • 最上方可以在 “3D 编辑器” 与 “草图” 之间切换、重命名设计，以及选择语言和配色方案。

工作区周围的按钮

把鼠标停在按钮上就能看到名称。如果不确定某个按钮的作用，点击 “交互式帮助”（位于 “帮助” 区域，快捷键 Shift+F1），再点那个按钮。下面是被问得最多的几个。

粘贴

“粘贴”（Ctrl+V）会把用 “复制” 复制的内容加入设计。“复制” 则一步完成复制和粘贴。

删除

“删除”（Delete）移除所选形状。“撤销” 可以把它们找回来。

取消分组

“取消分组”（Ctrl+Shift+G）把所选分组重新拆成组成它的那些形状。

工作区设置

“工作区设置” 打开工作区的设置：单位、平台大小、打印机、网格、颜色、光照等。详见视图与工作平面。

主题

最上方的 “主题” 决定 PrintCAD 的外观：跟随系统、浅色、深色或石墨色。

重命名设计

“重命名设计”：最上方名称旁边的铅笔图标。输入新名称并按 Enter。

设计名称

设计的名称（“设计名称”）位于最上方。点击它，输入，按 Enter 即保留该名称。

显示选项

“可见性选项”，即眼睛图标旁的箭头，里面是你可显示或隐藏的内容：对象列表、你隐藏的所有东西、注释以及打印的悬垂。详见选择与排列。

隐藏所选

“隐藏选中项”（Ctrl+H）隐藏所选形状。它们仍留在设计和对象列表中；“可见性选项” 可以让它们重新显示。

搜索命令

“搜索命令（Ctrl+K）”：输入你要找的东西——一个工具、一个形状或一项设置——然后点击结果。

隐藏相机控制

“隐藏相机控制” 收起左侧的相机控制，给工作区腾出更多空间；“显示相机控制” 会把它们调回来。

吸附网格

属性面板底部的 “吸附网格” 是移动和调整尺寸时吸附的步距。它旁边的小开关 mm | in 用来切换单位。详见视图与工作平面。

单位：毫米或英寸

“吸附网格” 旁的开关 mm | in 会为本设计更改单位、平台网格和吸附步距。

页脚

在窗口底部：“支持项目” 通往可以支持本项目的页面；“用户指南” 打开本指南；“讨论区” 通往提问、提想法和报告错误的地方（GitHub 上的讨论区，德语用户则为 drucktipps3d 论坛）；“问题报告” 生成一个用于错误报告的 ZIP 文件；“在 GitHub 上了解项目的更多信息” 通往 GitHub 上的项目，版本号则打开发行说明。法律声明和隐私政策的链接属于你所使用的那份 PrintCAD 的运营者。

你的第一个零件

举个例子，我们做一个带孔的立方体。

  1. 点击功能区中的 “添加形状”，选择 “长方体”。这个形状现在挂在鼠标指针上。在工作平面上点一下即可放下。
  2. 在右侧设置尺寸，比如长 40 mm、宽 40 mm、高 20 mm。
  3. 用同样的方式在中间放一个 “圆柱体”，直径 14 mm、高 30 mm。它应该比立方体高，这样才能贯穿整个立方体。
  4. 选中圆柱体，点击右侧的 “孔”。它会变为半透明：这个实体变成了一个从材料中去除东西的工具。
  5. 同时选中两个形状，点击 “分组”。立方体现在有了一个孔。

孔、槽和凹坑就是这样做的。实体与孔一章有详细说明。

上次访问之后的新内容

更新之后再次打开 PrintCAD 时，起始页上的一张卡片会列出你上次离开之后新增的内容：从那时起的每个版本，最新的在最上面。隔了很久没来，就在卡片里向下滚动。在它们下面，“显示更早的版本” 会把上次访问之前的版本也加进来。用 “知道了” 关掉它，它就会一直消失到下一次更新。起始页页脚的 “有哪些新变化？” 随时可以再次显示最新的新增内容。浏览器会记住你上次看到的版本，关于你的任何信息都不会离开它。

在你自己电脑或服务器上的 PrintCAD 副本中，有可用更新时会出现一个按钮 “预览：本次更新带来了什么？”，可以在安装前列出这次更新带来的内容。只有你按下按钮时，列表才会从 GitHub 获取。

从设计到打印

零件做好后，点击 “导出”，选择 STL 或 3MF 并下载文件。在你的切片软件中打开它，例如 Bambu Studio、PrusaSlicer、OrcaSlicer 或 Cura。如果在设置中选好了打印机，你在建模时就能看出零件是否能放进打印床。详见打印。

提示： 如果你来自 Tinkercad，会很快上手：平台、形状、实体与孔、分组、对齐和镜像的用法几乎一样。新东西主要是倒角与圆角、抽壳、螺纹和草图。 你自己的 Tinkercad 设计也可以带过来，见 文件、保存与分享。

2. 视图与工作平面

在场景中移动、正对着观察，以及把新形状放到任意你喜欢的表面上。

移动视图

使用鼠标：

操作效果
按住右键拖动旋转视图
单击右键在实体上打开常用命令菜单：复制、设为孔或实体、分组、隐藏、锁定、删除等；在空白处为“粘贴”和“全选”
按住中键拖动平移视图
滚轮放大和缩小
按住 Ctrl / Cmd 并用左键拖动也可平移视图（在 MacBook 触控板上：按住 Cmd，按下并拖动）
双击工作平面上的空白处或平台旁边平移视图，使该处位于中央；之后视图绕该处旋转

滚轮缩放的速度在设置的 “外观” 下用 “缩放速度” 设定：滑块范围 1 到 14，初始为 5。它只作用于滚轮和触控板：按钮以及 + 和 − 键始终按同样的小步距缩放。鼠标滚轮的一格在任何浏览器里缩放幅度都相同，触控板则按你滑过的距离缩放。

平板或手机上，两根手指缩放（张开和捏合）并平移视图（并拢滑动）。一根手指在空白处会转动视图，在那里轻点会清除选择；落在形状或控制柄上时，则像鼠标左键那样操作设计。要让从形状上开始的手指也能转动视图，请打开相机栏中的 “用单指旋转视图”。这个开关只在带触摸屏的设备上显示。

带笔的绘图板用起来像鼠标：笔尖是左键，笔杆上的按键是右键，用于转动视图和打开菜单。绘图板的热键可以在其驱动中设为 PrintCAD 的键盘快捷键。

在平板上，尽量使用触控笔。 它的笔尖比指尖细得多，也不会挡住你要对准的地方，因此草图中的小点、细线和控制柄、测量点与边都能精确点中，长时间工作也更省力。PrintCAD 已经让手指比鼠标指针更容易够到点、线、控制柄和边，但触控笔仍然是更精确的方式。这适用于绘图板能识别为笔的笔（S Pen、Apple Pencil 等）。普通橡胶笔尖的触控笔在屏幕上等同于手指，并不会更细。

平板没有鼠标右键：把一根手指在形状或空白处按住半秒，就会打开右键所打开的菜单，空白处还有全选。同一菜单里的多选在平板上代替 Shift：之后每次点按实体都会把它加入或移出选择，直到你点按空白处或按 Esc；手指落在空白处仍然会转动视图。选中形状周围的控制柄，手指从旁边一点的位置也能抓住。

视图立方体

左上角的立方体显示你正看向哪里。点击它的某一面，就会跳到从上、下、前、后、左或右看的正视图。点击立方体的角，会从那个角斜着看向模型；点击边附近，则从那条边看过去，位于两个面之间；指针停在上面时该处会亮起。数字键 1 到 6 也能给出正视图。同时按住 Shift，视图还会缩放到选中项，就像 Shift+F 那样。

拖动立方体可以转动视图，和按住右键拖动一样。没有选中任何东西时，方向键也会转动视图：每按一次 15°，配合 Shift 为 90°。它们按所指的方向转动模型——→ 把模型的正面转向右，↑ 把它的正面向上仰。按住 Ctrl 时，方向键改为让视图在屏幕上平移：每按一次移动画面的十分之一，同时按 Shift 则为一半。模型按所指的方向移动。如果选中了东西，方向键会移动它；先点击空白处再转动视图。在触摸屏上，用一根手指即可，无需打开 “用单指旋转视图”。

相机栏

左边缘是一条窄栏。从上往下：

  • “复位” 把整个场景重新装回画面。快捷键是 Home；没有选中任何东西时，F 也可以。
  • “将视图居中到选中项” 缩放到选中项（F 或 Shift+F）。
  • “放大” 和 “缩小” 按步缩放，+ 和 − 键也是如此。
  • “正交视图” 切换到平面视图，平行边保持平行。对于测量和对齐边，这通常比透视视图更舒服。O 来回切换，再点一次也会返回。
  • “隐藏工作平面”（网格上方的眼睛）连同网格一起隐藏平台，让你可以从下方查看设计的底面。改变的只是视图：新形状仍然落在工作平面上。再点一次会重新显示。
  • “放置工作平面”、卷尺和直角尺是各自的工具，下文以及测量与注释中会介绍。

栏最顶部的小箭头会在它挡路时把它收起。

设计会按你离开时的样子打开：视图的角度、缩放和位置会随设计保存在这个浏览器中，所以你可以从停下的地方继续，即使回过起始页或关闭过页面也一样。保存的文件（.lyl）会带上视图，因此在别处打开时也是这个视角。视图不属于撤销历史。

每个设计中还可以保存四个自己的视图。Shift+7、Shift+8、Shift+9 或 Shift+0 把当前视图原样保存到该键下——包括角度、位置、缩放以及平面或透视——只按该键（7、8、9 或 0）即可恢复。底部会有消息确认保存；在同一键下再次保存会替换该视图。和上面的视图一样，保存的视图会随设计留在这个浏览器中，并随保存的文件（.lyl）一起带走，它们也不属于撤销历史。

查看内部：剖视图

“剖视图”，栏中最后一个按钮（切割工具），沿一个平面把视图切开，以便检查壁、空腔以及互相嵌套的零件。不会真的切掉任何东西：设计、它的文件和所有导出都保持完整。平面穿过实体的地方，切面会以该实体稍暗的颜色填充，内部的孔则保持空白，这样就能区分实心与空心；平面停止移动片刻后，填充面才会出现。

  • 选择平面横跨的轴：X（宽度）、Y（深度）或 Z（高度），与位置字段中的相同。平面从设计的中间开始。
  • “坐标基准” 设定这些轴跟随什么。“设计” 采用设计的坐标轴。“工作平面” 采用工作平面的坐标轴：此时 Z 平行于它切割，X 和 Y 与它垂直，位置从它的原点算起。工作平面位于斜面时，你就平行于该面切割，移动工作平面时切口也会跟着移动。“视图” 把平面转向屏幕：它去掉前方遮挡的部分，滑块则沿视线把平面推入设计更深处，例如为了够到被埋住的零件并点击它。转动视图后，再点一次，切口就会跟随新视图。
  • “粗调” 让平面横跨整个设计移动，“微调” 让它在当前位置两侧小幅移动，以十分之一毫米为单位。也可以直接输入位置。
  • 坐标轴旁的按钮显示切口的另一侧，“居中” 把平面放回中间，“显示剖切平面” 隐藏蓝色平面。
  • 你可以点击并选中切口露出的内容，包括内壁。
  • “在此处放置工作平面” 把工作平面放到切口上。它位于剖面上，朝向保留下来的实体外侧，就像切割留下的面。如果你随后切换到草图，草图会正好从那里开始，淡淡的轮廓显示切口，你可以沿着它绘制并吸附。例如，这就是给用剖视图打开的空腔配一个盖子的画法。坐标轴旁的按钮选择保留哪一侧，也就决定了工作平面朝哪个方向。像平常一样，可以把工作平面放回底板。
  • “测量” 直接在切口上测量：轮廓以蓝色显示，在它上面点击两次即可得到距离，以及沿平面两个轴的分量。两个点都会吸附到轮廓上，优先吸附角点。当第二次点击落在对侧壁上任意位置时，它会与第一个点垂直对齐——因此不用精确瞄准，就能读出壁厚、间隙和公差。第三次点击开始下一次测量，Esc 结束测量。移动平面会清除测量。在圆形轮廓上，例如穿过圆柱或孔的切口，小十字会标出圆心，圆心也会吸附。点击圆上一点，再靠近它正对面的点：第二次点击会正好落在圆心另一侧，读数显示 Ø，即直径。从圆心到圆上一点则得到 R，即半径。
  • “剖切导出为 SVG” 把切割平面上的轮廓按 1:1 保存为 SVG，供激光切割机、绘图仪、模板或垫片使用。X 切口从右侧看，Y 切口从前面看，Z 切口从上方看。与导出时一样，只有可见实体才会写入，孔已经扣除，同色的实体会合并成一个轮廓。每种颜色保持为独立的无填充路径，这样激光软件会把它们当作不同图层分开。

面板附着在它的按钮上。如果它挡住了东西，可以抓住标题栏把它拖到工作平面上的任意位置；下次也会在那里打开。双击标题栏或把它拖回按钮处即可复原。

X 和 Esc 会关闭面板；如果正在测量，Esc 会先结束测量。切口会一直保留，直到你用 “剖切已启用” 将其关闭，或回到设计总览。开启时，它的按钮保持高亮。放在被切掉那一侧的任何东西，只有关闭切口后才会显示。平板没有 Esc，所以那里的面板多两个按钮：“返回” 在测量进行时结束测量，否则关闭面板；“关闭” 一步关闭面板。电脑上不显示这两个按钮。

工作平面

新形状会与工作平面对齐。起初它是带网格的底板。但你可以把它放到任何表面上，以便在侧壁或斜面上放置东西。

  1. 按 W 或点击 “放置工作平面”。
  2. 把鼠标移到实体的某个面上。该面会亮起。
  3. 点击一下就把工作平面放在那里。此后添加的所有东西都位于该面上。

如果改为点击空白的平台，工作平面会平放在你点击的位置，并吸附到网格上。新形状和完成的草图（包括旋转生成的）会出现在那里，而不是平台中央。工作平面这样平放在平台上时，平台只显示轮廓：同一平面里的两个网格会造成闪烁的花纹。

在面上时，工作平面的原点否则会吸附到网格。点击靠近面角的位置，它就正好落在那个角上。靠近边时它落在边上，网格也与边对齐；这就是有意选择网格角度的方法。没有角或边时，平放的面上的网格与实体平行，所以在一个转过的长方体上，网格也会跟着转。

点击平台旁边或按 Esc 会把工作平面送回底板。更快的是 “工作平面回到底板”：工作平面位于面上时，带向下箭头的按钮会出现在相机栏里眼睛的下方。Shift+W 直接把它放到当前选中的面上。Alt+W 随时把它放回底板，无论是否选中了东西。如果点击时按住 Shift，平面会朝向另一边。

工作平面位于面上时，“放置工作平面” 旁边会出现一只眼睛。它会隐藏工作平面而不取消它，方便清楚地查看设计：新形状仍然落在那个面上，旋转也仍然绕它进行。点击眼睛会重新显示，设定新的工作平面也会。

网格与吸附

网格显示平台的大小。右下角是吸附步距：移动和缩放按这个步距吸附，例如 1 mm。精细作业时调小，粗略摆放时调大。功能区中的 “吸附到网格” 会在之后把选中的形状移到最近的网格交叉点。移动时，形状还会吸附到其他形状，见选择与排列。

提示： 精确拼合零件时，不要一边转着视图。用数字键转到俯视或正视，再按 O 切换到平面显示。这样一眼就能看出两条边是否真的齐平。

设置窗口

功能区中的齿轮（“工作区设置”）打开设置。左侧有五个区域：“外观”、“测量”、“工作平面”、“形状默认值” 和 “历史记录”。改动立即生效。底部的 “设为默认” 把当前设置保存为默认值，让新设计从这些设置开始；右上角的 “关闭设置” 关闭窗口。本节逐项介绍这些设置。

外观：主题、工具栏与视图立方体

“主题” 设定整个程序的配色：“跟随系统” 跟随电脑，其余为 “浅色”、“深色” 和 “石墨”。也可以在编辑器右上角更改。

“工具栏大小” 让顶部功能区的按钮、其形状菜单、左侧相机控制和右侧属性面板变小或变大：“小”、“中”（一直以来的样子）或 “大”。小尺寸在笔记本电脑上给工作平面留出更多空间；大尺寸在大屏幕上或用手点击时更容易命中。使用大按钮时，如果窗口太窄，功能区的各组会排到第二行。尺寸保存在这个浏览器中，对所有设计生效。

“视图立方体位置” 把视图立方体放到工作平面的另一个角：“左上”（一直以来的位置）、“右上”、“左下” 或 “右下”。除了左上角，相机控制都会上移到立方体让出的位置。在右下角时，立方体正好位于 “吸附网格” 控件上方。右侧打开形状属性时，右侧的立方体会让到属性面板左边。这个角保存在浏览器中，对所有设计生效。窗口很窄时（例如手机上），该设置会隐藏，立方体留在左上角。

外观：快速模式

“快速模式” 用于较慢的电脑。它会关闭阴影、所有实体的边线和相机的惯性，并且只按屏幕分辨率绘制视图。你自己的设置会保留下来供以后使用，开启期间被覆盖的开关会显示 “在快速模式下关闭”。更多关于慢电脑的提速方法见下文“PrintCAD 卡顿的时候”。

外观：工作区与草图的颜色

工作区的颜色在 “外观” 下设置：浅色主题的 “窗口背景（浅色主题）” 和 “网格下方的工作平面（浅色主题）”（深色主题保留自己的颜色），网格颜色则在 “工作平面” 下。每种颜色都是一个显示该颜色的按钮。点击后会打开一个小窗口，其中有色域、一行预设颜色、十六进制值输入框，以及一个把颜色恢复为 PrintCAD 初始值的箭头。按 Enter 应用输入的十六进制值，点击窗口外也会应用。

草图视图有自己的颜色：“草图：窗口背景（浅色主题）” 用于纸张周围的窗口，“草图：网格下方区域（浅色主题）” 用于网格下方的纸张，“草图：网格颜色（浅色主题）” 用于网格，均针对浅色主题。“草图与工作区一致” 一键采用工作区的三种颜色。

“经典外观” 把工作区布置成 Tinkercad 的样子：白色地面、淡蓝色的毫米网格（每厘米一条较深的线）、黑色边线、来自上方的光以及柔和阴影。之后每个值仍可单独更改。这些初始值都是 PrintCAD 一直以来的样子，哪种合适取决于你的显示器。

外观：坐标轴箭头与边线

“坐标轴箭头”（默认开启）在平台后左角画出三个箭头：X 为红色指向右，Y 为绿色指向后，Z 为蓝色指向上，与位置字段的计数方式一致。这就是 Tinkercad、CAD 程序和切片软件也采用的右手定则。工作平面位于面上时，它们会跟随该面。如果它们挡路，可以在这里关闭。

“所有实体显示边线” 为每个实体绘制轮廓，颜色由 “边线颜色” 决定（初始为黑色，与 Tinkercad 相同）：当深色彼此混在一起时会很有帮助。默认关闭，非常大的导入网格会被略过。

“更清晰地显示孔” 把孔画成更深的灰色、更不透明，并在周围加一条深色线。当孔在透明实体中难以找到时很有帮助。与边线不同，它在快速模式下仍然开启。

外观：光照与阴影

“显示阴影” 打开或关闭投射阴影。两个滑块设定实体的受光方式。“阴影强度” 决定投射阴影的深浅，“着色对比度” 把光从均匀的环境光转向主光：偏向“强烈”时，背光面更暗、阴影更明显；偏向“柔和”时，整体更平。对比度拉到最高会非常强，背光面和阴影会变得很暗。“阴影柔和度” 让阴影边缘变柔和而不是锐利。“光照方向” 让主光绕平台旋转（0° 从前方，90° 从右方），“光照高度” 把它抬高；90° 时它像 Tinkercad 那样位于平台正上方，阴影正好落在实体下方。“重置光照与阴影” 恢复全部设置。

外观：工作平面上的测量

“显示移动尺寸” 显示拖动时移动了多少，“显示到原点的距离” 显示选中项到平台原点的距离，选中多个实体时也会显示。开启 “尺寸始终可见” 后，这些测量会一直可见，而不只在拖动时显示。选中转过的实体时，其角度会显示在工作平面上它的下方；“显示旋转后实体的角度” 可关闭这一显示。更多内容见测量与注释。

外观：选择与移动

“先选中再移动”：实体必须先被选中，下一次拖动才会移动它。当小孩或匆忙的手会碰到实体时，以及在触摸屏上，这很有用。

“由框选方向决定”：向右拖出的选框只选中完全位于其中的对象，向左拖出的选框则选中它碰到的所有对象（以虚线绘制），与 SketchUp 相同。

“双击打开草图” 决定双击拉伸出的草图是否会重新打开草图，与 Tinkercad 相同；“双击打开分组或捆绑” 决定双击分组或捆绑是否会打开它进行编辑。“双击工作平面，视图以该处为中心” 决定双击工作平面上的空白处是否会把视图移到该处。

“移动时吸附到其他形状” 让形状的边和中心在拖动时吸附到其他形状；右下角的网格菜单有同样的开关。“添加新形状时启用巡航” 让新形状挂在鼠标指针上，并落在其下方的面上，类似 Tinkercad 的 Cruise；关闭时，新形状出现在平台中央。更多内容见选择与排列。

外观：视图

“编辑器以透视视图启动”：编辑器随即以透视视图打开，而不是平面视图。

“缩放速度” 是一个从慢到快的滑块：滚轮和触控板缩放的速度；缩放按钮和按键仍保持自己的小步距。“相机继续转动”：松开鼠标后，视图会继续转一小会儿并平缓减速。关闭后它会立刻停住，与 Tinkercad 和 Fusion 360 相同。

“标记 {angle}° 起的悬垂” 是在可见性菜单中打开“显示悬垂”时，一个面被视为悬垂的起始角度：这些面会以红白斜线标示。30° 偏保守，70° 依赖良好的打印冷却；45° 是常用的起点。

“剪切导入网格上限为” 限制导入网格在切割、合并或相交时允许的三角形数量，因为这些计算在你的浏览器中完成。超过上限的网格不会被处理；请先简化网格，或者如果电脑承受得住，就提高上限。上限过高可能让编辑器卡住几秒。

测量：单位、比例与吸附步距

在 “测量” 下，你可以设置 “单位”，即测量显示所用的单位（“比例”：公制为毫米、厘米或米，英制为英寸或英尺）、数字显示的小数位数（“精度”）、移动和调整尺寸时吸附的 “吸附网格”，以及 “自定义吸附网格” 下自己的吸附步距。

在设置的 “测量” 下设置 “单位”。使用 “英制” 时，PrintCAD 会把所有测量显示为英寸——形状上、属性面板中、卷尺和标尺上都是如此。吸附网格随后提供从 1/64 到 1 英寸的步距，平台的网格也按英寸绘制（1/8 到 1 英寸，默认 1/4 英寸），每个整英寸处有一条更粗的线。在 “英寸显示方式” 下，你可以选择英寸显示为像 Tinkercad 那样的分数（1 5/8，四舍五入到 1/64 英寸），还是显示为小数（1.625），小数位数由 “精度” 设定。两种写法都能输入，包括“1 5/8”。在毫米和英寸之间快速切换的方法是属性窗口底部 “吸附网格” 旁的小开关 mm | in：它会像设置一样改变单位、平台的网格和吸附步距，且只作用于当前设计。

在同一处的 “自定义吸附网格” 下，可以添加自己的吸附步距：一个名称和一个以毫米为单位的大小，例如用“Pin pitch 2.54 mm”表示 DIP 芯片、排针和洞洞板孔的间距，或用 19.05 mm 的“MX Key Unit”表示键盘按键的间距。吸附步距菜单随后会提供该尺寸的整份、一半和四分之一（1 ×、½ × 和 ¼ ×），因此形状可以按一个间距、半个间距或四分之一个间距移动。如果你只想要该尺寸本身，取消勾选旁边的 “同时提供半格和四分之一格”；菜单就只剩这一个步距。自定义步距随设计保存，也会随 “设为默认” 一起保存。

工作平面：平台与打印机

“打印机” 把工作平面调整为打印机的打印床大小，并标出超出边界的实体，见打印。“平台标签” 在平台上写设计的名称，选择打印机后还会写上打印机名称和成型体积。

“工作平面尺寸” 给平台设定自定义尺寸，用 “宽度” 和 “长度”，单位为毫米或你选择的单位。网格始终穿过原点，所以无论平台多大，较粗的线都位于坐标轴上。

工作平面：网格

“显示网格” 显示或隐藏平台上的网格。“网格块大小” 设定网格线的间距，“加深网格线间隔” 设定较深的线每隔 5 个还是 10 个网格步距出现；“加深线颜色” 给这条线单独的颜色，中心十字和平台边框也会采用；“网格颜色” 是普通网格线的颜色。

放大时网格的每条线都会变宽，与 Tinkercad 相同，缩小时也保持可见。如果觉得太粗，关闭 “缩放时网格线变粗”，线条在任何缩放下都保持一个像素宽，与草图中一样。

如果网格消失了，比如因为颜色被设成了与平台相同，“工作平面” 区域末尾的 “重置网格” 会把它的可见性、颜色、间距和线宽恢复为标准值，这里的设置以及用 “设为默认” 保存的默认值都会恢复。

形状默认值

在 “形状默认值” 下，用 “形状” 选择一种形状，并设定添加它时的初始状态：宽度、长度和高度。“使用应用默认值” 把该形状恢复为程序的初始值。有各自设置的形状会在 “形状详情” 下显示这些设置。这些值只作用于新形状，不作用于已经在平台上的形状。“自定义尺寸限制” 为控制柄和属性可以把该形状做到多大设定你自己的上限；留空则保留通常的限制。

保存的历史记录

在 “历史记录” 下，滑块 “已保存的历史记录” 设定保存或重新打开设计后，有多少已完成的操作仍可用于撤销。每个设计默认保留 100 个操作。降低上限会永久丢弃该设计较早的撤销步骤。

PrintCAD 卡顿的时候

PrintCAD 在你的浏览器中计算并绘制一切。因此在较旧的电脑上、显卡较弱时，或在多块大屏幕上，视图可能会显得迟缓。以下方法有帮助：

  • “快速模式”：“外观” 下的快速模式会立即关闭所有让视图开销很大的效果：阴影、所有实体的边线和相机的惯性。它还只按屏幕自身分辨率绘制视图，在高分辨率屏幕上像素最多减少到四分之一。你自己的设置会保留，一关闭快速模式就重新生效。
  • 相机会继续转： 转动后松开鼠标时，视图会继续转一小会儿并平缓减速。这是有意为之，不是卡顿。如果你习惯了 Tinkercad 或 Fusion 360，可在 “外观” 下关闭 “相机继续转动”，视图会立刻停住。
  • 单独关闭各项： 不用快速模式，也可以只关闭 “显示阴影” 或 “所有实体显示边线”。
  • 使用显卡： 在 Chrome 中打开 chrome://gpu（Edge 中为 edge://gpu）。在“WebGL”旁边应显示“Hardware accelerated”。如果显示“Software only”，说明浏览器设置中的硬件加速已关闭。在 Windows 上，还可以在“设置”→“系统”→“显示”→“图形”中为浏览器选择“高性能”，让它使用真正的显卡，而不是处理器中较弱的显卡。
  • 简化大型导入网格： 包含几十万个三角形的模型会拖慢任何视图。精简方法见文件一章中的“简化导入的网格”。
  • 关闭其他标签页： 每个打开的 PrintCAD 标签页和其他 3D 页面都共用同一块显卡。

3. 放置与调整形状

形状库、用数字和手柄设置尺寸、颜色、旋转、锥度与扭曲。

PrintCAD 里的每个零件都从一个形状开始。用这些形状，你可以搭建其他一切：形状彼此互补、相互挖空，或合并成一个新形状。

添加形状

单击功能区中的 “添加形状”。形状库随即打开。

每选一个形状，形状库都会关闭。拖动它的标题栏可以移动它，这样你就能把它放到不遮挡目标位置的地方，例如属性面板上方；双击标题栏可让它回到按钮下方，你上次留下的位置会保存在浏览器中。标题栏中的图钉可让形状库保持打开，方便你连续放置多个形状。拖动边缘和角可以调整它的大小，最大可到屏幕允许的宽高；尺寸也会保存在浏览器中，双击边缘可恢复。拉窄后，形状库会隐藏名称，只显示图片；指向某个形状时才出现名称。

选择一个形状。它会跟随鼠标指针，并在你单击的位置落下。把它移到某个实体上方，它会贴到指针下的面上，斜面也一样，就像 Tinkercad 的 Cruise；在空白平台上方，它会落在工作平面上。Esc 取消放置。等待单击的工具（例如卷尺、直角尺、便签、“放置工作平面”、“平放于面” 或边缘工具）在你选择形状时会被关闭，因此单击会放置形状。反过来，开启其中某个工具会把形状放下。如果你更希望形状直接出现在平台中央，可以在设置中关闭单击放置（“外观” 区域，“添加新形状时启用巡航” 开关）。

在一个面上,指针靠近面中心时形状会吸附到该面的中心,就像吸附到角或边一样;按住 Alt 可放在任意位置。如果从形状库把它拖到一个面上,它总是落在面的中心,按住 Alt 则落在松开的位置。

形状库提供：

  • 基本形状： “长方体”、“圆角长方体”、“圆柱体”、“胶囊”、“椭圆”、“多边形”（三到二十四条边）、“球体”、“圆锥”、“棱锥”（三到二十四条边，因此也有三棱锥）、“楔形”、“圆形屋顶”、“半球” 和 “圆环”。
  • 管： “管” 和 “弯管”，由最多十二段直管及之间的弯头组成，以及从一种轮廓过渡到另一种的 “放样”，比如从方形到圆形。
  • 装饰形状： “星形”、“心形” 和 “月牙”。
  • 文字： “文字”，也可沿圆弧排列。更多见文字。
  • 机械件： “螺纹”（螺杆、螺钉、螺母和螺纹孔）、“弹簧”、“Gridfinity” 收纳盒和底板、“齿轮”，以及用于握持的 “滚花”。更多见螺纹与机械件。
  • 用于结构件： 一体打印的 “铰链”、“燕尾”、用于水平孔的 “泪滴孔”、用于螺钉头的 “沉孔” 和 “锥形沉孔”，以及 “标尺”，它只是测量工具，永远不会出现在导出结果中。

有两种方式可以得到三角形：三边的 “多边形” 是等腰三角形，也就是 Tinkercad 的“Roof”；“楔形” 是直角三角形。两者都是真正的三棱柱。要挖出三角形孔，复制该形状，把副本缩小，标记为孔，然后用 “居中到工作平面” 或 “对齐” 对齐。两者都按形状的边界框工作，也就是包围它的最小方框，所以被切掉一半的正方形仍按完整正方形计算。命令搜索（Ctrl+K）在“triangle”或“roof”下也能找到这两种形状。

“胶囊” 可以一端比另一端窄，例如用于两个带轮之间的皮带护罩。在 “属性” 下设置 “小端（直径）”；大端与胶囊一样宽，两侧从一段圆弧直通另一段圆弧。“中心距” 是两段圆弧圆心之间的距离，也就是两个带轮的间距。改变小端时圆心距保持不变，胶囊会变长或变短。锥形胶囊同样是精确实体，可用于圆角和 STEP。

形状的设置

选中形状后，它的设置会立即出现在右侧。顶部是名称，旁边的铅笔（“重命名”）可输入新名称。Enter 保留，Esc 取消，名称为空则恢复形状的默认名称。再往右，挂锁可锁定形状、防止误移动，眼睛图标可隐藏它。最左侧的箭头可把设置折叠到只剩标题栏。下方的卡片可通过单击标题展开和收起（“属性”、“位置”、“旋转”、“锥度”、“扭曲与倾斜” 以及特殊形状的卡片）；PrintCAD 会记住你保持展开的卡片，供下一个形状和下次访问使用。

设置停靠在右侧边缘。如果它挡住了你想看的内容，拖动标题栏即可让它浮动到你放下的位置；下一个形状也会保持在那里。把它拖回右上角，或双击标题栏，它就会重新停靠。浮动或折叠时，吸附步距会从设置底部移到工作平面右下角。

  • “实体” 或 “孔”： 实体保留材料，孔则去除材料。单击 “实体” 会打开颜色；你在那里调出的自定义颜色之后会留在 “最近使用” 下，最多最近八个。更多见实体与孔。“已保留” 一行中的图钉可永久保留你选的颜色：它独占一行，更新的颜色永远不会把它挤掉，再次单击同一图钉即可取消保留；此浏览器最多保留 21 种颜色。
  • “透明”： 让实体变得透明，例如看清它后面的形状。
  • “多色”： 仅用于分组；Shift+M 可切换。开启后，分组中的每个部件都显示自己的颜色，被孔挖成单一实体的分组也一样（孔留下的壁采用被挖实体的颜色）。为分组选择颜色会关闭它，并给整个分组上色。捆绑始终保持各部件的颜色。导出 3MF 时，每个部件都保留自己的颜色，切片软件可据此把部件映射到耗材；OBJ 把颜色记录在顶点上，所以两种颜色的交界在那里会略显粗糙。
  • “属性”： 尺寸以及属于这个形状的一切。圆柱体有直径、高度和边数。圆管或圆环有 “外径”、“内径”（用于已知轴径的衬套）和壁厚：任意两个值可得出第三个，输入顺序不限。设置外径时内孔保持不变，壁厚随之改变；设置内径时外径保持不变，壁厚随之改变；内孔比管更宽时，外径会按壁厚增大。管的长度就是它的高度。被拉过一条边的非圆管，会用“长度”和“宽度”两个值代替原来的外径；在那里改变宽度时壁厚保持不变。齿轮有齿数，弹簧有圈数。离开默认值的数值名称旁会出现一个小箭头：单击只恢复这个数值，无论你之后还做了什么，这一点与撤销不同。双击滑块也一样，这里以及工作区设置中的滑块都是如此。用鼠标拖动时，长度滑块会吸附到吸附步距，因此高度会得到整毫米值（网格关闭时以及短滑块上不会）；输入的值和滑块上的方向键仍保持精确。底部的 “保存为默认值” 会把当前值设为这类形状的起始值（与设置中的 “形状默认值” 相同），“重置默认值” 则恢复应用的默认值。 开启“编组时孔作为空洞切除”后，管子编组时其孔算作空洞：它也会切开与管子编组在一起的物体的壁，于是T形相接的两根管子彼此贯通。
  • “设为椭圆”： 仅用于圆柱体。圆柱体始终是圆的：它只有一个直径，每个手柄都会同时改变两侧。要得到椭圆，单击此项，它就会变成 “椭圆”——同一个实体，之后你可以分别设置它的长度和宽度。带有倒角、圆角或壁的圆柱体，以及旋转过或分组过的圆柱体，不能这样转换；这些情况请从一开始就使用 “椭圆”。
  • “锥度”： 顶部和底部尺寸不同，例如用于斜面或漏斗。
  • “扭曲与倾斜”： 让顶部相对底部扭转或横向偏移。这样可以做出扭转的柱子和倾斜的塔。

锥度和扭曲几乎适用于所有形状。只有齿轮、螺纹、弹簧、Gridfinity、铰链、棱锥、弯管、泪滴孔、用于螺钉头的沉孔与锥形沉孔以及标尺不支持：它们有自己固定的尺寸，或者像棱锥那样已经有自己的顶部。

“保存为默认值” 会把你在该形状上的改动保存为同类型每个新形状的起点：尺寸、形状的设置和颜色。把一个圆柱体涂成绿色，按下按钮，之后添加的每个圆柱体都是绿色；其他类型保持各自的颜色。“重置默认值” 把该类型恢复为应用的初始状态。有各自默认值的类型会在设置的 “形状默认值” 下标出。从起始页新建的设计也会以这些默认值开始；数值保存在此浏览器中。

锥形或倾斜的长方体、圆柱体、椭圆、多边形、管或圆环保持精确形状；胶囊、星形、心形、月牙、燕尾、顶部和底部边缘未倒圆的圆角长方体，以及直的或圆的滚花（其倒角端也随之收窄）同样如此：倒角和圆角可以像在普通形状上一样作用于它，STEP 导出也会写出它。扭曲的形状同样如此：它的截面随高度精确旋转，侧面从底部到顶部均匀盘旋。

输入比拖动更精确。所有数字字段都接受毫米，也接受百分比：在 40 mm 的宽度中输入“50 %”，得到 20 mm。它们也会计算：“15*3”“120-2*4”或“(40+2)/2”分别得到 45、112 和 21；可以用 x 代替 *。字段会记住算式，属性面板和选中实体周围尺寸框中的字段都是如此：之后再次单击它，只要数值仍然吻合，那里显示的就是算式而不是数字，你可以就地修改，把“(140+2)/2”改成“(40+6)/2”。用手柄拖动实体或缩放它之后，算式不再吻合，字段就只显示数字。 在点击过的数字框中，鼠标滚轮和 ↑、↓ 键会按一步改变数值，按住 Shift 步长更大，按住 Alt 步长更细。在尺寸或位置字段中，Shift 改为按网格步长变化；网格关闭时按十个步长。

选择颜色

单击实体属性中的 “实体” 会打开颜色卡片，标题为 “形状颜色”。顶部显示实体当前颜色的十六进制值。下面是调色板中的现成颜色；单击一种即可给实体上色并关闭卡片。

“自定义” 会打开浏览器的颜色选择器，用于自定义颜色。它提供什么取决于浏览器：在 Chrome 和 Edge 中，它有颜色字段、色相滑块、可从屏幕任意位置取色的吸管，以及以 HEX、RGB 或 HSL 表示的值，可用旁边的箭头切换。关闭选择器或单击其外部时，颜色才会生效。

你在那里调出的自定义颜色之后会留在 “最近使用” 下，最多最近八个。“已保留” 一行中的图钉可永久保留你选的颜色：它独占一行，更新的颜色永远不会把它挤掉，再次单击同一图钉即可取消保留；此浏览器最多保留 21 种颜色。图钉用于自定义颜色，调色板中的颜色始终都在。选中多种颜色时，或选中孔时，没有单一颜色可保留。

设置中工作区颜色有自己更简单的选择器，包含颜色字段、一排现成颜色和十六进制值字段；见设置。

圆有多圆？边数

圆柱体、圆锥、管、椭圆或内孔等圆形形状，其属性中有 “边数随尺寸变化” 开关和 “边数” 滑块。“圆环” 有两个滑块：沿环的 “环向边数” 和沿管身的 “管向步数”。它们在那里也会跟随尺寸，直到你手动固定，因此大型圆环不会显出棱面。原因在于：对于视图以及 STL、3MF 和 OBJ，PrintCAD 把圆画成由许多小边组成的多边形。边越多越平滑，占用的三角形也越多。

“管粗”设定从上方看时管有多粗。高度只会压扁或拉伸管，所以扁平的圆环会保留中间的孔；当管粗达到外径的一半时孔会闭合。拖动手柄时，管会随形状一起缩放。只有管粗等于圆环高度的圆环，才会在倒角、圆角和 STEP 中保持为精确实体。

边数在哪些地方重要

  • 导出给切片软件时（STL、3MF、OBJ）。边数少的圆柱体到了那里就是多边形。
  • 合并实体和孔时。 由边数少的孔挖出的内孔，在成品中会带有棱角。螺钉孔也包括在内。
  • 在视图中。 许多非常精细的形状会拖慢编辑器。

边数在哪些地方不重要

  • 导出 STEP 时。 它写出的是圆形形状，而不是多边形。
  • 使用倒角和圆角时（“倒角”、“圆角”），只要形状保持圆形。未设置边数、边数不少于该形状的默认值，或者多边形与圆的偏差最多 0.05 mm 时，就是这种情况。默认值是：圆柱体、椭圆、管和圆锥为 96 条边，“圆形屋顶” 为 64，“球体” 为 24 段，“半球” 为 32 段，“圆环” 为 96 条边和 24 段，圆形 “弯管” 的 “质量” 为 32。
  • 螺纹、弹簧或斜齿轮。 边缘工具和 STEP 导出使用它的精确实体；它的 “质量” 只决定绘制得有多精细。

边数再次重要的情况

  • 在边数少的形状上使用倒角和圆角时。 如果把边数设得低于默认值，边缘工具会按形状绘制出来的样子处理：6 条边的圆柱体仍是六棱柱，圆角会沿它的六条边延伸。这样你就可以做出例如带圆角的螺母槽。对于圆形形状，请保持 “边数随尺寸变化” 开启。

如何使用

  • 保持 “边数随尺寸变化” 开启。 然后 PrintCAD 会根据直径选择边数，使多边形与真实圆的偏差最多 0.005 mm，远低于打印机能够分辨的程度。小形状至少有 24 条边，大形状则更多。
  • 减少边数：只有在你有意要多边形时才这样做（不过那种情况有 “多边形”），或者当编辑器因大量圆形形状而变慢时。
  • 增加边数：几乎不需要。只有在非常大的圆形零件上、在 STL 中能看到棱边时才需要。
  • 对于只用边缘工具处理或以 STEP 交付的零件， 边数无关紧要。

使用手柄

除了设置之外，形状本身也有手柄：

  • 角和边用于放大或缩小形状。把其中一个拖过对侧，形状会在该边的另一侧继续增大。顶部的箭头在底面下方做同样的事。拖动角时按住 Shift 可同时缩放宽度、深度和高度并保持比例；按住 Alt 则从中心缩放，而不是从对角缩放。没有键盘，或者不想按键时，可开启属性顶部的 “保持比例”：此后角始终保持比例，输入宽度、深度或高度之一，另外两个会按相同比例缩放。该设置会被记住。
  • 形状上方的黑色箭头抬高或降低形状；从一开始按住 Alt，会在松开处生成一个副本，方便叠放。顶面上的白色手柄改变高度。
  • 弧形箭头旋转它。
  • 形状旁的数值显示尺寸。单击其中一个会打开字段，可输入想要的数字。按 Enter 时，形状从该数字对面的边开始增大，与拖动时相同；按 Alt+Enter 时，它围绕自己的中心增大，因此与另一个形状对齐过的形状仍保持对齐。这适用于宽度和长度；高度始终从底面向上增大。右侧属性中的字段不用按键就保持中心。Tab 保留数字并打开下一个（宽度、深度、高度）；Shift+Tab 返回上一个。在已单击过的属性字段中，鼠标滚轮也会改变数值：一格一个单位，按住 Shift 为十倍，Ctrl 为十分之一，Alt 为百分之一。未单击过的字段把滚轮留给面板，由面板滚动。
  • 单击一个角（不拖动）会同时打开宽度和深度。输入第一个，按 Tab 切到第二个，按 Enter 应用两者。Esc 取消。

形状一旦按直角转过，例如用 “平放于面” 侧放，属性中的字段就会按每项尺寸当前的方向命名：“高度” 是向上的尺寸，“宽度” 沿 X 方向，“长度” 沿 Y 方向。因此输入躺倒形状的高度会改变垂标尺寸，它的底面仍留在平台上。以其他角度倾斜的形状会在字段中显示自己的尺寸，下方会有说明。

不用鼠标时，可以用键盘：方向键按一个吸附步距移动选中项（网格关闭时为 0.01 mm），按住 Shift 为五步，或者在设置的 “外观” 下把 “加深网格线间隔” 设为 “10 个网格步距” 时，为十步：直到下一条更深的线，与 Tinkercad 中一样。它们跟随视图：→ 移向屏幕右侧，↑ 远离你，即使转动过平台也是如此。把形状推出画面时，视图会跟着移动。Ctrl+↑ 和 Ctrl+↓ 升高和降低它。连续按方向键在历史记录中算作一步：只要下一次按键在 1.5 秒内跟上，撤销就会收回整串操作，而不是一次一次地收回。R 旋转 45°，Shift+R 旋转 22.5°。D 把选中项放到工作平面上。

手柄可把形状拉到和你的平台一样大，宽和深至少 220 mm。在属性中输入数字可以超过这个范围，而这样放大的形状再次抓取时不会缩回。在设置的 “形状默认值” 下，可用 “自定义尺寸限制” 为每种形状设置自己的上限。

吸附步距位于编辑器右下角，随时可以更改。

复制与重复

“复制”、“粘贴” 和 “复制副本” 位于功能区（“剪贴板”）。Ctrl+D 复制选中项。PrintCAD 会记住你上次如何移动或旋转副本，并在下次复制时再次应用。这样几下按键就能做出一排孔或一排台阶。规则排列还可以使用阵列，见选择与排列。

提示： 如果某个形状不肯接受你想要的尺寸，通常是新形状的限制所致。在设置的 “形状默认值” 下，你可以决定每种形状如何开始，以及最大能有多大。

自定义形状

需要反复使用的支架、手柄或底板，可以放进 “自定义形状”。它们位于形状库顶部、“基础形状” 上方，可用箭头收起。

  1. 选择一个或多个实体、孔、分组，也可以包含导入的模型。
  2. 打开形状库并单击 “保存选中项”。输入名称，用 “保存” 确认。
  3. 在任何设计中，单击图块即可插入该形状，与其他形状一样。你也可以把图块拖到工作平面上；它会在你松手的位置落下。随后形状会跟随指针，和其他形状一样：它跟着指针移动，经过其他实体的表面时也是如此，单击即可放下；Esc 把它收走。

多个实体会一起回来，保持它们彼此的相对位置，并且仍可逐个选择。固定到已保存实体上的便签会随之保存，并在插入时以收起状态回来，仍固定到插入的实体上；自由便签和参考点留在设计中。图块上的铅笔可重命名，垃圾桶会在询问后删除。已插入设计中的形状保持原样。

“自定义形状” 保存在此浏览器中，与设计分开，下次启动时仍在。起始页的 “全部备份” 会把它们和设计一起备份，打开备份即可恢复两者。如果只想把形状带到另一个浏览器，“备份自定义形状”（向下的箭头）会把它们保存为 ZIP 文件，“载入形状”（向上的箭头）会把它们带回来。“载入形状” 也接受单个 .lyl 设计；每个都会变成一个形状。已有的形状不会重复添加。

文件夹

许多自定义形状更适合分类到文件夹中。“新建文件夹”（带加号的文件夹，位于 “保存选中项” 旁）会要求输入名称，并在顶部创建文件夹；文件夹上的加号 “在其中新建文件夹” 会在其中创建子文件夹。文件夹最多三层：第三层的文件夹可以放形状，但不能再放文件夹。文件夹按名称顺序排列在不属于任何文件夹的形状上方，可用箭头展开和收起；文件夹上的数字统计其中及内部文件夹中的形状数量。保存时，在名称旁的列表中选择文件夹；“无文件夹” 会把形状留在顶部。

图块上带箭头的文件夹可把该形状移到另一个文件夹，或用 “无文件夹” 移回外面。文件夹上的铅笔可重命名，垃圾桶会在询问后删除它以及其中的文件夹和形状。文件夹本身不能移动：请在合适的位置新建一个，再把形状移过去。备份会保留文件夹，载入后形状会回到原来的位置。

服务器上的自定义形状

开启共享服务器存储后，该区域会显示两组：“服务器上” 和 “此浏览器中”。保存时你可以选择形状的去处；默认选择服务器。在那里，它存放在 Custom shapes 文件夹中，是一个独立的 .lyl 文件，带有图片，任何能访问服务器的设备上都可以使用；它的文件夹就是 Custom shapes 内的文件夹。两侧各有自己的文件夹，形状只会在所属一侧的文件夹之间移动。浏览器图块上的云图标会把这个形状放到服务器上；此后它就不再保存两份。

Custom shapes 文件夹也会显示在起始页上。在那里像设计一样打开形状，修改后它会像服务器上的任何设计一样自动保存；下次插入时使用的就是新版本。由于服务器存储没有登录功能，所有能访问服务器的人看到的都是相同的形状。

包裹到圆柱

想让图案、标志或文字贴到杯子、罐子或管子上？先把平铺在平台上，例如作为导入的 SVG 或文字，并按从上方看应有的样子摆好。然后在形状设置的 “包裹到圆柱” 下把它包裹到圆柱：

  1. 打开 “包裹到圆柱”，输入圆柱壁的 “直径”，例如杯子的外径。也可以精确到十分之一毫米，比如 63.5。
  2. 单击 “包裹”。原本从左到右延伸的内容现在绕着圆柱延伸，后边缘变成顶部，厚度从壁面向外突出。
  3. 选中包裹后的形状和圆柱，让两者在左右和前后方向都居中。包裹后形状的中间就是圆柱的轴线，因此它会正好贴在壁上。

如果要雕刻，请开启 “向内（雕刻）”：厚度此时会陷入壁内。把形状设为孔，居中，然后与圆柱分组。

已经包裹过的形状是包裹后物体的网格，不能再次包裹：撤销包裹，或者用另一个直径再次包裹原来的平面形状。

结果像导入的模型一样是网格。撤销会把形状重新摊平；要换直径，先撤销再重新包裹。包裹范围不能超过圆柱一圈；超过时 PrintCAD 会给出能够容纳的最小直径。

4. 选择与排列

选择形状、在对象列表中查找它们、对齐、镜像、旋转、平放在某个面上，以及按阵列复制。

选择

单击形状即可选中。按住 Shift 可以添加更多，也可以再次移除。按住 Shift 且选中两个或更多形状时，鼠标指针下方的小数字会显示数量。单击空白处会清除选择，Esc 也是如此。在空白工作平面上拖出选框，可选择它接触到的所有内容；按住 Shift 时，选框会添加未选中的内容并移除已选中的内容。如果你想从一簇形状中只挑出某一个，请在设置中开启 “由框选方向决定”（区域 “外观”）：此时向右拖出的选框只包含完全位于框内的形状，向左拖出的选框仍会选中接触到的所有内容，且选框线为虚线。拖动时按住 Alt 可为这一次拖动反转选框方向，例如从该方向不允许的一侧框选整个实体。Ctrl+A 选择所有可见实体。拖动实体或选框手柄时，只要鼠标按键仍未松开，Esc 就会取消：一切恢复原状，历史记录中也不会新增步骤。

挡住视线的东西就隐藏起来（“隐藏选中项”，Ctrl+H）。隐藏的形状仍留在设计中，只是不可见，也不会进入导出；导出窗口会事先说明有多少个。Ctrl+Shift+H 可将它们全部恢复显示。应当固定不动的东西，用设置顶部的挂锁或 Ctrl+L 锁定。锁定的形状无法移动、调整大小、旋转、改色或删除：它的手柄变灰，顶部箭头旁显示挂锁，会改变它的工具也会变灰。将鼠标悬停在手柄上仍会显示尺寸，按下任何会改变它的按键都会提示“对象已锁定”。只要选择中包含一个锁定形状，其他形状也不会有任何变化。隐藏、重命名、复制和创建副本仍然可用。

“可见性” 组中按钮上的数字表示隐藏了多少个形状，单击它即可全部重新显示。打开带有隐藏形状的设计时，会提示一次，并提供一个显示它们的按钮。

对象列表

零件一多，视图里很容易看不清。对象列表（“显示对象列表” 或 Ctrl+Shift+O）以列表形式显示所有形状。无论哪个设计，它都会保持你上次的打开或关闭状态，直到你关闭它；这个选择保存在浏览器中。

  • 单击条目即可选中形状，包括分组内部的零件。按住 Shift 可添加或移除条目，与在视图中一样。箭头可展开和收起分组。
  • 标签显示零件是 “实体” 还是 “孔”。
  • 挂锁和眼睛图标可锁定和隐藏单个零件。
  • “重命名” 可给零件单独命名；设置顶部名称旁的铅笔按钮对选中形状起同样作用。合理的名称在较大设计中非常有帮助。
  • 搜索框按名称和种类查找形状，因此也可以搜“圆柱体”或“孔”。它还会搜索分组内部，无论嵌套多深：包含匹配项的分组会留在列表中并展开，显示匹配的零件以及通向它们的各层分组。按自身名称找到的分组，展开后会显示其全部零件。
  • 标题栏最左侧的箭头可将列表折叠到标题栏，再展开。

列表停靠在视图立方体右侧。拖动标题栏可将它放到工作平面上的任何位置；它会从视图立方体和相机栏下方穿过。拖回视图立方体旁边，或双击标题栏，它就会重新停靠。它原来的位置以及是否折叠，都会在此浏览器中记住。

输入位置

属性面板中的 “位置” 卡片显示选中实体的位置，也可以直接输入：“X” 和 “Y” 是实体包围盒中心在平台上的位置，正负号与工作平面上显示的距离一致，“Z（高度）” 是其底面的高度。X 向右计数，Y 向后，Z 向上，遵循与 Tinkercad 和 CAD 程序相同的右手定则；平台上的坐标轴箭头显示方向。数值使用你设定的单位，滑块的可调范围与拖动时一样。

把零件停在平台旁

你可以把形状拖过平台边缘并留在那里，大约超出每边一个平台宽度，以便留待后用。方向键可把它移到任意远。停放的零件仍属于设计，会和其他内容一起导出。若要排除它，请隐藏它，或仅导出选中项。如果已选择打印机，当有内容位于其平台之外时，PrintCAD 会在导出时发出警告。

移动时吸附

在工作平面上拖动形状时，它会吸附到其他形状：其左、右、前、后边缘或中心会精确落在另一个形状的边缘或中心上。粉色参考线会显示它正对齐到什么。这样两个零件无需输入数字就能并排齐平或前后居中。关闭网格时也同样有效。

拖动时按住 Shift 可将移动限制在一个轴上：形状会沿你拖动更多的方向（X 或 Y）移动，另一个方向保持不变。最好在已经开始拖动后再按 Shift；对于尚未选中的形状，按住 Shift 单击只会把它加入选择。

如果在拖动开始时已经按住 Alt，拖动的就是副本，与 Tinkercad 一样：原形状留在原处，副本落在你松开的位置。只在拖动途中按 Alt 会暂停吸附；此时形状只跟随网格。副本也只有在途中松开 Alt 后才会吸附。要永久关闭吸附，请使用右下角的网格菜单（“吸附到形状”）或设置。目前只有正常在工作平面上的移动会吸附，抬升和调整大小不会。

对齐

选中两个或更多形状后，用 “对齐” 将它们对齐：选择周围会出现左、中、右，前、中、后，以及上、中、下的点。单击某个点即可将所有形状移到那里。如果先单击选中的某个形状，它会留在原处，其他形状与它对齐。选择中若有锁定形状，则该固定形状就是基准。左、右、前、后、上、下都以形状的包围盒为准；三角形、五边形或星形的中心是其自身中心，因此以它为中心的孔会位于形状中心，而不是其包围盒中心。

以某个角度旋转过的形状（比如 45°）对齐时依据的是它的包围盒，而不是它自身的边。要按边对齐，先在该形状的某个面上设置工作平面（“放置工作平面”，然后单击该面）：这些点便会立在该平面的坐标轴上，形状也沿这些轴测量和移动，与 Tinkercad 一样。重置工作平面，即可重新沿平台对齐。

快捷键是 L。Esc 取消。

镜像

“镜像”（M，或右键单击选择并选择它）会让选择沿某个平面翻转：“左右”、“前后” 或 “上下”。单击对应的轴箭头即可。这对对称零件很方便：做好一半，复制一份，再镜像副本。

旋转与设置旋转中心

可以用形状上的弧形箭头、设置中的数值，或按 R 以 45° 为步长旋转。在旋转圆环上拖动时，旋转会吸附到每个刻度，即每 22.5°；按住 Shift 可更精细，并会每隔 11.25° 出现额外刻度。在圆环外拖动可自由旋转，步长为 1°，按住 Shift 则为 45°。通常选择会绕其中心旋转。有时不应如此，例如要让一根倾斜的管在其端部继续旋转。这时可用 “设置旋转中心”：随后单击某个面。平面会提供其中心，例如管端的轴线。选择现在会绕该点旋转。再次单击该工具可移除旋转中心。

角度会随实体保留。在其设置中，“旋转” 以 “绕 X 轴”、“绕 Y 轴” 和 “绕 Z 轴（高度）” 显示角度，命名与位置相同：Y 横穿平台，Z 向上。在那里输入角度，实体便会转到该角度——绕其中心，或绕它自己的旋转中心（如果有）。选中旋转过的实体时，其角度也会显示在工作平面上它下方；设置中的 “显示旋转后实体的角度” 可关闭此显示。

选中一个实体时，旋转中心属于该实体：选择其他零件再回来，它仍然存在。它会随实体移动、旋转和缩放，保存在项目中，并可通过撤销恢复。在 “位置” 下，旋转中心有自己独立的 X、Y 和 Z，可以输入或微调，“移除” 可将其移除。你也可以用鼠标拖动旋转中心的红色标记：它会在实体表面滑动，并吸附到角、边中点和边上，因此铰链销能精确落在某个角上。选中多个实体时，旋转中心只属于当前选择，重新选择就会移除它。将它们组合或捆绑时会保留：该组会把它作为自己的旋转中心，并在“位置”下显示 X、Y 和 Z。

平放在某个面上

想让零件以最适合打印的一面朝下吗？选中它，单击 “平放于面”，然后单击应朝下的面。当指针在零件上移动时，指针下方的面会高亮，让你看出即将选中哪个面；旋转视图可以检查其他面。零件会转动，使该面贴在工作平面上。

两个零件需要面对面，或齐平对齐？选中应移动的零件，单击 “对齐面”，然后依次单击它的一个面和另一个零件的面。在面板中，“面对面” 让两个面相对（背面相贴、接触），“齐平” 将它们并排放在同一平面；“间隙” 在它们之间留出空间，例如用于间隙。“对齐” 会移动该零件：它以最短路径旋转，直到两个面平行——如果已经平行则不旋转——然后只朝另一个面滑动，因此横向位置保持不变。另一个零件留在原处，一次撤销即可全部还原。

孔对齐到同一轴： “同轴” 改为对齐圆面：孔对孔、销插孔、螺钉对通孔。请在点击面之前先选它。然后在要移动的零件上点击孔的圆形内侧（或销的外侧），再点击另一个零件的圆面；指向时整个圆面会高亮。“对齐” 以最短路径转动零件，直到两条轴平行，再横向移到另一条轴上。沿轴方向它保持原位，所以销会保持高度，之后再把它推进去。导入的网格也可以，只要孔由围绕一条轴的小面组成。

两个面之间的精确角度： “对齐面” 只会让面平行；没有专门用于面间角度的工具，但可以这样实现。先用 “对齐面” 让两个面靠在一起，使它们平行。然后在它们相交的边上设置旋转中心（“设置旋转中心”，单击该边或某个角），再在零件的 “旋转” 卡片中输入角度，例如 15 或 30。零件会绕该旋转中心转动。卡片中的轴是平台的轴，因此当该边沿 X、Y 或 Z 方向时，这个方法有效。

同样简单的还有 “落到工作平面”（D），它把选择落到工作平面上，以及 “居中到工作平面”。

C 会拾起选择，就像 Tinkercad 中的 Cruise：它跟随鼠标指针，并平放在你正悬停的另一个实体的面上，斜面也可以。单击即可放下，Esc 则让它留在原处。其底面随后贴在该面上，像新建形状一样与面的边缘对齐；它保留自身绕竖直轴的旋转。多个零件会一起移动并保持间距。在空白平台上，C 会让倾斜的零件重新竖直立在工作平面上。没有键盘时，长按菜单中有 “放置在面上” 可达到同样效果。

阵列：直线与圆周

孔阵列、螺栓圆周和齿圈可以用 “阵列”。选中要复制的形状，然后在功能区中单击它。

  • “行”： 选择会以相等间距重复。直线阵列可同时沿三个轴逐步排列，使用 “间距 X”、“间距 Y” 和 “间距 Z（高度）”：其中一个给出直线排列，两个或三个则给出斜线或阶梯排列。负间距会让排列朝相反方向。
  • “圆周”： 选择会围绕一个中心分布。副本数量在 “数量（含原件）” 中设置，“总角度” 为 360° 时是整圈。可选择副本是否随之旋转。“每份副本升高” 让每个副本比前一个略微升高（螺钉或上升螺旋），“每份副本半径变化” 让它离中心更远或更近（平面螺旋）；两者结合则形成锥形螺旋。螺旋最多绕一圈：角度超过 360° 按整圈计算，副本最多 100 个。

提示：先用 “设置旋转中心” 在某个面上设置旋转中心，圆周的中心就会正好落在那一点。

副本首先以预览形式出现。只有 “创建” 才会创建它们。如果副本是孔，之后请将它们与要挖孔的实体分组。

在面上制作孔阵列

对于通风口、扬声器格栅、篮子和外壳，“孔阵列” 会在平面上均匀分布孔。你不必再先做一个孔、重复它，再把它放到壁上。只选中一个实体，然后单击 “孔阵列”，它位于工具栏的 “修改” 组中、阵列旁边。也可以右键单击实体，或用 Ctrl+K 找到它。

  1. 单击实体的一个平面。你单击处周围的整个平面都算数，而不只是指针下的三角形。曲面不行：会给出提示，请改选一个平面。
  2. 在窗口中设置孔的外观和排布：
  • “孔形状”： “圆形”、“正方形”、“长方形”、“六边形” 或 “槽形”。
  • 大小： 圆孔用 “直径（Ø）”，方孔用 “边长”，矩形和槽孔用 “宽度” 与 “高度”。六边形的大小是 “对角直径（Ø）”。
  • “中心距”： 从一个孔的中心到下一个孔中心的距离。如果它小于孔所允许的最小值，PrintCAD 会将其提高到最小可能值，以便孔之间保留壁。
  • “孔间壁厚”： 同一距离的另一种说法：相邻两个孔之间留下的壁，也就是打印件中的壁厚。设定它，中心距会随之变化，反之亦然。对于六边形、矩形和槽孔，PrintCAD 测量它们边缘之间的最短距离。
  • “排列方式”： “网格” 将孔排成行与列。“交错” 将每隔一行错开半个间距，并让行更靠近，使每个孔到相邻孔的距离相同——用于六边形时便形成蜂窝。
  • “距面边缘的边距”： 孔与面边缘之间的净距离。只有完全位于“面减去此边距”范围内的孔才会生成；任何会超出该范围的孔都会被略过。面中的开口周围也会保留此边距。
  • “深度”： “贯穿整个实体”（默认）会切穿整面壁。使用 “自定义深度” 时，以毫米为单位给出深度，例如用于凹槽。
  1. 孔会立即在面上以预览形式显示，并跟随每个数值变化。窗口会说明能容纳多少个孔。“换一个面” 可选择另一个面，Esc 关闭工具；和其他工具窗口一样，可拖动其标题栏移动。
  2. 只有 “创建” 才会真正制作孔。

这些孔是与实体分组的普通孔，就像使用 “分组” 之后一样：没有任何内容被固化。“取消分组” 会再次解散分组并释放每个孔，之后你可以逐个移动、修改或删除。整个操作在 “撤销” 中算一步。该工具一次最多制作 400 个孔；超过时请把孔做大或把间距加宽。

AI 可以通过 MCP 桥接使用 layerling_perforate_face 完成同样的事（参见 AI 与 MCP 一章）。

将面推出或推入

要加厚壁、在面上加凸台或在面上挖凹槽，可使用 “面” 工具处理一个平面。它也可用于导入的 STL，那里没有草图可改。只选中一个实体，然后单击 “面”，它位于工具栏的 “修改” 组中、孔阵列旁边。也可以右键单击实体，或用 Ctrl+K 找到它。

  1. 单击实体的一个平面。与孔阵列一样，你单击处周围的整个平面都算数；曲面不行。
  2. 在窗口中：
  • “方向”： 选择 “向外：添加材料” 让材料凸出于面，或选择 “向内：挖出凹槽” 挖出凹槽。凹槽不会比面后方的实体更深；在抽壳实体上，它仍可通向内部空腔。
  • “距面边缘的内缩”： 新轮廓在面边缘内缩多少。向外时，0 会取整个面，从而加厚壁。面中的开口会按同样数值扩大。
  • “圆角半径”： 圆化轮廓的每个角，包括内角，因此尖角末端会变成圆弧。窄于两倍半径的缺口会闭合，而窄于内缩量与半径之和的两倍的那部分面会被略过。
  • “深度”： 新部分凸出于面多少，或凹槽有多深。
  1. 结果会立即以预览形式显示，并跟随每个数值变化。“换一个面” 可选择另一个面，Esc 关闭工具。
  2. 只有 “创建” 才会真正执行。

该工具添加的是一个与实体分组的普通草图实体：没有任何内容被固化。“编辑分组” 可打开分组，对新零件使用 “编辑草图” 可查看它遵循的轮廓。在普通草图实体的顶面或底面上——单一区域、未分组、未镜像、未锥化、未扭曲或倾斜，且没有描边、钥匙环、圆角或倒角——那就是实体自身的轮廓，在构建时嵌入，因此只要 CAD 内核能嵌入，其直线和圆弧就保持精确，可供边工具和 STEP 导出使用。之后调整大小时，该零件会保留其内缩量。在任何其他面上，以及导入网格的每个面上，轮廓都跟随面的三角形，曲线由短直线段组成。整个操作在 “撤销” 中算一步。之后若要更改内缩量或半径，请撤销并重新运行该工具。若之后要圆化顶边，请在最后一步对分组使用 “圆角” 和 “顶部边”：与分组上的所有边处理一样，这会将分组合并为一个实体。

AI 可以通过 MCP 桥接使用 layerling_push_face 完成同样的事（参见 AI 与 MCP 一章）。

同时修改多个零件

选中多个零件时，右侧的属性面板会显示数量，并提供适用于所有零件的操作：“实体” 或 “孔”、统一颜色（单击 “实体” 会打开颜色）以及锁定。对于混合选择，单击一次即可全部设为实体或全部设为孔。只要有任一零件被锁定，就只能使用锁定。可通过手柄、“按百分比缩放”，或在尺寸标签中输入数字来更改尺寸。选中多个零件时，该数字表示整个选择的尺寸：每个零件都会随之增大，它们之间的间距也会，就像拖动手柄一样。实体和孔也可通过右键单击或 S、H 键切换。

按百分比缩放

要按相同比例放大或缩小一个或多个零件——比如把某个打印文件的所有零件放大 20 %——请使用 “按百分比缩放”。选中零件，右键单击并选择 “按百分比缩放”，或用 Ctrl+K 搜索它。

在 “新尺寸” 下，以当前尺寸的百分比输入新尺寸：120 % 表示放大五分之一，50 % 表示缩小一半。宽度、深度和高度会同样变化，因此比例保持不变。底部保持在原处，所以不会有东西陷入平台。

选中多个零件时，可以选择它们如何增长：

  • “一起”： 零件围绕它们的共同中心增大，间隙也随之增大。整体就像一个大零件一样变大。
  • “各自原位”： 每个零件在原地增大，它们之间的间隙保持不变。

只有 “缩放” 会更改设计，后退一步即可撤销。如果选择中包含锁定零件，则不会打开该工具。

撤销

“撤销”（Ctrl+Z）和 “重做”（Ctrl+Shift+Z 或 Ctrl+Y）会在历史记录中前后步进。保存的设计会附带多少步历史，可在设置的 “历史记录” 下设定。

回看：历史记录视图

撤销和重做旁边的 “历史记录” 会打开历史记录视图，而不更改任何内容。工作区显示当时的设计，底部的滑块可浏览每个撤销步骤：最右端是当前状态，向左每一步都早一步撤销，而你已经撤销掉的状态位于当前状态的右侧。方向键可逐步浏览这些状态，Esc 返回当前状态。在滑块上滚动鼠标滚轮也有同样效果，每格一个状态，直到更早的状态；Page Up 和 Page Down 跳十个状态，Home 跳到最早的状态，End 回到当前状态。期间你可以旋转和缩放视图，并单击对象将其带回（见下文），但不能移动任何东西；设计本身保持原样。如果这条栏挡住了内容，可拖动其标题栏移开；双击它可使其归位。

有两种方式可以从较早的状态带出内容。“从此状态新建项目” 会把该状态放入起始页中的新设计，以当前设计的名称命名，并在括号中带上该状态的时间——在 PrintCAD 记录时间之前保存的设计则显示“副本”——同时附带截至该时间点的历史记录，因此撤销在那里仍然可用。“导出此状态” 会以该状态作为设计打开通常的导出窗口，因此你可以将它保存为 STL、3MF、STEP、图片或 LYL 文件，并带有截至该状态的历史记录。

你也可以把单个对象带回设计。在所示状态中单击一个对象——Shift+单击可添加更多或再取消一个，单击空白处则什么都不选——然后选择 “带入设计”。视图关闭，每个对象的副本会进入当前设计，与该状态中完全一样，并位于它当时所在的位置，处于选中状态，与设计当前的内容并排；其他内容不变。这是一步操作，因此撤销即可还原。可用于恢复你后来改过的某个零件版本，或恢复你删除过的零件。分组会整体带回；对象上的备注和参考点则不会带回。其名称会带上该状态的时间，例如“长方体（12:32）”，因此很容易与设计当前的版本区分。要从分组内部带回零件，请选中该分组并选择 “打开分组” 或按 E，与在设计中的操作一样：其零件会摆放在编辑分组时它们应在的位置，可供挑选，这条栏会显示你正位于哪个分组。“退出” 可再次关闭。这只是查看——分组、设计和历史记录都保持原样。

“删除历史记录” 单独位于这条栏的左下角。经确认后，它会永久删除所有较早的步骤：设计保留当前状态（不是所显示的状态），撤销没有可回退的内容，之后保存的文件也不带历史记录。可用它在分享设计时去掉过去的历史，或重新开始撤销步骤。此操作无法撤销；若要分享文件而不影响自己的设计，请在导出时选择 “无”。

5. 实体与孔

简单的形状如何变成内孔、槽和凹槽，以及之后如何再次修改分组。

这是 PrintCAD 中最重要的概念，而且很快就能学会：每个形状不是实体就是孔。 实体保留下来。孔是一种去除材料的工具。

实体还是孔

选中一个形状，在其设置中点击 “实体” 或 “孔”。用键盘更快：H 把选中项变成孔，S 把它变回实体。右键点击实体打开的菜单中也有这两项。孔以半透明方式显示，好让你看到它所在的位置。T 让实体变为半透明，比如为了看进一个外壳内部；再按一次又恢复不透明。它对整个选中项生效：只要其中有一个实体已经半透明，所有都变为不透明，否则所有都变为半透明。

只要没有分组，孔就不会有任何作用。它只是待在那里，显示之后某处会消失。

分组

选中实体和一个或多个孔，点击 “分组”（Ctrl+G）。现在孔会从它接触到的实体上移除材料。剩下的是一个新的单一形状。

这样就能做出：

  • 内孔： 用一个圆柱体作为孔穿透一个实体。
  • 槽： 用一个长条盒体作为孔放在边缘处。
  • 凹槽： 不穿透的孔。
  • 零件中的螺纹： 用一个孔做出内螺纹孔，参见螺纹与机械。

如果分组里有多个实体，它们会连接在一起。两个接触的实体会变成一个零件。

你可以把分组当作形状来处理：移动、旋转、上色、再次分组。“取消分组”（Ctrl+Shift+G）会把它解散，各个部件重新独立。

让分组变成孔

整个分组也可以是实体或孔。适用一条简单的规则：

  • 如果分组只由实体（或只由孔）组成，你就整体切换它，它的部件也随之改变。
  • 如果两者都有，比如一个带内孔的立方体，每个部件保持自己的状态。整个分组然后变成一个工具，但内孔仍然是内孔。

捆绑

有时部件只应保持在一起，而不该合成一个——比如多色打印时黑色底板上的一块白色标志。这就是 “捆绑”（Ctrl+B）的用途，与 Tinkercad 中一样。捆绑可以像形状一样移动、旋转和调整大小，但不会合并任何东西：

  • 每个部件保留自己的颜色，并保持为实体或孔。
  • 孔不切割任何东西。当你把捆绑与其他部件分组时，它的孔会切割那些部件，但仍不会切割捆绑自身的实体，与 Tinkercad 中一样。所以，一个旁边带着孔的销钉，可以作为一个捆绑反复使用。
  • 在 STL、3MF 或 OBJ 导出中，每个部件都是独立的实体；在 3MF 和 OBJ 中还会带上颜色。

“取消分组”（Ctrl+Shift+G）可以再次拆开捆绑，E 像打开分组一样打开它进行编辑。倒角、圆角和抽壳对捆绑不起作用，因为它不是一个实体：要这样做就先分组，或者逐个处理它的部件。如果捆绑中的某个孔也应切割捆绑自身的实体，就把捆绑拆开，再对其部件分组（Ctrl+G）。

交集

“布尔交集” 只保留两个或多个实体共有的部分。把两个相互重叠的形状叠放在一起，全选后点击它。这样就把一个圆柱体和一个盒体变成一面圆、一面直的块。分组按它的外观计算，包括孔。如果孔也被选中，剩下的是所有实体与所有孔共有的部分。如果这些形状没有任何共同部分，则不做更改，并会提示说明。旁边的 “显示公共部分” 会在应用之前显示公共部分：所选形状变为半透明，它们共有的部分以绿色绘制。逐个选中并移动每个形状，绿色部分随之变化；“布尔交集” 应用结果，Esc 关闭预览。

从一个实体中挖出另一个实体

对需要配合的零件，例如套筒里的轴或外壳里的螺栓，先做出其中一个零件，再把它从另一个零件上挖出来。选中两个实体，在“组合”区域点击“Cut out”，或右键点击后在那里选择。面板会写出保留的零件和得到空腔的实体；PrintCAD 把较小的当作零件，“Swap the two”可以对调。“Clearance”让空腔在零件四周都大出这么多：0 表示刚好吻合，0.2 mm 是打印配合的常用间隙。“Cut out”从另一个实体上挖掉零件的副本，零件本身留在原处。结果是一个分组：“取消分组”可以把这次切割重新拆开。设置间隙要求零件是精确实体，与为此使用的“偏移”工具相同。

编辑分组

如果内孔做小了，你不必解散分组再重建。选中分组，在其设置中点击 “编辑分组”、点击对象列表中的文件夹图标，或按 E。双击分组也一样，与 Tinkercad 中一样，对捆绑也适用；如果你不希望这样，在设置中关闭 “双击打开分组或捆绑”。部件只有在指针拖动几个像素之后才开始移动，所以手抖的单击或双击不会把它碰偏。现在部件分别摊开，你可以用任何工具修改它们：把孔做大、移动实体、添加孔。

画面底部会出现一条栏。“完成” 会重建分组，保留它的名称、颜色以及实体或孔的状态。“取消” 则原样放回。

如果其中一个部件本身就是一个分组，你可以用同样的方式编辑它，以此类推，深入到设计有多深都行。栏中会显示你所在的位置，例如“支架 › 螺钉柱”。“完成” 和 “取消” 总是结束最内层的分组，并把你退回上一级。当你在某个分组内部时，只能编辑其部件中的分组；要编辑另一个，先完成当前编辑。

与 “取消分组” 不同——后者会永久拆散分组——编辑会保留分组：它的名称和设置都还在，你随时可以用 “取消” 返回。

注意：加在整个分组上的圆角和倒角会在重建时丢失。栏中会提示你。

分割

“分割” 在 “修改” 区域中用平面把选中项一分为二——比如一个对打印床来说太大的零件，或一个你想看内部的零件。选中一个或多个实体或孔，然后点击它。一个半透明平面会明确显示切割的位置，实体上还会有一条白线标出平面与实体的交线；在你应用之前不会有任何改变。

  • “平面方向”：X 在左右之间做竖直切割，Y 在前后面之间做竖直切割，Z 在上下之间做水平切割。坐标轴按位置卡片上的命名，Z 朝上。平面一开始平行于工作平面，因此在底板上是沿 Z 轴。
  • “对齐到工作平面”：“平行” 让平面平行于工作平面，“沿 X 方向” 和 “沿 Y 方向” 让它垂直于工作平面，横跨其 X 或 Y 方向。工作平面的原点穿过选中项时，平面就经过该点，否则经过中间。于是你可以用 W 把工作平面放到一个斜面上，直接在那里切割，不必转动滑块。
  • “平面位置”：平面在何处穿过，用滑块或输入数值。开始时位于中间。你也可以拖动平面上的箭头；平面沿箭头方向以 0.1 mm 的步长移动。
  • “拾取面”，位置旁边的按钮，把平面放到一个面上：点击它，然后点击那个面。方向、两个旋转和位置都会相应设置。拾取时，指针下方会有一个蓝色平面，显示将要采用的面。未选中实体的面也可以，用来对齐切割，但平面仍局限在选中项内。Esc 停止拾取，平面留在原处。
  • 下方两个旋转滑块绕另外两个轴转动平面，各方向最多 180°，用于斜切。两者可以组合。

“分割模型” 或 Enter 执行切割，Esc 取消（在拾取面时，第一次按 Esc 只会停止拾取）。平面穿过的每个对象都会变成两个封闭实体，按所在侧命名，例如“长方体（Z+）”和“长方体（Z-）”；未穿过的对象保持原样。一个孔会变成两个孔，抽壳实体保留其空腔。两半都留在原位——要打印的话，用 “平放于面” 把每一半放到其切割面上。

两半是普通网格：圆柱体的边数或文字的字体等设置都已丢失，所以要先设置好这些。Ctrl+Z 一步即可恢复原状。锁定和隐藏的对象无法分割。

分离部件

如果一个形状由几个分开的片段组成，比如由单个字母组成的文字，“分离部件” 会把它拆分为各自独立的形状。右键点击形状打开的菜单里也有这一项。

提示： 孔总要做得比它要穿过的零件稍长一些。如果孔正好在表面处结束，有时会残留一层极薄的表皮。多伸出 1 mm 就能确保切穿。

6. 处理边与抽壳实体

对指定的边做倒角或圆角，为盒子、杯子和壳体抽出等壁厚的空腔。

为边做倒角与圆角

在打印件上，锋利的边很少好看，也并不特别结实。倒角把边斜着切掉，圆角把边磨圆。两者都作用于你点击的边。

  1. 选中实体（或分组）。
  2. 在功能区点击 “圆角” 或 “倒角”，按 B 打开圆角、按 Shift+B 打开倒角，或右键点击实体并从菜单中选择。
  3. 实体的边会亮起。点击要处理的边。再点一次可将该边取消。按住 Shift 可单独添加或移除一条边。
  4. 设置尺寸，然后用 “应用” 或 Enter 确认。之后窗口会带着相同尺寸停在新实体上，马上就能接着做下一个圆角或倒角；“完成”、Esc 或叉号可关闭它。按住 Shift 或 Ctrl 点击 “顶部边”、“底部边”、“竖直边” 或 “水平边” 时，这些边会加入已选的边，而不是替换它们。

面板位于右上角。如果它挡住了你要点击的边，抓住标题栏把它拖开；下次它也会在那里打开，“抽壳” 和 “阵列” 同样如此。双击标题栏可将其复位。

面板打开时从形状列表中选取形状会关闭面板，不应用任何更改，你点过的边也会被遗忘。这一次点击会放置新形状，而不是选取边。

面板中包括：

  • “所有锐边” 一次选中所有边，“清除” 清空选择。
  • 圆角用 “半径”。倒角则设置 “距离” 或 “角度”。
  • “可变半径”（仅圆角）让半径沿一条边变化：一端小，另一端大，中间匀速过渡，例如直壁与斜壁相交处。先点击单条边，再设置 “起点半径” 和 “终点半径”。哪一端算起点取决于这条边是如何生成的；如果较大的半径出现在错误的一端，可用 “交换两端” 对调。它一次只处理一条边，所以多条边要依次倒圆。“编辑” 可把两个数值调回来。
  • “锐边阈值” 决定哪些边算作锋利的边。设为 25° 时，只有明显的折角才算边，平缓过渡不受影响。
  • “竖直边” 选取竖直向上的边，例如长方体的角：一次圆角就能把所有竖直的角一起倒圆。
  • “顶部边” 只选取实体最顶部的边。做饼干模具时这是快捷做法：在草图里用描边画出轮廓，再对顶部边做倒角。“角度” 设置倒角的陡峭程度；倒角深度不会超过壁厚。
  • “底部边” 只选取实体最底部的边，是 “顶部边” 的镜像。想只对零件底部做圆角或倒角时，这是快捷做法。
  • 在倒角窗口顶部 “倒角” 旁选择的 “圆滑倒角”，用于做零件可打印的底部：在平台上是一段倒角，朝壁面方向相切地过渡为圆角，这样最初几层不需要支撑，边的收尾依然柔和。“距离” 是底部占用的高度，“角度”（15° 到 75°）是平台处倒角的陡峭程度。用 “底部边” 选取边。
  • “仅可见边” 隐藏从你的视角看位于实体背后的边。默认情况下所有边都会透过实体显示，零件复杂时容易看花眼；打开此开关后，你只能看到并点击朝向你的边。转动视图才能处理其余的边。以红色显示的边（见下文）始终可见。
  • “单击还会选中平滑延续的边”：点击时还会一并选取彼此平滑相接的边，例如带圆角的面周围的所有边。这个开关只决定点击选取哪些边：CAD 内核总会让倒角或圆角沿着这类平滑延续的边延伸下去。面板会告诉你它还沿多少条边延伸。
  • “缩放时保持边尺寸” 即使之后缩放实体，也让倒角或圆角保持原来的大小。
  • “预览质量”（“草稿”、“标准” 或 “精细”）决定预览的计算精度。零件复杂时 “草稿” 更快。

调整尺寸时，PrintCAD 会重新计算预览。这可能需要一点时间。你可以继续调整；最终计算的是你最后选择的数值。

如果尺寸对这条边来说太大，PrintCAD 会提示并建议一个更小的值。通常少一两毫米就够了。在尖锐的夹角处，圆角需要的空间比半径看起来更大。屏幕较小时，面板会自动向下滚动，让提示信息显示出来。

如果原本可行的选择在又点了一条边后失败，那条边会变红并画得更粗：在当前尺寸下，它无法与其他边一起处理。再点一次可将它取消，或把尺寸调小。提示仍在时继续点击其他边，最早出问题的那条会保持红色。如果没有先前可行的选择——比如第一次点击，或你刚调大的尺寸——则单独处理也失败的边会变红；若只是它们的组合失败，则全部变红。

指针下方的边也会画得更粗，方便你看出点击会选中哪一条。

撤销边处理

处理过的实体随时可以再次处理。重新选中它并打开工具——圆角、倒角或抽壳都会显示这份列表：在 “撤销边特征” 下可以看到它上面已经有哪些处理。“撤销” 可撤销单次处理。注意：如果上面还叠着更新的处理，它们会一并撤销，面板会告诉你有多少个。

倒角、圆角或抽壳旁边还有 “编辑”。它以同样的方式撤销该处理，但会立刻用相同的边和原来的数值重新打开工具。你改完数值再应用即可：3 mm 的圆角变成 5 mm，无需再点一遍边。如果上面叠着更新的处理，这里它们也会一并撤销。这适用于从今往后做的边处理；更早的处理只提供撤销，分组中的单个部件也是如此。

对分组，比如带孔圆柱体，被处理的边属于最终成形的实体，而不属于其中某个部件。因此分组会变成一个实体。“取消分组” 对它仍然有效：它会先撤销边处理特征，再解散分组，整个过程一步完成，Ctrl+Z 即可撤销。若按上文所述撤销该处理，分组会带着所有部件恢复。最省事的做法是把边处理留到最后。螺纹也是如此：边工具把螺纹当作它的精确实体，所以带螺纹孔的方块可以在螺纹就位的情况下倒圆边。计算螺纹的边比普通形状更耗时，M6 需要几秒，G1/2 管螺纹约需半分钟。

值得了解： PrintCAD 对圆角和倒角使用真正的 CAD 几何，而不只是三角网格。因此在 STEP 导出中，倒圆的边依然是倒圆的边。

以 STEP 导入的零件也会保留其 CAD 几何：倒角、圆角和抽壳都作用在文件中的实体上，无论屏幕上把零件画得多精细。STL、OBJ 和 3MF 只带来三角面，绘制精细的零件可能对边工具来说过于稠密。如果某个零件同时有 STEP 版本，就导入它。

抽壳实体

盒子、杯子、壳体和盖子都有一个共同点：内部是空的，壁厚均匀。这正是 “抽壳” 做的事。

  1. 选中实体并点击 “抽壳”，或右键点击实体并从菜单中选择。
  2. 设置 “壁厚”。
  3. 在 “开口侧” 下打开要保持开口的各个面：“顶部”、“底部”、“前”、“后”、“左” 或 “右”，想开几个都行——只开 “前” 会做出抽屉槽，开 “左” 和 “右” 则做成通道。一个面都不开时，实体四周封闭，中间留有空腔。“封闭（内腔）” 一键关掉所有面。面板打开时 “顶部” 已经处于打开状态；再点击它就会把顶部重新封上。四周封闭的实体从外面看没有变化：剖视图能显示空腔。
  4. 选择 “内部边” 是 “圆角” 还是 “尖角”。
  5. 点击 “抽壳”。

壁向内部生长。外部保持不变。

“内部边” 只在内壁分开的地方才有影响——实体上的台阶处或开口周围。普通长方体空腔的角在两种设置下都是尖的。想要圆润的内壁，先对实体的外边倒圆（见上文），再抽壳：内壁会按半径减去壁厚来跟随。如果圆润的内壁无法生成，例如轮廓由大量很短的直线段组成时（比如描摹的图形），PrintCAD 会改用尖锐的内角来构建同样的抽壳实体。

每个开口面都要求实体在该侧的最边缘有一块平面。因此球体和自由曲面形状不能这样抽壳。如果壁厚对实体来说太厚，PrintCAD 会提示并要求更小的值。上下边也做了圆角的长方体就是这种情况：它的壁厚必须明显小于那个圆角，或者先把圆角设为 0。

带凹槽的实体——比如把长方体与一个抬高的孔分组，做出不通透的孔——也能抽壳，顶部开口：凹槽周围的壁同样会被抽空，于是外壁与凹槽之间留下一圈顶部开口的空腔，凹槽底面之下还有一层薄空腔。

以尖端收尾的实体，例如圆锥或旋转出的三角形，顶部没有可以保持开口的平面。全封闭空腔在这里也行不通，因为尖端无法向内偏移：即使壁厚只有 1 mm，也会提示无法使用这样的壁厚。改为在旋转之前把壁画进轮廓：复制轮廓，将副本等比缩小，把它放到大轮廓中间并用它切掉大轮廓，再整体旋转（见“草图”章节的“旋转”一节）。两条轮廓之间的距离就是壁厚。

如果之后调整已抽壳实体的尺寸，PrintCAD 会立即按新尺寸重新抽壳。壁厚保持你选择的厚度，圆形实体也一样。圆柱体若某一方向拉得比另一方向多，就会变成椭圆。

提示： 使用 0.4 mm 喷嘴时，1.2 到 2 mm 的壁厚是个不错的起点：够薄以节省材料，够厚以保证零件结实。

偏移实体

实体的每个面都可以向外或向内移动相同的距离。配合、盖子或卡扣连接需要的正是这个：四周留出 0.1 到 0.3 mm 的间隙，而各个特征留在原位，这是缩放做不到的。

  1. 选择一个实体并点击 “偏移”，或在实体上点右键后在菜单中选择。
  2. 选择 “放大” 或 “缩小”，并设置 “距离”。
  3. “外角” 决定外角：圆角让偏移后的曲面在外角保持圆滑，尖角让各面延伸直到相交。
  4. 勾选 “保留原件，并把偏移后的实体作为孔添加” 可保持零件不变，并把放大后的实体作为已经是孔的副本。把这个孔和配合件编组，它就切出你选定的间隙。
  5. 点击 “偏移”。

不勾选时偏移的是实体本身。它会变成固定的精确实体，就像倒角之后：面板顶部的列表可以撤回偏移，“编辑” 会用原来的距离重新打开工具。只有精确的 CAD 实体可以偏移 - 长方体、圆柱体和其他形状、它们的组、导入的 STEP 零件。只是三角网格的实体，如许多 STL 导入，往往不行。对实体来说过大的距离，例如缩小到超过最薄的壁，会被拒绝。

删除面

挡路的圆角、位置不对的孔、不再需要的凸台：“删除面” 能把它从实体上去掉，而无需重建实体。

  1. 选中实体并点击 “删除面”，或右键点击实体并从菜单中选择。
  2. 点击要删除对象的每一个面：圆角的面、孔的壁面、凸台的侧面和顶面。选中的面会亮起；再点一次可取消。面板会统计面的数量。
  3. 点击 “删除” 或按 Delete。Esc 关闭工具，不做任何更改。

被删面周围的面会延伸，直到补上缺口。顶部边做了倒圆的长方体会恢复锋利的边，孔被填上，凸台消失。实体保持精确，因此还能再做圆角和倒角，STEP 导出也会保留真实的曲面。Ctrl+Z 一步撤销删除。它也会与圆角、倒角一起列在 “撤销边特征” 下，在那里可用 “撤销” 撤销；它没有 “编辑”。对分组而言，结果是一个实体，与边处理相同。

选中要删除对象的每一个面，而且只选这些面。如果周围的面无法补上缺口，PrintCAD 会提示，且不做任何更改：例如长方体的一个主侧面，没有能顶替它的相邻面。只删除凹槽的底面，会让它变成通透的孔，因为凹槽的壁会一直延伸到另一侧。

“删除面” 需要精确的面：它适用于以 STEP 导入的零件和 PrintCAD 的形状。凡是 PrintCAD 以网格保存的都没有精确面：导入的 STL、OBJ 或 3MF，分割、包裹或简化过的实体，或者非常精细的形状，例如很长的文字。能导入 STEP 时就导入 STEP。对精细的导入零件，少数几个面也可能超出 CAD 内核的处理能力：45 秒后删除会被中止，且不做任何更改。如果实体在边处理之后调整了尺寸，同时保留了边的尺寸，那么在新尺寸下它没有精确的面，直到撤销这次尺寸调整。

7. 草图：从轮廓到实体

画出平面轮廓，给角点做圆角或倒角，再把它拉伸或旋转成实体。

并非所有东西都能用基本形状拼出来。像支架、齿形或花瓶这类有自己轮廓的零件，要先画出轮廓，再由它做出实体。草图模式就是干这个的。

开始草图

在顶部从 “3D 编辑器” 切换到 “草图”。功能区的 “创建” 组里并排有三个按钮，决定轮廓要变成什么：

  • “拉伸草图”：轮廓向上拉起，像饼干模具。
  • “旋转草图”：轮廓绕一条轴旋转，如同车床。花瓶、杯子、圆锥和所有圆形的东西都这样做。
  • “扫掠草图”：轮廓沿一条路径拉伸：拐弯的线缆槽、导管、绕在某个形状上的环。见下面的沿路径扫掠。

编辑器随后显示一张带网格的图板。那就是你的绘图面。

绘制

草图模式的功能区分成几个区域：

  • 绘制：“直线” 画直线段：依次点击各个点；按住 Shift 时新线按 15° 步距吸附，水平和垂直也包括在内。新线的长度和角度显示在指针旁。也可以键入长度，见用数字画线。“圆弧” 通过三个点画真正的圆弧：先点击它的两个端点，再点圆弧经过的第三个点；在第三次点击之前，预览跟随指针，提示信息会说出半径。端点若点在与已有点重合的位置，就会连接到它，因此圆弧可以封闭轮廓。Esc 放弃已点击的点并回到 “选择”。之后圆弧就是由点和曲线组成的普通几何图形：像其他线条一样移动、剪切或擦除。“贝塞尔曲线” 用它的手柄塑形：点击一个点，并沿线条应继续的方向拖动，就像 Illustrator 或 Inkscape 里的钢笔工具。拖得越远，弯曲越强；拖向新点的那一段在拖动时就跟着弯曲，因此能直接看到结果。放置点时拖动会让曲线弯曲；如果你来自 Tinkercad，只想点几个点，就用 “平滑曲线”。“平滑曲线” 在你点击的各点之间铺出一条流畅的路径。要封闭轮廓，最后再点击第一个点。要不封闭轮廓而结束连续画线，保持指针不动点右键，或双击最后一个点。
  • 形状：“添加草图形状” 提供现成的轮廓：“矩形”、“圆形”、“椭圆”、“半圆”、“扇形”、“螺栓圆”（带孔的圆盘）、“三角形”、“六边形”、“多边形” 和 “星形”。点击其中一个即可放到草图原点，也可以从菜单把它拖到想要的位置。在菜单底部，“边数 / 角数” 设置多边形的边数和星形的角数，“星形内径” 设置星形的凹谷向中心伸入多深（外半径的 10% 到 90%）；两者都作用于你下一个添加的形状。和所有草图形状一样，之后它们就是普通的角点，可以逐个移动、做圆角或倒角。
  • 重叠：把两个闭合轮廓叠在一起，它们仍是两个实体，在 3D 编辑器中合并；重叠部分不算孔。只有完全位于另一个轮廓内部的轮廓才会形成孔。移动不会在交叉处连接线条，所以可以再把形状拉开。不过，如果你画一条线穿过其他线，PrintCAD 会在每个交叉处放一个点。
  • 选择：“选择” 移动点和线。在闭合轮廓内部点击会选中整个轮廓，可以直接拖动或调整大小；在孔的内部点击则选中孔。选择框有八个手柄：角上的手柄同时改变宽度和高度，按住 Shift 时保持比例。边上的手柄只改变一个方向。出现的栏里的 “保持比例” 无需 Shift 也能保持比例：这时角上和边上的手柄都会按同样比例拉伸，键入宽度或高度也会同时改变另一个。PrintCAD 会记住这个开关。旁边的 “锁定” 锁定选中的轮廓，就像 3D 编辑器里锁定实体一样（Ctrl+L 效果相同）：它不能再被移动、调整大小、旋转或修改，线条变淡，点变成灰色，选择框的手柄也变灰且不再响应。选中时，点击其角上的锁形图标即可解锁。线条仍然可以从它的角点开始。“解锁” 或再按 Ctrl+L 可解锁。选择框四角外的弧形箭头让整个选择绕其中点旋转：指针上方的数字显示角度，按住 Shift 时按 15° 步进。旋转时会出现一个圆环：指针在环内时按 22.5° 步进吸附，在环外按整度旋转，不受网格影响。每按一次 R，整个闭合轮廓旋转 45°。点击宽度或高度胶囊框可键入新尺寸，也可以输入算式（“60+12.5”）或百分比（“150%”）。按住 Shift 时，点击一个点或一条线会将它加入或移出选择，这样就能选中多个一起移动。在空白处拖出选框，可选中框内所有内容。线条也能拖动（它随两端移动；若它属于某个选择，则整个选择一起移动）。方向键按一个网格步距移动选择，同时按 Shift 则步距更大；拖动时按住 Shift 可让移动保持在一个轴上。“添加或移除点”：点击一段线条添加点，点击一个点则删除它。此外还有 “擦除”（点击一个点或一条线就删除它，拖出选框经过多个则删除框内所有内容，已有选中项时该按钮删除所选内容）以及插入模板图片（“添加图片”）。删除一个点时，PrintCAD 会把它的两个相邻点连接起来，使轮廓保持闭合。要补上缺口，例如擦掉六边形的一条边之后，把一个开放端点拖到另一个上：它会吸附过去，两点合为一点，轮廓便重新闭合。在交叉处，例如一条线穿过一个圆的地方，直通的两侧会相连：弧接弧、线接线，圆仍保持圆形。如果只想去掉圆的一小段，比如做一个圆角，就用橡皮精确点击两点之间的那段弧；其余部分保留。
  • 剪贴板：“复制”、“粘贴”、“复制副本” 和 “删除” 作用于选中的点、线和图片，与 3D 编辑器一样；Ctrl+X 为剪切。粘贴和复制的几何图形会落在原图形旁边，相隔 10 mm，位于不接触任何现有线条的空位，因此绝不会与已有内容连在一起。它保持选中，可以直接拖到位。
  • 历史记录：“草图撤销” 和 “草图重做”。
  • 管理：“备注”（或 N）在草图上放置备注，与 3D 编辑器中相同：下一次单击即放置备注，可以放在任何位置，也可以放在线条上。拖动图钉可移动备注；单击图钉会收起卡片。草图的备注属于它的实体：在 3D 视图中，它们位于用 “拉伸草图” 或 “扫掠草图” 生成的实体顶面上，以及用 “旋转草图” 生成的实体所绘制的轮廓上，并随实体一起移动。再次打开草图会显示该实体的所有备注，包括在 3D 中放置的备注。“草图撤销” 会像撤销线条一样撤销备注，“取消” 会放弃对备注的更改。详见“测量与备注”一章。
  • 视图：用中键平移，或按住 Shift 或 Ctrl 加右键拖动，与 3D 编辑器一样。没有选中任何东西时，Ctrl 加方向键也能平移视图：每按一次移动画面的十分之一，同时按 Shift 则为一半，草图按所指的方向移动。Home 让整个草图适合视图，F 缩放到选择（没有选中项时缩放到整个草图），+ 和 − 放大缩小，与 3D 编辑器一样。没有选中项时，双击空白处会平移视图，使该处移到中间，与 3D 编辑器一样；设置中的 “双击工作平面，视图以该处为中心” 可关闭此功能。侧栏上的 “卷尺” 测量两点之间的距离。一选中某个东西，草图就会显示尺寸：一条线的长度，或某个点上与之相交各线的长度。当这些尺寸碍事时，例如在塑造曲线时，侧栏上的 “显示测量” 按钮可以隐藏和显示它们；卷尺仍然可用。在直线上可以点击尺寸胶囊框，键入以毫米计的长度；Enter 应用，Esc 取消。线条保持方向，起点不动，另一端的线条跟随移动。若选中的是一个端点，则该端点移动。Alt+Enter 使线条以中点为心向两侧伸缩。在曲线上，胶囊框只显示长度。

只有闭合的轮廓才能生成实体。

按 1 到 4 选择绘图工具，顺序与工具栏一致：“直线”、“贝塞尔曲线”、“平滑曲线” 和 “添加或移除点”。在没有画线时它们有效；正在画线时，数字是线的长度（见下文）。

用数字画线

用 “直线” 或 “平滑曲线” 定下第一个点后，直接键入数字：线旁会打开两个字段，“长度” 以毫米计，“角度” 以度计。< 或 Tab 切换到角度，所以 “50<30” 得到一条长 50 mm、角度 30° 的线，与 AutoCAD 一样。Enter 定下该点，随即可以键入下一条线；Esc 关闭字段但不结束连续画线。

角度从右侧起逆时针计算：0° 向右，90° 向上，180° 向左，270° 向下。留空则线条跟随指针，因此只给出长度，用鼠标指示方向。两个字段里都能输入 “40+12.5” 这样的算式。如果该点会落在平台之外，字段会提示并等待另一个值。

让直边弯曲

选中一条直线，点击出现的栏里的 “曲线化”：这条边弯成曲线，与 Tinkercad 一样，并显示两个手柄。拖动手柄来塑造曲线；手柄拉得越远，弯曲越强。“直线化” 让这条边重新变直。选中的点可以用 “平滑曲线” 变成圆滑的：它获得自己的手柄，相邻的线变成曲线。选中三个或更多点时，栏里的 “过点曲线” 会从第一个点到最后一个点铺一条平滑曲线，穿过中间的每个点，与 “平滑曲线” 工具画出的一样；两端以外的线保持不变。其他软件称之为“Fit curve”或“Fit point spline”。两者的区别：“曲线化” 把每条选中的边单独弯曲，保留边与边之间的拐角，适合在一条边上做拱形；“过点曲线” 让一条曲线穿过这些点，不留拐角，适合把描出的锯齿状边缘变平滑。点击一个手柄，它会亮起：此时方向键按一个网格步距移动它，配合 Shift 步距更大，因此可以精确设置曲线。

读取和键入角度

点击两条直线相交的角点：在长度旁边，PrintCAD 以小圆弧显示它们之间的角度，单位为度。在闭合轮廓上，这是形状内侧的角度，所以凹口读到的是大于 180° 的值。点击该数值并键入新角度。两条线中的一条随即绕角点转动并保持长度，另一条留在原处。转动的线以虚线绘制；Tab 切换到另一条，Enter 应用，Esc 取消。转动线远端连着的东西随之移动。

移动一个点会改变三个角度：该点本身，以及它两条线远端相邻的两个角。因此 PrintCAD 也显示那两个角，每一个都可以点击并键入。这样就能在选中会随之移动的左上点的情况下，把左下角设为例如 75.5°。这里也能做运算，例如 “90-14.5”。

曲线交汇处，或超过两条线交汇的角点，不显示角度。侧栏上的 “显示测量” 按钮会连同长度一起隐藏角度。

圆角与倒角

点击一个角点，选择 “圆角化角点” 或 “倒角化角点”。会出现一个小字段，用于 “半径” 或 “距离”。输入尺寸并用对勾确认。这适用于两条直线之间的角。

也可以一次处理多个角：按住 Shift 逐个点击选中，或框选它们，然后从出现的栏里选择 “圆角化角点” 或 “倒角化角点”。它们都得到相同的半径或距离。若两个选中的角共用一条边，每个角最多占这条边的 45%，这样四角都做圆角的长方形每个角看起来都一样。不是两条直线之间夹角的点会被略过，提示信息会说明略过了多少个。框住整个形状，或在形状内部点击，会同时选中它的角点和线条，此时栏里在角工具旁边会为所有选中的线提供 “曲线化” 和 “直线化”。

镜像

选中点和线（点击、Shift 加点击，或框选），然后点击栏里的 “镜像”。然后选择轴：“左右” 沿穿过平台中点的垂直轴镜像，“上下” 沿水平轴镜像，“沿直线” 沿你接下来点击的草图中的一条直线镜像。副本加到另一侧，原图形保留；两者没有任何关联，因此可以各自修改。位于轴上的点是共用的，因此两端落在轴上的半个轮廓会变成一个闭合轮廓：画出半个支架，选中、镜像，然后生成实体。构造线很适合做轴。Esc 取消。

构造线

构造线帮助你放置点，而不成为实体的一部分。它以虚线绘制，永远不算轮廓：想拉出形状多远都可以，实体不会因此变大。

  • 在 “绘制” 组里打开 “构造线”。之后新画的线，包括按尺寸键入的线，都是构造线。再按该按钮切回普通线。
  • 已经画好的线，点击它并选择 “构造线” 即可变成构造线。“设为普通线” 让它恢复为普通线。
  • 新点会吸附到构造线与其他线的交叉处（会显示蓝色圆环），也会吸附到构造线的端点。这样无需计算，就能把角点放在中点、距某条边固定距离处或交叉处。
  • 新点还会吸附到草图中每条直线的中点、每个圆和圆角的中心，以及下方显示实体的各边中点（#624）。正在拖动的点会忽略它自己线条的中点。
  • “绘制” 组里的 “从中间画线” 从线的中点开始画线：先点击中点，再点击端点，线条会向另一侧延伸同样的长度。中点会成为独立的一个点。再按该按钮可画普通线。
  • 构造线穿过轮廓时不会把它切开。旋转时它也可以位于轴的右侧。

用它生成实体

点击 “完成草图”。轮廓作为实体立在工作平面上。在它的设置里，可以像其他形状一样修改高度、颜色和其他一切。调整它的大小时，PrintCAD 片刻之后会从草图重建它，草图也随之变大。因此它仍是精确实体，可以倒角和圆角，下次编辑时草图的尺寸就是实体的尺寸。

如果工作平面位于实体的某个侧面上，你就按看那一面的方向来画：草图里的上方就是完成实体上的上方。草图视图中实体淡淡的轮廓显示它所在的位置。如果工作平面切过实体，草图视图改为显示那个切面的轮廓，因此抽壳实体看起来像一个环，你可以让草图与它的壁对齐。你设置或拖动的点靠近这些轮廓的角点时，会精确吸附到角点上；会出现一个小蓝环。这样就能把其他实体的边带入草图中，即使工作平面并不恰好落在这些边上。要描摹已有的模型，请打开 “显示透视到的部件：它们在草图平面上的所有边”（左侧视图按钮中的图层按钮）：之后实体的所有边都会画在草图平面上，细而淡，仿佛能看穿它们，无论它们位于什么高度。竖直的平面，例如设在正面的平面，就会以这种方式显示正视图。这个选择会保存在浏览器中。

用 “编辑草图” 可以随时回到草图进行修改。双击实体也可以，与 Tinkercad 一样（锁定的实体不会打开）；设置里的 “双击打开草图” 可以关闭这一功能。不过，你已经对实体做过的边缘处理会丢失，因为边是重新生成的。在 3D 编辑器中旋转或移动过的物体，会在它在平台上的位置打开，方向与你在那里看到的一致，并使用平台的网格；只有倾斜或镜像的物体才会以它自身的方向打开。

包含多个轮廓的草图生成一个实体，重叠的轮廓在其中合并。若想让每个轮廓各自独立，选中实体并点击 “分离部件”：每个外侧轮廓连同其中的孔成为独立实体，并保持实体的高度、颜色和位置。每个部件都有自己的草图可编辑，构造线也在其中，因此可以逐个抬高或降低各个部件，之后再合并或切除它们。边缘处理会阻止此操作，之后被拉伸过的实体也不行：那样它会作为网格拆开。

用同一张草图做另一种实体：草图顶部的标记说明它会变成什么，“拉伸草图”、“旋转草图” 或 “扫掠草图”。点击它并选另一个，编辑已有实体时也可以：导入的 SVG 本来是拉伸的，切换到 “旋转草图” 就变成花瓶或旋钮。跨越轴的轮廓会向左移动，直到右边缘落在轴上，于是 SVG 的半个横截面就绕它的直边旋转；Ctrl+Z 可撤销这次移动。完成时，新实体接替旧实体的位置、名称和颜色，底部高度相同。边缘处理会消失，这与每次编辑草图一样。

旋转

旋转时，把半个横截面画在草图中所示轴的左侧。旁边可以看到旋转的 3D 预览。它立刻显示实体将会是什么样子。轮廓必须闭合，或者把开放线条建成描边，见下文。最后点击 “完成旋转”。设计中的其他实体以正面显示，与轮廓采用同一视图，轴位于中间：把轮廓画在它们旁边或上方。实体立在你在草图中画它的位置，穿过草图中央的水平线是地面：画在它上方的轮廓得到的实体立得更高，其最低点就是实体的底部。

旋转实体和拉伸实体一样是精确实体：可以倒角和圆角，也可以抽壳，做成杯子或花瓶。用旧版 PrintCAD 旋转出的实体是网格；打开 “编辑草图” 再完成一次，即可让它变精确。跨越轴的轮廓无法精确构建，和以前一样会变成网格。

一根连续的条：“螺距”。旋转会把轮廓变成闭合的环。选中旋转实体，在属性面板中给它一个大于 0 的 “螺距”，即每圈上升的距离，轮廓就会改为盘成螺旋：一根连续的条，像线轴上的耗材或弹簧。“扫掠” 则变成 “圈数”，最大 200；负数向左旋。相邻圈距小于轮廓高度时会熔成一个实体，因此细螺距的实心芯也能做。螺旋以网格构建，因此圆角、倒角和抽壳对它无效；圈数多时把 “边数” 设低。螺距为 0 又变回环。

沿路径扫掠

“扫掠草图” 把轮廓沿路径拉伸：拐弯的线缆槽、导管、皮带周围的护罩、绕六边形的环。它在 “创建” 组里，位于 “拉伸草图” 和 “旋转草图” 旁边。

在同一张图板上画两样东西：

  • 横截面照常作为闭合轮廓。按从路径起点沿路径看过去的样子来画：横向是草图的左右，向上就是完成实体的上方。空心截面，比如槽或管，是轮廓里再套一个轮廓。截面以路径为中心，实体以截面的最低点立在草图平面上。
  • 路径作为 “构造线”：打开它，画出线或曲线，构成一条链，开放或闭合（闭合链得到环）。路径平躺在草图平面内。

把截面画在路径应当开始的端点附近；路径从离它最近的端点开始。然后点击 “完成扫掠”。直线段的拐角会变成斜接，曲线保持平滑，截面全程保持竖直。实体和拉伸的一样精确：圆角、倒角和 STEP 导出都能用。如果缺少闭合轮廓或路径，或者有多条彼此分离的路径，PrintCAD 会提示。用 “编辑草图” 可以回到草图修改截面或路径。

按描边生成

通常，闭合轮廓内部的区域成为实体。用 “完成” 区域里的 “描边”，改为构建线条本身，宽度由你设置。在面板中勾选 “按描边构建”；草图立刻显示结果。

  • 闭合轮廓变成一个边框。“位置” 说明壁落在哪里：“居中” 在画的线上，“内侧” 在其内侧，“外侧” 在其外侧。外侧对齐在留公差时很方便：画出孔的轮廓，比如燕尾，给它 0.2 mm 的外侧描边，就得到了打印所需的间隙。
  • 开放线条变成一条带子，以线为中心。“端点” 决定端头的样子：“平头”、“方头”（长出半个宽度）或 “圆头”。
  • “拐角” 对两者都适用：“尖角”、“圆角” 或 “斜角”。

草图保留所画的线。再次打开后可以继续修改线条和描边；取消勾选，区域又会重新生成。曲线会为此拆成短的直线段。

在旋转中，描边是一层薄壁：把花瓶或杯子的壁画成轴左侧的一条开放线，勾选 “描边” 并设置宽度，旋转就会把这条带子转出来。越过轴的部分会在轴处被切掉。

填充与剪影

不用打开草图也能设置描边：在草图实体的属性里，在 “填充” 下选择 “面积”、“描边在外”、“描边在内” 或 “描边居中”，并设置 “线宽” 和 “拐角”。实体会立刻在原位重建。这些对应 Tinkercad 导入 SVG 的填充模式：默认、外线和内线。“加宽” 保持区域填充，并向四周扩展一个线宽，角可以是尖角、圆角或斜角：多色打印时标志下方的一层底色，仅用外侧描边只会得到一个环。“收窄” 相反：区域保持填充，边缘向四周内缩一个线宽，孔也算在内（孔会变大）。在同一草图的副本上两者都用，可以做配合：孔保持画的尺寸，穿过它的零件用 “收窄” 缩 0.5 mm，或者在同一轮廓切出的形状里做一层壁。宽度超过轮廓允许的范围就什么都不剩。在草图的描边面板里，这两个选项位于 “位置” 下。

“剪影（无孔）” 略过所有位于其他轮廓内部的轮廓：孔以及孔里的东西。只保留外侧轮廓。与 “描边在外” 一起就能做出饼干模具：把同一个 SVG 导入两次，一次用剪影作为底部的面，一次用剪影加外侧 1 到 2 mm 描边作为壁。在草图模式下，这个开关也在 “描边” 面板里。

实体重建时，边上的圆角和倒角会消失，与编辑草图时一样。

斜壁，用于印章

拉伸的草图是垂直的壁。印章、压花模或冲头需要斜壁，外侧和内侧都要，且壁厚处处相同。PrintCAD 的拉伸没有拔模角，但对于简单的轮廓，可以用 “锥度” 达到目的。一种可行的做法：

  1. 画出带所需孔的轮廓并生成实体。复制该实体（Ctrl+D）。
  2. 在第一个实体上打开 “剪影（无孔）”，让孔被填上，再用 “锥度” 让底部比顶部宽。
  3. 在副本上再次打开它的草图，删除外侧轮廓，只留下孔的轮廓。完成草图，把实体切换为 “孔”，再用 “锥度” 让底部比顶部窄。
  4. 把孔移到第一个实体中原来孔的位置，并将两者分组。

现在外侧和内侧的壁都倾斜了。锥变会缩放整个轮廓，所以对简单形状是精确的（可以选择尺寸让壁平行），对文字之类的细节只是近似。

用图片作模板

用 “添加图片” 把照片或图样放到草图下面，照着描。可以设置它的大小、不透明度和位置。图片放好后，用 Ctrl+L 锁定它，以免绘图时不小心移动。锁定的图片不会挡路：点击会穿过它，因此能选中它上面的线和点，也能在上面框选。点击它角上的锁形图标即可解锁；Alt+点击则选中它而不解锁。如果右边缘的设置挡住了图片，抓住标题栏把它们拖开；双击可重新停靠。

在 “对齐” 下，可以校准拍歪的照片：

  • “旋转”：绕图片中心旋转，可用四角外的弧形箭头，或输入以度计的数字。按住 Shift 时箭头按 15° 步距吸附。旋转时出现的圆环内按 22.5° 步距吸附，环外按整度。
  • “至 X = 0” 和 “至 Y = 0”：把图片中心放到 X = 0 或 Y = 0。对旋转来说，X = 0 就是轴，图片因此关于轴对称。
  • “校准”：按钮在顶部，紧挨预览图下方。在图片中点击距离已知的两点，比如尺子的两端或已知直径，然后键入实际距离。图片会等比缩放，使该距离正确；第一个点留在原处。
  • “裁剪”：框上的手柄此时裁剪图片而不是缩放；裁掉的部分仍被保存，可用 “显示完整图片” 或再次向外拉手柄恢复。

这四项都只影响参考图，绝不会影响草图。

8. 文字与弧形文字

用八种字体或你自己的字体创建凸起或凹刻的文字，还可以让它沿圆弧排列，例如硬币、盖子或戒指上的文字。

添加文字

在形状库中选择 “文字” 并放置。在右侧的 “文本” 字段中，输入要显示的内容。下方是各项设置：

  • “字体”： 提供八种字体：Multilanguage、Sans、Serif、Script、Monospace、Rounded、Stencil（用直线构成的字母）和 Japanese（Zen Maru Gothic）。新文字默认使用 Sans。每种字体都包含 ä、ö、ü、é 等带重音的字母和 € 符号，也包含假名、常用汉字以及姓名中许多生僻字，例如 澤、槇 和 檜：日文姓名在每种字体和名牌上都能正常显示。首次用到日文字符时才会下载（生僻汉字位于第二个文件，只有文字中用到时才下载），因此这类文字会短暂显示为问号。之后它们会保存在电脑上，从那时起日文离线也能使用。你自己的字体会显示在最上面，见下文你自己的字体。
  • “字母大小”： 从上方看字母的大小；“高度” 决定字母的厚度。
  • “高度”： 文字高出表面的距离。
  • “斜角”： 将字母边缘做成圆角，看起来更柔和。用 “分段” 决定分成多少段。
  • “字母边缘”： 对字母的顶边做圆角或倒角，就像名牌上那样：“无”、“圆角” 或 “倒角”，并设置 “边缘尺寸”（初始为 0.4 mm，最大不超过文字高度）。它比 “斜角” 影响更远，但只到笔画宽度允许的范围：当笔画比尺寸的两倍还窄时，边缘会终止于一个更窄的顶面。底面保持平整，因此单个字母可以之后再粘上去。选择边处理时，它会取代 “斜角”。
  • 尺寸： 与任何形状一样设置这一行的长度和宽度。拖动手柄或输入尺寸。
  • “字距（%）”： 在字体原有间距之上增加的字母间距，以字母大小的百分比表示：0 表示保持字体原本的间距，大于 0 时字母分得更开，小于 0 时（最低 -50）更紧凑，你自己的字体常常需要这样。字母大小不变，外框随这一行变化，直线文字和弧形文字都是如此。阿拉伯文和希伯来文的字母相互连写，不应用此间距。
  • “将字母拉伸到外框”： 初始为关闭：字母保持原有比例并位于外框中间，因此把外框拉得比文字所需更宽或更深时，外框会比字母大。开启后，字母会在两个方向上拉伸以填满整个外框：大写字母可以变矮或变窄，与 Tinkercad 中一样。它适用于直线文字；弧形文字有自己的字母大小。

文字最初是一个实体。如果想单独处理每个字母，点击 “分离部件”。之后每个字母都是独立的形状。

文字的边也可以倒角或加圆角，直线文字和弧形文字都可以，见断开边缘与抽壳实体。请使用 0.2 至 0.5 mm 这样的小尺寸，因为字母的笔画很窄。

你自己的字体

除了八种内置字体，你还可以使用任何自己的字体：电脑上的字体文件，或者在 Chrome 和 Edge 中直接使用电脑上已安装的字体。在 “字体” 底部选择 “你自己的字体…”，会打开 “你自己的字体” 窗口。

  • “选择字体文件…” 可接受 TrueType 文件（.ttf）、OpenType 文件（.otf）或 WOFF 文件（.woff）。也可以直接把文件拖进窗口。
  • 在 Windows 上，已安装的字体放在 Fonts 文件夹（C:\Windows\Fonts）中，浏览器的文件对话框会隐藏它。改为在资源管理器中打开该文件夹，把字体拖到 “你自己的字体” 窗口。仅为当前用户安装的字体位于 %LOCALAPPDATA%\Microsoft\Windows\Fonts，文件对话框会显示这个位置。在 Mac 上，字体位于 /Library/Fonts 和 ~/Library/Fonts。
  • “从电脑中选择字体…” 会列出电脑上已安装的字体。首次使用时，浏览器会询问是否允许 PrintCAD 读取这些字体。用搜索框可以快速找到字体，点击即可选用。

如果已选中文字，它会立即使用新字体。否则该字体会出现在 “字体” 下的 “你自己的字体” 分组中，窗口里的 “使用” 可将其应用到选中的文字上。自己的字体与内置字体的工作方式相同：弧形文字、边缘倒角和圆角以及 STEP 导出都照常可用。字体缺少的字母会从 Sans 中取用。

阿拉伯文与希伯来文

阿拉伯文、波斯文、乌尔都文和希伯来文从右向左书写：第一个字母在最右边；在“Name عربي”这样的混合文字中，只有阿拉伯文单词反向排列，数字保持正常方向。阿拉伯字母按书写规则与相邻字母连写，lam-alef 会形成连字。这需要包含这些字母的字体；内置字体没有。添加一种自己的字体，例如 Windows 上的 Arial、Tahoma 或 Segoe UI，或者 Noto Naskh Arabic、Noto Sans Arabic、Amiri 这样的免费字体。元音符号会落在所属的字母上。弧形文字、轮廓、剪影、分层和名牌都能像处理其他文字一样处理它。

网页不能随意读取已安装的字体。只有 Chrome 和 Edge 具备这项权限，而且仅限于安全页面，即通过 https 访问，例如 the public site。当 PrintCAD 通过 http 运行时，例如运行在你自己的服务器上或作为家庭网络中的 Docker 安装，“从电脑中选择字体…” 不会出现；这时请从资源管理器把字体拖过来。在其他浏览器中，从字体文件夹选择字体文件，效果相同。如果你在 Chrome 或 Edge 中拒绝了询问，可以在网站设置中重新允许，入口位于地址栏左侧的挂锁图标后面。

PrintCAD 无法读取 WOFF2 文件（几乎总能找到 TTF 或 OTF 版本）、字体集合（.ttc，一个文件里含多种字体）或彩色 emoji 字体。对于超大的字体，例如中文字体，PrintCAD 只取前 8000 个字符。可变字体会按其默认设置读取，通常是常规字重。

有些字体，尤其是手写体和可变字体，用相互重叠的笔画绘制字母。PrintCAD 在读取字体时会把它们合并成一个干净的轮廓，让实体保持可打印。这样得到的字母由许多很短的直线段而不是曲线构成；肉眼看不出来。

字体保存在哪里

你自己的字体保存在这台电脑的这个浏览器中。其他浏览器或其他电脑在你也添加之前不会知道它。清除浏览器的网站数据也会清除这些字体。在 “你自己的字体” 窗口中，垃圾桶图标会把字体从浏览器中移除。你的设计不会因此丢失任何东西，下一节会说明原因。

传递使用了自定义字体的设计

设计不会保存字体文件，只保存其文字所用字母的轮廓，历史记录中较早步骤里的文字也是如此。如果文字是“Hello”，随设计一起传递的只有 H、e、l 和 o。设计以任何方式保存都是如此：保存在浏览器中、你自己的服务器上、.lyl 文件中，以及 “自定义形状” 中。

因此：

  • 设计在任何地方都能正确打开，包括没有该字体的电脑。文字看起来一样，可以移动、旋转、缩放和加圆角。
  • 新字母需要字体。 如果使用者在没有该字体的情况下输入了设计未携带的字母，PrintCAD 会用 Sans 绘制它。此时在 “字体” 下，字体会标记为 “仅设计用到的字母”。添加字体文件后，所有字母都会恢复。
  • 导出内容只包含几何体。 STL、3MF、OBJ、STEP 和 SVG 只包含实体和轮廓，不含字体。
  • 较旧的 PrintCAD 版本尚不认识自定义字体，会用 Multilanguage 绘制这类文字。

许可： 字体受版权保护，其许可条款规定了你可以如何使用。PDF 文件从字体中携带的正是内嵌的字母轮廓，大多数许可允许这样做。但有些商业字体连传递单个字母都禁止。在传递或发布使用自定义字体的设计之前，请检查字体的许可。Google Fonts 等免费字体（大多采用 SIL Open Font License）可以放心传递。对于打印出来的零件或导出的 STL 则无所谓：它们不再包含字体，只有几何体。

凸起或凹刻

  • 凸起： 将文字放在表面上，并与实体分组。它会长出来形成浮雕。
  • 凹刻： 将文字切换为 “孔”，让它略微伸入表面，再与实体分组。字母就被刻进去了。

要在侧面放置文字，先把工作平面放到该面上，见视图与工作平面。

轮廓、剪影与加宽

文字不必做成实心字母。属性中的 “填充” 提供了与 Tinkercad 相同的选项：

  • “实心”： 字母保持原样。
  • “轮廓”： 沿字母轮廓画线，一半在内、一半在外。
  • “外轮廓线”： 沿字母外侧画线。
  • “内轮廓线”： 沿字母内侧画线。

选择线条后，列表正下方会出现两项设置：“线宽” 设置线条的粗细，“拐角” 设置线条如何绕过拐角（“圆角”、“斜角” 或 “尖角”）。较少用的设置位于 “更多” 下：“剪影（无孔）” 会略去 O、A 或 e 中的孔，“加宽（多色打印底座）” 让字母保持实心，并沿四周按线宽加粗；相互接触的字母会连成一体。

使用外侧线、居中线条或“加宽”时，文字的外框会变大，而字母大小保持不变。“斜角” 和 “分段” 仅适用于实心字母。

分层与名牌

用于多色打印的名牌是分层的文字：最上面是字母，下面是用第二种颜色、略宽一些的同样文字，最底层是第三种颜色、不带孔的底板。PrintCAD 一键即可生成：

  • 新建名牌： 在形状库中选择 “名牌” 并放置。它显示“Name”，白色字母配红色边框和深色底板。
  • 从文字生成： 选中文字，点击其设置顶部的 “生成分层”。

名牌的所有设置都在设置顶部的 “名牌” 卡片中：

  • “文本” 和 “字体”，也包括自己的字体。名牌会随文字增长。
  • “字母大小”： 大写字母的高度，单位为 mm。所有层都会跟随并保持对齐。
  • “分层”： 每层一行，从上到下排列。每行包含颜色（点击色块）、该层比字母宽出多少、高度以及 “无孔”（用于填平 O、A 等字母中的孔）。“角” 设置较宽的层如何绕过字母的拐角：“圆角”、“斜角” 或 “尖角”。最上面一行就是字母本身。+ 在底部添加一层，– 移除最底层。名牌可有两到六层。
  • “钥匙环孔”： 在底层加上一个末端为圆形的直舌片，并开一个钥匙圈孔；舌片会随孔一起变大。默认的 3 mm 孔会生成一个宽 6.5 mm、伸出 6.75 mm 的舌片，孔边缘距底层边缘 2 mm。选择 “孔径” 和 “侧边”：“左侧”、“右侧” 或 “顶部”。“自由” 会把孔从名牌上取下，在旁边放一个独立的 “钥匙环挂耳”，颜色和高度与底层相同：这是一个普通形状，你可以用手柄移动和旋转它到名牌需要的任何位置。放好之后，其面板中的 “固定到名牌” 会把它并入最近的名牌，并保持在当前位置：孔会穿过它到达的每一层，耳片并入底层，而且文字或尺寸变化时，两者都会保持在该字母的拐角处。“自由” 会把舌片重新放回原来的位置，以便再次移动。孔会穿过它接触的每一层，改变文字、字母大小或字体时舌片也会跟着移动。“沿侧边位置” 让舌片沿所在边上下移动（在顶边上则是左右移动），直到将要离开该边的位置；0 表示中间。当边的中点正好遇到空隙时（例如 J 旁边），可以用它把舌片移到字母伸出的部位。
  • “字母边缘”： 对顶层的字母顶边做圆角或倒角，就像打印出的名牌那样收边：“无”、“圆角” 或 “倒角”，并设置 “边缘尺寸”（初始为 0.4 mm，最大不超过层高）。它适用于所有字体和文字。该边是字母网格的一部分，因此边工具会把这样的文字当作网格处理，对如此精细的文字来说负担很重；请改为在这里选择边处理。

每次更改都会立即显示。名牌是一个捆绑体：它作为一个整体移动，而每一层仍是各自独立、各具颜色的实体，切片软件进行多色打印正需要如此。要对某一层的边做圆角或倒角，点击 “编辑捆绑” 并选择该层，见断开边缘与抽壳实体。

一次生成多个名牌

在 “姓名列表” 中输入姓名，每行一个，最多一百个。下方的按钮会显示将生成多少个名牌，例如“生成 12 个名牌”。每个名牌使用相同的层、字母大小和钥匙圈孔，并且是独立的对象；它们从第一个下方开始按行排列，间距 5 mm。普通文字在其设置靠下的位置也有姓名列表。

图标牌

图标牌是同样的名牌，只是用 SVG 图标代替字母：一颗心、一朵云、俱乐部的标志。最上面是图标，下面是用第二种颜色、略宽一些的相同轮廓，最底层是不带孔的底板。

  • 新建图标牌： 在形状库中选择 “图标牌”。会打开一个小窗口：点击 “浏览…”，选择 SVG、PNG 或 JPG 文件，检查图片，输入图标的 “宽度（mm）”，然后点击 “确定”。图标牌会立在平台中央，分层与新名牌相同。
  • 从草图实体生成： 导入的 SVG 或你自己绘制的草图，其设置顶部有 “生成分层”。

设置顶部的 “图标牌” 卡片包含：

  • “另一个文件…”： 用另一个文件（SVG、PNG 或 JPG）的图标替换到图标牌上；分层和宽度保持不变。
  • “宽度”： 顶部图标的宽度，单位为 mm。所有层都会跟随并保持对齐。
  • “分层”： 各行与名牌相同——颜色、宽出多少、“角”、高度和 “无孔”，以及 + 和 –，两到六层。最上面一行就是图标本身。
  • “钥匙环孔”： 与名牌相同：穿过每一层的钥匙圈孔，底层在图标之外有一个末端为圆形的舌片。“孔径” 和 “侧边” 选择它的大小和位置；“自由” 会生成独立的舌片，与名牌上一样。舌片是按图标轮廓生成的，因此对于轮廓非常参差的图标，请检查它与底板相接的位置。“沿侧边位置” 让舌片沿所在边移动，与名牌上相同。
  • “数量”： 想要多少个图标牌，1 到 100。“放得下多少就多少” 会根据设置中所选打印机的平台计算数量，小标志可以铺满一整个平台。下方的按钮会生成它们，间距 5 mm，以平台中央为中心排列；第一个就是图标牌本身。

SVG 需要闭合轮廓；只有开放线条的图形无法成为图标牌。填充为线条的草图实体会保留线条：线条围出的区域就是图标。

图片（PNG 或 JPG） 会被描摹成轮廓，预览中会显示该轮廓。在 “描摹依据” 下选择是 “深色部分” 还是 “浅色部分” 成为图标；初始为非背景的部分。透明像素永远不属于图标。只包含一张图片的 SVG（例如 Inkscape 保存导入的位图时）也以同样方式描摹。轮廓会跟随像素，因此小图片的边缘会比较粗糙：几百像素以上的图片效果最好。“另一个文件…” 会取图片中非背景的部分。

二维码

二维码把文字或网址变成手机摄像头可读取的图案：招牌上指向你店铺的链接、杯垫上的 Wi-Fi 名称、钥匙牌上的电话号码。

在形状库中选择 “二维码”。会打开一个窗口，光标已经在文本字段中：

  • “文字或网址”： 二维码的内容。Enter 生成二维码，Shift+Enter 换行。字段下方会显示已用掉多少容量；变音符号和其他特殊字母占两个字节。文字过长时，字段会给出提示。
  • “纠错级别”： L、M、Q 或 H。级别越高，二维码局部弄脏或刮花时仍可读取（L 约 7 %，M 15 %，Q 25 %，H 30 %），但同样的文字需要更多模块，因此每个模块会更小。初始选择 M。
  • “构建方式”： “仅二维码” 只生成二维码本身，高 4 mm。“在底板上凸起” 把它以 1 mm 的高度放在 3 mm 厚的白色底板上，作为双色捆绑体，这样多色打印会把二维码印成深色、底板印成浅色。“雕刻” 把二维码刻入底板 1 mm 深。
  • “尺寸依据”： 输入整个二维码的 “宽度”（初始为 40 mm）或单个模块的尺寸；另一个数值会显示在下方。模块小于 0.8 mm 时会给出警告。这只是针对 0.4 mm 喷嘴的经验法则，并非保证：打印机、材料、颜色和手机都会有影响。
  • “静区（4 个模块）”： 扫描器需要二维码四周有一圈四个模块宽的空边。在底板上，这圈空边是底板的一部分；只有底板放在更大的浅色表面上时才可关闭。单独的二维码自身没有空边：请在其四周留出空间。
  • 高度： 二维码的高度，或者在底板上为二维码高度或雕刻深度，以及底板厚度。

预览会显示二维码构建后的样子。“确定” 会把它放到平台中央。

二维码与其他实体一样：移动、旋转、缩放（保持宽度和深度相同，否则二维码会被拉伸）、分组，或者把它设为孔并与你自己的零件分组，从而在那里刻出二维码。缩放会缩放整个二维码；每个模块始终保持正方形。

设置顶部的 “二维码” 卡片中保存着文本。修改后点击 “重新生成”：二维码会在原处重新生成，宽度保持当前值。纠错级别、空边和构建方式保持原先的选择；如需其他选择，请从形状库新建二维码。

打印前用手机扫描一次，打印后再扫描一次。深色配浅色最易读取；深色底板上的浅色二维码并非所有手机都能读取。

弧形文字

文字不一定非要排成直线，也可以沿硬币、盖子或戒指的边缘排列。为此提供了 “沿圆弧” 设置。

开启后，文字会沿圆周排列。所有字母都立在同一条基线上，与普通文字一样均匀。共有四项设置：

  • “圆弧半径”（5 至 500 mm）：字母基线所在圆的半径。
  • “字母大小”： 字母的高度。它不再取决于形状的宽度。
  • “沿底部”： 把文字从圆的顶部移到圆的底部。此时字母的顶部朝向圆心。
  • “上下翻转”： 只把字母翻转过来，让你可以从另一侧阅读。文字在圆上的位置不变。

圆心就是形状的中心。 因此对齐照常有效：如果把文字与圆柱体或圆环居中对齐，它会正好同心。拉动手柄时，半径和字母大小一起增大，因此文字不会变形。

提示： 在圆的顶部，字母立在基线外侧；使用 “沿底部” 时它们立在基线内侧，顶部朝向圆心。要让文字正好落在圆盘上，半径加上字母大小应小于圆盘的半径。

9. 螺纹、齿轮和其他零件

相互配合的螺钉、螺母与螺纹孔，以及齿轮、弹簧、弯管、燕尾、泪滴孔、沉孔和锥形沉孔。

除了基本形状，形状库里还有一些自己拼起来会很麻烦的零件。它们之后都可以在设置中修改。

螺纹

在形状库中选择 “螺纹”。在 “类型” 下决定它的类型：

  • “螺纹杆”： 带螺纹的圆柱体，例如没有头的螺钉。
  • “螺钉”： 带头部。你可以选择 “头部”：“内六角头”、“沉头” 或 “六角头”。
  • “螺母”： 配套的螺母。
  • “螺纹孔”： 螺纹孔。它属于孔。把它拖进零件，将两者分组，零件就有内螺纹。

在 “规格” 下从列表中选择规格：公制从 M2 到 M24，英制 UNC 和 UNF 从 No. 4 到 1 英寸，以及管螺纹 G1/16 到 G4。如果选择 “自定义”，就自行设置 “直径” 和 “螺距”。对于英制或 G 规格，该字段要求填写 “每英寸牙数”，而不是以毫米计的螺距。

列表按系列对规格分组，字段下方的一行会给出所选规格的系列，并附上日常生活中熟悉的例子：

  • M，公制粗牙： 符合 ISO 261 的 ISO 公制粗牙螺纹，与标准螺钉和螺母相同。
  • UNC，美制英寸粗牙： 相机和三脚架螺钉为 1/4"-20 UNC（ISO 1222），较大的三脚架云台使用 3/8"-16 UNC。
  • UNF，美制英寸细牙： 与 UNC 相同的直径，螺距更细（ASME B1.1）。
  • G，管螺纹： 淋浴软管用 G1/2 连接，洗衣机进水管用 G3/4。花园水龙头末端为 G3/4，较小的水龙头为 G1/2；快接软管系统的水龙头接头就拧在这里。

G 规格是符合 ISO 228-1 的平行惠氏管螺纹，常见于水、燃气、液压和气动接头。规格指的是管子，而不是螺纹：G1 在螺纹处测得 33.249 mm。选择 G 规格会把牙型设为 “惠氏螺纹（55°）”，选择公制或英制规格则设回 “V 形螺纹（ISO）”。自己选定的 “梯形” 或 “圆形” 牙型会保留。标准只定义螺纹，所以 G 规格的螺钉头和螺母会得到与你自行设置直径时相同的比例。锥形管螺纹 R、Rc 和 Rp 不包括在内。

更多设置：

  • “方向”： “右旋” 或 “左旋”。
  • “牙型”： “V 形螺纹（ISO）” 是公制和英制螺纹的标准牙型，“惠氏螺纹（55°）” 是 G 管螺纹的牙型：55°，牙顶和牙底为圆角。“梯形” 和 “圆形” 的牙顶和牙底是平的。这种牙型通常打印更可靠，因为不会产生细薄的牙尖。
  • “自定义（梯形）”： 自行塑造的梯形，带有等宽的平牙顶和平牙底。“牙侧角” 是一颗牙两个牙侧之间的夹角：60° 是尖锐的 V 形螺纹，30° 是梯形螺纹；在 90° 或更小时，任何牙侧都不会比 45° 更平，因此螺纹无需支撑即可打印。“螺纹深度” 和 “芯径” 是同一个尺寸的两种说法：芯径等于直径减去两倍深度，改动其中一个就会改变另一个。新的自定义牙型从 60° 的 V 形螺纹深度开始。深度有限制，取决于角度和螺距：不得浅于螺距的十分之一，不得深于直径的 40%，也不得深到两个牙侧占据超过十分之九的螺距。如果改变螺距，深度按比例跟随；如果缩放螺纹，深度也同样跟随。间隙和倒角的作用与其他牙型相同。通过 MCP 桥接时，牙型为 custom，并带 threadFlankAngle 和 threadDepth。
  • “间隙（XY）”： 对于螺母和螺纹孔，这是确保打印出的一对零件真能转动起来的余量。打印机越粗，这一对需要的间隙越大。它是整个直径上的额外余量，而 V 形螺纹牙侧之间的缝隙大约只有它的一半，所以打印件需要比想象中更大的值：新螺母从 0.4 mm 开始，0.3 偏紧，0.5 偏松。先打印一对测试件。螺纹杆和螺钉在这里有自己的间隙，会让螺栓的直径相应变细。它设为 0。余量加在哪一侧取决于你如何配对：
  • 打印的螺钉配打印的螺母： 螺钉保持 0，把余量给螺母（它初始的 0.4 mm）。
  • 真实螺钉配打印螺母或螺纹孔： 打印的一侧承担全部余量，所以螺母保留 0.4 mm。如果螺钉晃动，值得试试更紧的 0.3 mm。
  • 打印的螺钉配真实螺母： 真实螺母没有间隙，所以螺钉必须更细：这里用 0.3 到 0.4 mm，与打印螺母本来会有的量相当。
  • “沿轴向（Z）的活动量”： 对于螺母和螺纹孔，这是在 “间隙（XY）” 之外沿轴向的活动量。螺母的每颗牙都会变薄这么多，直径保持不变。原因在于：“间隙（XY）” 只作用于直径，把 V 形螺纹的牙侧张开到其数值的约 0.58 倍。想要牙侧之间留出空隙的人只能把直径开大，代价是左右晃动。沿轴向的活动量把两者分开。它设为 0，所以已保存的螺纹不会改变；最大可到螺距的五分之一，因为超过这个值螺母的牙就不剩什么了。该字段只对螺母和螺纹孔存在；螺纹杆和螺钉保留自己的间隙。更多内容见下文“3D 打印用的螺纹”。
  • “倒角，顶端”、“倒角，底端”、“头部倒角” 和 “边缘倒角”： 两端的倒角，让螺纹起始干净，头部没有锐边。螺纹杆、螺母或螺纹孔的每一端都有自己的倒角，所以顶端可以长、底端可以短或没有。螺钉只在尖端有一个，标为 “倒角”。在螺母或螺纹孔上，倒角是孔口超出外径的扩张量；锥面以 45 度一直延伸到螺纹芯部，因此外径处不会留下台阶。

在 “螺纹杆” 和 “螺纹孔” 之间切换螺纹会保留其长度。螺母和螺钉则从各自的标准尺寸开始。

  • “质量”： 螺纹计算的精细程度。越高越精确，但越慢。

打印螺纹是另一个话题。在打印大零件之前，先做一对螺钉和螺母作为测试，并根据你的打印机调整间隙。

3D 打印用的螺纹

打印出的螺纹需要在两处留出空隙，它们的作用不同：

  • 直径上的间隙（“间隙（XY）”）： 让螺母变宽。于是螺钉每侧有该值一半的空隙，0.4 mm 时每侧 0.2 mm。螺纹转动轻松，但螺钉会左右晃动。
  • 沿轴向的活动量（“沿轴向（Z）的活动量”）： 让螺母的牙变薄。螺钉在未拧紧时可以沿轴向前后移动这个量。它不会额外增加侧向的空隙。

两者合起来形成牙侧之间的缝隙：约为直径间隙的 0.58 倍再加上沿轴向的活动量。以 0.3 mm 的缝隙为例：以前需要在直径上留 0.5 mm，也就是每侧 0.25 mm 的空隙。现在直径上 0.2 mm（每侧 0.1 mm）加上轴向 0.2 mm 就够了，缝隙为 0.32 mm。

需要知道的后果

  • 螺钉沿轴向有活动量。 没有负载时，它可以前后移动这个量。对于紧固件、盖子和外壳，这无所谓；对于需要精确定位的丝杠就有影响，所以那里要留小或设为 0。
  • 螺母的牙会变薄。 在 1.75 mm 螺距下取 0.3 mm，每颗牙在中间几乎薄了三分之一，强度明显下降。重载零件请改用更粗的螺纹。
  • 计算量更大。 牙形会增加额外的点，所以螺纹的三角形更多，计算稍慢。
  • 惠氏牙型在 STEP 导出中没有真正的圆弧。 带轴向活动量的 “惠氏螺纹（55°）” 螺纹，在边缘工具和 STEP 导出中会变成由直线段拼成的牙形，而不是真正的圆弧。设为 0 时一切保持原样。

提示

  1. 先做一对测试件。 一个螺钉和一个螺母，各只有 4 到 6 mm 高，几分钟就能打完。并排打印三对活动量不同的零件，挑出转动轻松且不晃动的那一对。
  2. 从常用的数值开始。 直径间隙 0.2 到 0.3 mm，沿轴向活动量 0.2 mm。如果螺钉左右晃动，减小直径间隙；如果卡住，增大沿轴向活动量。如果不想用沿轴向活动量，就照旧在直径上取 0.4 mm。
  3. 沿轴向的活动量应至少为一个层高。 低于一层的量打印机无法分辨。层高 0.2 mm 时，0.2 mm 是不错的起点；层高 0.1 mm 时，少一些就够。
  4. 竖直打印螺钉和螺母。 轴线朝上，每一圈都落在完整的层里，牙侧才会干净。平放时牙侧会下垂。
  5. 细螺距很难。 螺距低于约 1 mm 时，螺纹圈常常粘在一起。较粗的螺纹，或牙顶平的 “梯形” 牙型，比细 V 形螺纹打印更可靠。
  6. 避免细薄的牙尖。 V 形螺纹的牙尖很窄，打印机的喷嘴宽度几乎覆盖不到。“梯形” 和 “圆形” 牙型的牙更平。
  7. 去毛刺并磨合。 最初的几圈常常发涩，因为牙侧上残留着打印的小凸起。来回转几次就会顺畅。起始处的倒角有助于拧入。
  8. 换了打印机或耗材。 活动量取决于打印机、材料和喷嘴。更换其中任何一个后，请重新打印测试件。

边缘工具会把螺纹当作精确实体。你可以在螺纹已就位的情况下，对承载它的零件倒角或圆角，也可以处理螺钉头的边缘，参见断开边与抽壳。计算螺纹的边需要一些时间：M6 几秒钟，G1/2 管螺纹约半分钟。给螺钉头断边最快的方法仍然是属性里的头部倒角。

齿轮

“齿轮” 有 “直齿轮”、“斜齿轮”、“人字齿轮” 和 “锥齿轮”，还有 “内齿圈” 和 “齿条”（见下文）。新齿轮在 “齿形” 下为 “渐开线”：带有渐开线牙侧的齿，与齿轮生成器和工程中的用法一致。这样的齿能彼此平顺地滚动。你设置 “齿数” 的齿数（6 到 500）和 “模数（mm）”，尺寸随之确定：外径为模数 ×（齿数 + 2），分度圆为模数 × 齿数。新齿轮从模数 2 开始。两个齿轮啮合的条件是模数相同、“压力角” 相同（通常为 20°），并且中心距为（齿数 + 齿数）× 模数 / 2。同时选中两个齿轮，属性面板会给出该中心距以及当前的中心距。如果齿轮应保持在原位，它还会给出使它们在此处啮合的模数，“适配两者的模数” 一步即可让两个齿轮都采用该模数；每个齿轮的齿数、高度和中心孔保持不变。如果此时一齿对着另一齿而不是齿槽，就把其中一个齿轮转半个齿，即 180° 除以其齿数。“齿隙” 会从齿上削去一点，避免打印出的一对零件卡死。该值针对这一对齿轮，每个齿轮承担一半；0.2 mm 是不错的起点，0 则得到精确的齿轮。在基圆以下，牙侧笔直向下延伸到齿根，不像刀具加工那样有根切。这适合打印，但齿数低于约 17 的很小齿轮可能会在齿根处轻微摩擦。

斜齿轮增加了 “螺旋角”。使用渐开线齿时，它是分度圆上的真实螺旋角：两个斜齿轮啮合的条件是模数相同、角度相同，一个为正、一个为负。“人字齿轮” 是两半旋向相反的斜齿轮：齿沿一个方向延伸到一半高度，然后反向回来，像箭头一样。这对 3D 打印有两个好处：齿轮会在轴上自行对中，而且没有轴向推力，因为两半的力相互抵消。相比之下，斜齿轮会沿其轴线向侧面推。你像设置斜齿轮那样设置 “螺旋角” 和 “螺旋质量”；角度对每一半都适用。两个人字齿轮啮合的条件是模数相同、角度相同且符号相反，一个为正、一个为负。中间没有铣削人字齿轮那样的退刀槽：两半无台阶地相接。边缘工具和 STEP 导出把人字齿轮当作三角形网格，而不是精确实体。

锥齿轮采用渐开线齿，并让齿向顶部逐渐变小。这是一种近似，不是精确计算出的锥齿轮副。

“圆弧” 是由圆弧构成的圆形齿，类似 Tinkercad 的 Useful gear：齿顶与齿槽无棱角地相接。小齿轮这样打印更宽容，转动也更轻松，在旋钮上齿还能带来舒适的握感。圆齿同样由 “齿数”、“模数（mm）” 和 “齿隙” 设定；它们没有压力角。它们比渐开线齿矮，所以外径为模数 ×（齿数 + 1.2）。相同模数的圆齿齿轮可以啮合，中心距与渐开线齿轮相同；与渐开线齿轮则配不上。

“简单” 是目前所有齿轮都用的直齿。在那里手动设置 “齿尺寸” 和 “齿宽”。旧设计会一直保留它们，直到你更改齿形。三种齿形都有 “中心孔”。

“内齿圈” 的齿朝内：一个较小的齿轮在其中运行的外齿圈，就像行星齿轮组的外轮。它像渐开线或圆齿齿轮那样通过 “齿数”、“模数（mm）” 和 “齿隙” 设置，另外还有 “轮缘”，即齿外侧的轮缘。其外径为模数 ×（齿数 + 2.5）加上两倍轮缘；圆齿则为模数 ×（齿数 + 1.7）。相同模数的齿轮在其中运行的条件是，其中心距齿圈中心（齿圈齿数 − 其齿数）× 模数 / 2；同时选中两者，属性面板会给出该距离。对于行星齿轮组，齿圈齿数 = 太阳轮齿数 + 2 × 行星轮齿数，例如 30 = 12 + 2 × 9。齿圈没有中心孔，它本身就是环。齿数在 26 到 33 之间时，其齿顶最多短四分之一个模数，因为否则会在基圆处形成极小的棱边；啮合不受影响。

“齿条” 是半径无穷大的齿轮：一根沿一侧带齿的条，使用渐开线齿时牙侧是压力角下的直线。其宽度（沿 X）为齿数 × 齿距，齿距为 π × 模数，所以同一模数的齿条可以首尾相接，每一端都落在齿槽里。其长度（沿 Y）是条的厚度，可自由设置，只要齿和半毫米的条能放得下。齿朝前，即朝向主视图的观察者；根据需要转动齿条。相同模数的齿轮在其上滚动的条件是，其中心位于节线前方齿数 × 模数 / 2 处；节线在齿顶后方一个模数处，圆齿则为 0.6 个模数。齿圈和齿条有渐开线和圆齿两种，没有简单齿；切换齿轮类型会保留模数。

边缘工具和 STEP 导出把每个齿轮当作其精确实体，渐开线牙侧是平滑曲线。椭圆形轮廓上的斜齿轮仍是三角形网格，从约 31 齿起的渐开线斜齿轮也是如此。小齿限制了边能圆角到什么程度：对于简单齿的齿轮，直径 30 mm、12 齿时，两齿之间齿根处的平面只有约 0.65 mm 宽，所以给每条边倒圆最多到约 0.5 mm；锥齿轮顶部更小，最多约 0.4 mm。斜齿轮的齿是倾斜的，这会在其斜边上收窄那个平面：螺旋角相对于齿轮高度越大，能容纳的圆角越小。两个平端面的边可以倒圆，但只给这些边倒角会在 CAD 内核中失败；请改为倒圆，或以更小的尺寸（例如 0.2 mm）给所有边一起倒角。

弹簧

“弹簧” 有 “圈数” 和 “线径”。它们与高度一起决定弹簧的软硬。“旋向” 决定线材的走向：“右旋” 像常见的压簧，或 “左旋”。

边缘工具和 STEP 导出把弹簧当作其精确实体：沿螺旋线的圆线材，两端切平。例如，你可以给这两个线材端头倒圆或倒角。

弯管

一个 “弯管” 最多由十二段组成：一段直管，接着一个弯。每一段你设置 “直段长度”、“弯曲角度”、“弯曲半径” 和 “滚转角”。正在编辑的段会在管上以橙色高亮，方便你跟上顺序。滚转角为 0° 时在工作平面内弯曲，90° 时管子向上弯。轮廓可以是圆形、方形、六边形或八边形，内部同样如此，也可以完全实心。如果管子撞到自己，PrintCAD 会提醒你。

放样

“放样” 把底部的一个轮廓与顶部另一个轮廓连接起来，就像 Fusion 里的放样：从一种直径到另一种直径的软管接头、把方形风扇接到圆管上、向上逐渐变圆的支架。每一端你选择 “底部轮廓” 和 “顶部轮廓”：“圆 / 椭圆”、带 “底部圆角半径” 的 “矩形”，或带角数的 “多边形”，再加上每一端的宽度、长度和高度。“顶部宽度方向偏移” 和 “顶部长度方向偏移” 把顶端向侧面移动，形成倾斜过渡；底端保持在原处。

“壁厚（0 = 实心）” 把实体变成上下开口的管。两端开口的横向尺寸都比外形小一个壁厚；壁倾斜处会略薄一些。把框架拖大，两端也随之扩大，而圆角半径和壁厚保持不变。

“平滑过渡（%）” 让过渡变得平滑。为 0 时，侧面从底部到顶部笔直延伸，像圆锥一样。为 100 时，两侧从两端笔直出发，在中间沿 S 曲线改变尺寸：软管接头从窄管平滑地扩到宽管，而不是像漏斗那样直斜。中间的数值在两者之间混合。平滑过渡可与 “壁厚（0 = 实心）”、扭转、倾斜和侧向偏移一起使用；带壁的管两端仍保持开口。它和直边放样一样是精确实体，所以其边可以倒角和倒圆，但它由多个截面构成，计算会稍慢。

“扭转” 在上升过程中让截面绕竖直轴均匀旋转，任一方向最多 360°；侧面于是盘旋而上。“顶部倾斜，前/后” 和 “顶部倾斜，左/右” 让顶端倾斜，最多 45°：正值会抬高其前缘或右侧。中间的截面按各自份额倾斜，所以壁面平滑地过渡到斜面上。最高点保持在设定高度。如果之后高度变得太小，使倾斜端会伸到平台以下，倾斜会退让到刚好放得下。沿路径弯曲（例如管道弯头）不是放样能做的。

放样是精确实体，扭转和倾斜后也是：其边可以倒角和倒圆，STEP 导出会保留它。照常添加带螺钉孔的法兰，然后分组。

Gridfinity

“Gridfinity” 形状用来制作 Zack Freedman 的开放式收纳系统的零件：42 mm 网格上的收纳盒，放在底板里，并且可以彼此堆叠。尺寸遵循已发布的 Gridfinity 规范，所以 PrintCAD 做的收纳盒能装进其他生成器做的底板，反之亦然。在 “类型” 下选择：

  • “收纳盒”： 每个网格单元下方都有支脚的收纳盒。“横向单元数” 和 “纵向单元数” 按 42 mm 的网格单元计数（收纳盒小 0.5 mm，一个单元为 41.5 mm）；“高度单元数” 按 7 mm 的高度单元计数，最多 20。壁顶的 “堆叠卡边” 托住下一个收纳盒的支脚，并使收纳盒增高 4.4 mm：3 单元带卡边的收纳盒高 25.4 mm。启用 “磁铁孔” 后，每个支脚的每个角都会得到一个用于 6 × 2 mm 磁铁的孔。
  • “底板”： 收纳盒所站的底板，高 5 mm，每个网格单元有一个插槽。它是没有底面、没有磁铁孔的开放框架。
  • “托盘”： 任意尺寸的平底托盘，用于桌游收纳和不需要网格的零件。“长度”、“宽度” 和 “高度” 可以自由设置（mm）：长宽 10 到 252 mm，高 3 到 140 mm。它没有底脚、堆叠卡边和磁铁孔，因此不能放进底板，也不能堆叠；它的四角与收纳盒一样，按 3.75 mm 半径倒圆。下文关于收纳盒内部的内容同样适用于托盘：底面厚 1.2 mm，可以设置；隔板和标签台一直延伸到顶部；它们和取物口在任何留有空间的高度都可以使用；隔间数量以每个至少 6 mm 宽为限，每边最多 24 个，总共最多 40 个。收纳盒改为托盘时保持尺寸，底板改为托盘时高 20 mm，托盘改回收纳盒或底板时取整到整网格单元；在 “工作区设置” 的 “形状默认值” 中把类型设为 “托盘” 时，新托盘起始为宽 80 mm、长 40 mm、高 20 mm。

收纳盒和底板的尺寸始终是整数网格单元（或下文半尺寸网格的 21 mm 单元），最大 6 × 6（252 mm，适合 256 mm 的打印床）；拖动手柄会吸附到最近的单元。壁厚（0.95 mm）、底面（1.2 mm）和磁铁孔深度（2.4 mm）不在规范中；孔深固定，壁厚可以设置，底面可以抬高（见下文）。规范中的 M3 螺钉孔不会做出。卡边顶部是尖的，与规范画法一致；如果你的打印机打出来有毛边，用边缘工具倒圆或倒角。收纳盒、底板和托盘是精确实体，所以圆角、倒角和 STEP 导出都能用。要给收纳盒分格，把薄长方体作为隔墙分组进去：让它们立在底面上，即高 5.95 mm 处（或抬高的底面上），对于带卡边的收纳盒，顶部至少保持在每个高度单元 7 mm 下方 0.5 mm 处，从收纳盒底面量起（3 单元为 20.5 mm），因为下一个收纳盒的支脚会向下伸入收纳盒 0.35 mm。打印收纳盒和底板时无需支撑，按它们在打印床上的姿态直立打印。

收纳盒也可以做在半尺寸网格上：开启 “半尺寸网格（21 mm）”，此时 “横向单元数” 和 “纵向单元数” 按 21 mm 的单元计数，最多 12（与 6 单元相同的 251.5 mm）。每个单元都有自己的支脚，顶部宽 20.5 mm，带有规范中的台阶，四个这样的支脚站在普通底板的一个插槽里，所以 1½ 或 2½ 单元的收纳盒能与整数单元的并排使用。开启 “半尺寸网格（21 mm）” 时收纳盒保持其轮廓（2 单元变成 4 个单元）；关闭时，奇数个单元会向上取整为整数单元。卡边照旧跟随收纳盒的轮廓。启用 “磁铁孔” 后，每个支脚得到一个孔，从其中点向位于 42 mm 网格上的那个单元角偏移两个方向各 2.5 mm，从收纳盒左后角算起：当该角位于网格的一个角上时，这些孔会与其他生成器做的带磁铁底板的孔对齐；奇数单元的收纳盒还可以转 180°，让这个角位于右前方的网格角上。底板仍保持 42 mm 网格。半尺寸网格不属于规范。

高度为 3 个单元或以上的收纳盒可以沿内壁设置标签台：以任意组合开启 “后侧标签台”、“前侧标签台”、“左侧标签台” 或 “右侧标签台”。每个开启的标签台都有自己的 “标签台宽度”、“标签台长度”，较短的标签台还有 “标签台位置”；它们下方的拐角设置适用于所有标签台。标签台顶部平整，可贴标签，前部有 1.2 mm 的下垂条，底面以 36 度上升。其顶部位于每个高度单元 7 mm 下方 0.85 mm 处，从收纳盒底面量起（3 单元为 20.15 mm），所以堆叠在卡边上的收纳盒支脚与其保持 0.5 mm 的间隙。低于 3 单元的收纳盒不显示标签台；回到 3 单元时它们会恢复。标签台不属于规范。

“标签台宽度” 是标签台伸入收纳盒的深度：14 mm，3 单元的收纳盒中最多 17.2 mm（抬高底面时更少），在 1 单元深、2 mm 拐角的收纳盒中两个相对的标签台为 16.8 mm。“标签台长度” 为 0 时，标签台从一面墙延伸到另一面墙。较短的标签台（至少 10 mm）会显示 “标签台位置”，把它从所在墙的中间移开：在主视图所示的后墙和前墙上向右移，在侧墙上向前移。如果一端距墙在 1 mm 以内（带堆叠卡边时为 1.8 mm，因为卡边的支撑在那里向内倾斜），或者停在该墙的标签台上，就会继续延伸进去，两个在拐角相遇的标签台会合为一个。当标签台与墙或另一个标签台相接且有余地时，拐角会倒圆或倒角：在 “标签台拐角” 下选择 “圆角” 或 “倒角”，并用 “拐角尺寸” 设置尺寸（2 mm；0 保持尖锐）。选择 “圆角” 时，较短标签台自由端的前角也会倒圆，尺寸相同，但最多为标签台宽度的一半。

收纳盒还可以沿任意内壁设置取物口，让细小零件能沿曲面被推出，而不必在底面与墙相接处抠出来：以任意组合开启 “后侧取物口”、“前侧取物口”、“左侧取物口” 或 “右侧取物口”。底面沿四分之一圆升入墙内，从一面墙延伸到另一面墙，相邻墙上的两个取物口在拐角处相接。带取物口的收纳盒，其每条底面边也会按 2.8 mm（内角半径）倒圆，取物口就是所在墙上这处圆角的放大。一旦开启取物口，开关下方会出现 “取物口半径”，并作用于所有取物口：在你设置之前，它是从底面到卡边支撑离开墙面处这段高度的一半，即每个高度单元 7 mm 下方 1.65 mm 处，从收纳盒底面量起（带卡边的 3 单元收纳盒为 6.7 mm，抬高底面时更少）；没有卡边的收纳盒则一直到顶部。它至少为 3.5 mm，并至少比该高度小 0.5 mm，在收纳盒横向至少留下 2 mm 的底面，无论是两个相对的取物口之间，还是取物口与其对面的墙之间。1 单元高的收纳盒没有空间做取物口，也不显示相关开关；到 2 单元时会恢复。取物口同样不属于规范。

收纳盒还可以有抬高的底面，作为可切出形状的实心坯料：“底部高度” 设置底面的高度，从收纳盒底面量起（在你设置之前为 5.95 mm，即支脚上的 1.2 mm 底面），收纳盒到该高度为止都是实心。带卡边时，它最多升到卡边支撑离开墙面处，即每个高度单元 7 mm 下方 1.65 mm（3 单元为 19.35 mm），这样卡边保持完整，堆叠其上的收纳盒支脚保持 1.3 mm 的间隙；没有卡边时，它可升到顶部，收纳盒成为一个实心块。把工具形状的孔分组进去，深度随你需要。取物口从抬高的底面开始，标签台伸入收纳盒的深度会减小，使其底面仍止于底面之上；一旦底面让它们没有空间，相关开关就会消失（带卡边的 3 单元收纳盒中，取物口在高于 15.35 mm 时消失，标签台在高于 15.54 mm 时消失），降低底面后又会恢复。带卡边、壁厚不超过 1.6 mm 的 1 单元高收纳盒没有空间抬高底面，也不显示该字段。抬高底面同样不属于规范。

收纳盒还可以分成隔间，而无需把隔墙分组进去：在 “隔间” 下，就在 “属性” 下方，“列数” 和 “行数” 设置数量，每个方向每个网格单元最多 4 个（半尺寸网格的每个单元 2 个），总共最多 40 个。隔板贯穿整个高度，从底面（或抬高的底面）一直到每个高度单元 7 mm 下方 0.85 mm 处，标签台也止于那里，所以堆叠在卡边上的收纳盒照常安放。隔板要求收纳盒至少有 2 个高度单元，且底面至少低于其顶部 3 mm；空间不足时收纳盒会在没有隔板的情况下构建，等又有空间时它们会恢复。“隔板厚度” 在设置前为 1.2 mm，范围为 0.8 到 3 mm。隔板初始均匀分布。要移动某一块，在 “列之间” 或 “行之间” 下选择它（从左或从后计数），并设置其 “位置”，从左墙或后墙内侧量到隔板中间；每个隔间至少保持 6 mm 宽。一旦移动过隔板，调整收纳盒尺寸时，该方向的隔板会以毫米为单位保持位置；重新设置隔间数量会让该方向的隔板再次均匀分布。每个隔间都有收纳盒的内角，按 2.8 mm 倒圆，其底面边也按 2.8 mm 倒圆，无论有没有取物口。取物口会在每个隔间重复：后墙上有取物口时，每个隔间的后侧都有一个，靠着墙或隔板。在狭窄的隔间里，半径会减小，以保留 2 mm 的平整底面；如果隔间窄到连 3.5 mm 都放不下，该方向的取物口就会消失；“取物口半径” 下方的提示会说明。隔板同样不属于规范。

带隔板的收纳盒可以在每个隔间里设置标签台，而不是沿墙的标签台：沿墙的标签台是给没有隔间的收纳盒用的，当收纳盒重新变成一个隔间时，它们的开关会恢复。在高度为 3 个单元或以上的收纳盒中，用 “行” 和 “列” 选择一个隔间（各自在多于一个时显示），并在 “标签台” 下选择其标签台所靠的一侧，即收纳盒的墙或某块隔板；只有当该侧的标签台仍能让隔间保持开口时，才会提供这一侧。“标签台长度（%）” 的范围是 10 到 100；如果标签台会短于 4 mm，就不做，并在其下方提示说明。较短的标签台会显示 “标签台位置”：在后侧或前侧时为 “左”、“居中” 或 “右”，在左侧或右侧时为 “后”、“居中” 或 “前”。“标签台宽度” 在设置前为 14 mm，在狭窄隔间中更小，而且标签台绝不会伸到把隔间封死：其前方至少保持 6 mm 开口。这些标签台的剖面与沿墙的标签台相同，“属性” 下的 “标签台拐角” 和 “拐角尺寸” 也适用于它们。

铰链

“铰链” 一次打印成型，之后可以活动（打印即组装）：两片叶片平摊在平台上，中间沿一根轴交替排列铰链节。销属于后片，并带间隙穿过前片的铰链节。你设置 “长度（轴向）”、“展开宽度” 和 “铰链节直径”，还有 “铰链节数” 的数量（奇数，这样销两端都被固定）、“销直径” 和 “叶片厚度”。

“间隙” 是活动部件之间的间隙：销周围、铰链节之间以及叶片前方。0.4 mm 时，调校良好的打印机通常轻轻一扭就能松开；如果部件粘在一起，就加大；如果晃得太厉害，就减小。按平台上的姿态平放打印铰链，不要支撑。如果你更想用自己的销，例如一段耗材或铁丝，在小铰链上它比打印的销更光滑，就开启 “无销（使用自备销）”：打印的销被略去，孔径等于销直径加间隙，贯穿每个铰链节，包括两端。用 “开合角度” 你让第二片绕销折起，把铰链摆成设计中的姿态：0° 平躺如打印时，180° 为闭合。铰链节保持原位，铰链仍是一体；在就地打印前记得设回 0°。你可以给叶片加孔，或把它们分组进更大的零件，例如盖子。

铰链也可以做成“带圆锥”（在“样式”下）：每隔一个关节的两端是圆锥，嵌入相邻关节的锥形凹坑。没有销，也没有可能下垂的长悬空桥，所以可以平放打印；圆锥为 45°。它是网格，因此倒角和圆角对它无效，STEP 导出包含的是三角形；关节对圆锥来说太短时，会做得更少。除了关节数量，也可以指定“关节宽度（最大）”：关节不会比它更宽，数量由长度决定；输入关节数量会取消宽度。

“样式”有三个选项：“带销”、“无销（使用自备销）”（为自备销留的孔）和“带圆锥”。选圆锥时，“圆锥直径”决定圆锥从关节长出处的大小；圆锥越大越牢固，默认取能放下的最大值。带圆锥的铰链没有销也没有孔，所以它的翼板可以和整个关节一样厚：把“叶片厚度”设为关节直径，翼板就与关节齐平；这样的铰链最多打开约 90°，因为厚翼板会相碰。

弹性关节（Flexi）

“Flexi joints” 把一个扁平的实体变成可以活动的小玩偶，例如鱼、蛇或龙，一次打印成型（print-in-place）。实体由你自己画或搭建，例如用草图或拉伸的 SVG。工具沿实体长度横向把它切成若干节，并在每个切口处加一个关节：一节带着一根竖直的轴，中间比上下两端粗，下一节带间隙地把它包住。这样关节既能卡住又不会粘连，所有斜面都是 45°，无需支撑即可打印。各节之间留出一道楔形缺口，宽度对应各节向两侧摆动的角度。

选中实体（多个部件会合并，其中的孔会被减去），点击 “Flexi joints”。在窗口中设置沿哪一边切分（“Longer side” 取较长的一边）、“Joints” 的数量、“Clearance”（一般 0.4 mm 即可）以及 “Swing to each side” 的角度。关节大小会按实体自动确定；取消 “Joint size to fit the body” 后可自己填写 “Joint diameter”。取消 “Links all the same length” 后可以设定第一个关节离起点、最后一个离终点的距离，比如让头部保持为一整块。关节所在处，实体至少应约 6 mm 高、12 mm 宽；放不下时，窗口会告诉你是哪一个。

结果是一组关节节段（网格）的捆绑，按摆放的样子直接打印。如果不满意切分，撤销后换别的数值再试。先用两三个关节试打一次，就能看出间隙是否适合你的打印机。

滚花

“滚花” 是布满四周沟槽的圆形握持面，用于旋钮、拨轮和工具手柄。在 “图案” 下选择 “直纹”（沿轴线的沟槽，像控制旋钮）、“交叉”（两排斜向沟槽交叉成小菱形），或 “圆形”（沿轴线的沟槽和凸脊形成柔和的圆弧波纹，握感舒适而没有锐利的棱）。圆形沟槽保持浅于半个齿距，否则凸脊会在根部鼓起；深度过大会自动退让。你设置 “直径” 和 “高度”、“槽数” 的数量和 “槽深”；交叉滚花还要设置相对轴线的 “槽角度”。“两端倒角” 以 45 度断开两端，像车削的旋钮；0 则保持尖锐。

直纹和圆形滚花是精确实体，所以其边可以断开和倒圆。交叉滚花仍是网格，因为作为精确实体，30 条沟槽要计算将近一分钟。要给轴上的旋钮用，把滚花与一个孔分组，例如设为螺纹孔的 “螺纹”。浅于 0.4 mm 的沟槽几乎没有打印机能够干净地打出，而且 PrintCAD 不会让它们沿握持面间隔小于 0.8 mm：细的握持面得到的沟槽更少。

燕尾

“燕尾” 是一种两个零件相互锁住、只能从侧面滑入的接头。你设置宽端的宽度、“颈部宽度” 以及燕尾的长度。为另一侧复制燕尾，并把副本设为孔：“作为孔时的间隙” 随后提供一点间隙，使接头打印后不会卡死。

提示： 分组时，螺纹孔会切入与其重叠的零件。所以把它稍微放入材料中，而不是只接触表面。

泪滴孔

侧放的孔打印时顶部会形成一段桥，桥会下垂。因此 “泪滴孔” 顶部有一个尖角：每一层都落在下一层上，孔无需支撑就能打得足够圆。把 “直径（圆部）” 设为孔的尺寸，M3 螺钉约为 3.4 mm，并让 “孔长度” 足够长，以穿透零件。“尖端角度” 为 90°，所以牙侧在 45° 相接。大多数打印机都能干净地处理；更平的尖端需要更多高度，更陡的尖端则更省高度。

把泪滴孔设为孔，并与零件分组。其长度沿深度方向，尖端朝上。要在另一个方向开孔，就让它绕竖直轴旋转 90°。

侧放的螺纹孔同样会在顶部下垂。给它配一个自己的泪滴孔：添加一个 “泪滴孔” 孔，其 “直径（圆部）” 为螺纹芯部，即齿让出的直径（M10 约为 8.4 mm），长度与螺纹孔相同，然后同时选中两者。点击 “对齐”，让它们在中间对齐——泪滴孔的中心是其圆部的中心，而不是带尖端的外框中心，所以两个圆彼此重合——再把两者与零件分组。螺纹照常切出，尖端打开孔的顶部，因此无需支撑即可打印。

沉孔与锥形沉孔

螺钉头常常不应该凸出。“沉孔” 为内六角螺钉（DIN 912）切出圆形的沉孔，“锥形沉孔” 为沉头螺钉（DIN 7991）切出锥形沉孔。两者都以头部一端朝上：“头部直径” 是沉孔或锥面的直径，“杆部直径” 是其下方的孔，“总长度” 是总长度。沉孔上你设置 “头部深度”，锥形沉孔上设置 “锥角”（90° 适合沉头螺钉）。默认值适合 M3 螺钉。

“双面锥形沉孔” 是两面都倒角的孔，用于正面和背面都要整洁的板件。它在形状库里没有单独的条目：取用 “锥形沉孔”，并在其属性中开启 “两侧”（本身就是双面锥形沉孔的实体已显示该开关开启）：两端各有一个锥面张开到 “头部直径”，中间是 “杆部直径”。你照旧设置 “锥角” 和 “总长度”。如果孔太短，容不下两个完整的锥面，它们会以该角度在中间相接，杆部会比你设置的更宽：10 mm 的头部、6 mm 的杆部、90° 和 2 mm 的长度会形成两个从 10 mm 收窄到 8 mm 的锥面。作为孔，它像其他孔一样被推穿零件。

把形状设为孔，并与零件分组。让它的顶端略高于头部应贴合的表面，使沉孔开口干净。要给六角螺母做沉孔，就用六边的 “多边形” 作为孔。

10. 测量与备注

卷尺、标尺与角尺，到原点的距离，附着在零件上的备注，以及可供吸附的参考点。

要精确地做出一个零件，就必须测量。PrintCAD 为此提供了几种工具，它们都不会出现在导出文件里。零件内部的壁厚和间隙，最好在剖视图中用 “测量” 测量。

卷尺

卷尺位于左边缘相机栏的下端（“卷尺”）。它测量角、边和面之间的距离。单击它会展开五个按钮。如果它们挡住了你想测量的地方，就抓住左侧的握柄，把它们拖到工作平面上的任意位置；双击握柄即可归位：

  1. “添加测量”： 单击一个点，拖到下一个点再单击，距离就会标注出来，前面标出它沿哪些轴：直线为 X、Y 或 Z，跨越一个平面为 XY、XZ 或 YZ，三个轴都有则为 3D。指针悬停在标签上可看到测量沿每个轴的长度，悬停在点上可看到它的坐标。放置第二个点时，轴、距离和沿每个轴的长度会显示在指针旁边。大部分位于另一个物体后面的测量会变淡；指针悬停在它的线或标签上时会恢复清晰。在相对的边或面上，当指针靠近时，第二个点会以直角吸附到第一个点——或者按住 Shift 时，可落在该边或该面上的任意位置。在同一面内或工作平面上，Shift 会让测量沿主轴保持笔直。
  2. “移动测量点”： 抓住这些点移动，数字会跟着变化。
  3. “删除测量段”： 之后单击某条测量即可删除它。“添加测量” 处于激活状态时，按住 Shift 或 Ctrl（Mac 上为 Cmd）单击测量点或测量线，就能直接删除，无需切换模式。
  4. “测量整条边”： 单击一条边会测量它的全长，例如一个圆的周长。关闭此项后，单击会在边上放置一个点，第二个点可以放到任意位置，于是你能测量直径或任何其他距离。按住 Alt 可让该开关对这一次单击取反。在圆上，当指针靠近时，与第一个点相对的点会自动吸附，而且点落在真实圆周上，因此直径是精确的。
  5. “删除所有测量”： 一次删除所有测量。由于无法撤销，PrintCAD 会先询问；没有测量时则无事可做。
  6. “将中点标记为参考点”： 每条测量的正中都有一个小圆形标记，下半部分填满。它会在测量的正中放置一个参考点：单击圆形边（例如孔的边缘）后，放在该圆的圆心——导入的网格也一样，那里没有别的东西标出孔心——对于直径或任何直线测量，则放在其中点。之后拖动形状时，它会以自身中心吸附到该点。已经存在的点不会重复创建。卷尺吸附参考点就像吸附角一样，因此你可以从圆心或线段中点开始测量：先标记，再单击该点。
  7. “输入长度:第二个点处的物体沿线移动;负值会把它移过第一个点”: 只要一条直线测量至少有一端落在物体上,就可以点击它的数字。输入新的长度并按 Enter:第二个点处的物体会沿着测量线移动,直到距离正好等于该值,就像 Tinkercad 的标尺一样。如果只选中了第一个点处的物体,则移动它。测量点留在物体上,所以测量会跟着移动。从角、边或参考点(例如圆心)开始测量,就能把零件放在精确的距离上。负数长度会让它越过第一个点同样的距离,例如在盒子边缘以内 5 mm。

按 Esc 退出测量模式。

标尺

从形状库中取出“标尺”。它纯粹是测量工具：不会出现在任何导出中，也不能分组或剪切。对于每个接触或与标尺重叠的实体，它会在视图中直接以浮动数字显示其范围。你可以就地修改该数字，实体随之改变。浮动的加号会创建被测形状的副本。它印制的刻度是毫米；把单位切换为英寸后（右下角的开关），刻度就是英寸，每十六分之一英寸一条线，整英寸处标有数字。

角尺

有时在直角方向测量更方便。单击相机栏中的 “放置直角尺”，再单击工作平面。一把两臂成直角、带类似直角尺刻度线的角尺便会放置在那里。它同样没有自己的实体。单击实体角附近，它的角就会精确吸附到那里。

角尺平放在工作平面上。如果该平面位于某个实体的侧面上，角尺也平放在那个侧面上，参见视图与工作平面。在竖直墙面上标注尺寸就是这么做的：把工作平面放到墙上，将角尺放在左上角，然后连续单击握柄，直到两臂指向右和下。

  • 拖动握柄可移动它。
  • 短促地单击握柄使它旋转 90°。
  • 旁边的 × 可移除它。
  • 握柄左侧的小按钮切换测量基准：实体的外侧（端点，带线条的图标）或它的中间（中点，十字准线）。每个绿色数字旁边都有一个同类小开关，只设置该数字：对竖立的圆柱体，两臂方向取中间、高度取底部；对横躺的圆柱体，横向取中间、沿轴向取一端。当三者再次一致时，握柄处的按钮会显示这个共同的模式。

如果实体位于某条臂上，角尺会自动显示它们的尺寸。这只在基板上有效，在实体侧面上无效。 角尺手柄下方带箭头的按钮可以关闭这一点，使只有选中的实体显示尺寸；它随设计保存。

选中一个实体后，角尺会用绿色显示它距角点的远近，包括沿两条臂的方向和高度。单击绿色数字输入距离，实体就会精确移到那里。选中多个实体时，它们被当作一个整体：标尺测量它们共同的外轮廓，输入数值会让它们一起移动，而彼此的相对位置不变。

绿色数字的引导线沿地面（即角尺所在的平面）延伸到实体下方或旁边的点；高度则有自己的箭头。每个数字的开关位于数字的边框内。两臂和刻度是空间中的线条：挡在它们前面的实体会遮住它们，就像真实的角尺会被遮住一样。握柄下方的眼睛图标可切换这一点：眼睛带斜线时，实体遮挡角尺（初始状态）；眼睛打开时，角尺始终显示在所有东西之上。当实体挡在两臂前面时，臂上的数字会淡出。

使用中点模式时，绿色数字量到实体的中间，高度也一样。这样你可以把球体的中心正好放在距某条边 15 mm 的位置，而不用减去半径。在墙面上把孔放在距左边 40 mm、距顶部 190 mm 处，可以这样做：选中孔，切换到中点，输入 40 和 190。此时高度从墙面起向外计算。

卷尺和角尺在你进入草图再回到 3D 视图的过程中都会留在原处。两者都不进入历史记录。角尺随设计保存，卷尺的测量也一样，保存在浏览器和 .lyl 文件中：打开设计时它们会再次出现。卷尺按钮中的眼睛按钮会隐藏所有测量并可再次显示；是否隐藏也会一并保存，添加、移动或删除测量时会先把它们显示出来。

到原点的距离与移动时的距离

在设置中的 “外观” 下，有两个用于实时尺寸的开关：

  • “显示移动尺寸” 显示拖动时移动了多少。用物体上方的黑色箭头抬起时也会显示，距离标在它的前角。松开后，点击这样的数字即可输入确切的距离；负数表示向下。
  • “显示到原点的距离” 显示所选对象到平台原点的距离，选中多个实体时同样有效。

启用 “尺寸始终可见” 后，尺寸会一直可见。

想暂时去掉它们时，按 Q：所选对象周围的尺寸和距离会消失，正在移动的部件更容易看清。再按一次 Q 即可恢复。指向某个手柄时，它仍会显示自己的尺寸。

备注

备注记录几何本身说不出来的事：“这颗螺钉紧了 0.3 mm”“盖子还要打印”“尺寸来自 Peter”。用 “备注” 或按 N 键放置一条。

  • 如果把备注放在实体上，它会跟着实体移动。
  • 如果放在旁边，它会留在工作平面上（“位于工作平面”）。
  • “从对象上解除” 会把附着的备注从实体上解下。
  • “分组” 会把附着的备注收进分组；“取消分组” 会把它交给下面可见的部件，包括其中的分组。用 “编辑分组” 打开分组时，备注随其下方部件移动，再用 “完成” 回到分组中；取消则恢复原样。
  • 如果它依附的实体被删除，或者它下方不再有可见实体，备注会留在原处，即工作平面上。
  • 拖动图钉可移动备注。单击图钉会把卡片收起，只留下那个小数字；再单击一次可重新展开。单击文字即可编辑。
  • 书写时，Enter 保存文字，Esc 恢复到你开始之前的样子；Shift+Enter 换行。
  • 在草图中，“备注”（位于 “管理”）或 N 同样可以放置备注，放在草图上的任意位置。草图的所有备注都属于它的实体：在 3D 视图中，它们位于实体上——用 “拉伸草图” 或 “扫掠草图” 生成的实体的顶面上，以及用 “旋转草图” 生成的实体所绘制的轮廓上——并随实体一起移动。再次打开草图时，会显示该实体的备注，包括在 3D 中放置的备注。在草图中，“草图撤销” 会像撤销线条一样撤销备注，“取消” 会放弃你对备注所做的更改。Shift+N 在这里同样可以显示或隐藏备注。

备注会保存在设计中，不出现在任何导出里，可用 “显示便签和参考点” 显示或隐藏（位于 “可见性选项” 中，眼睛图标旁的箭头），也可按 Shift+N。

参考点

参考点是空间中的一个纯标记，就像车间里的铅笔记号或放样点：它不属于任何实体，永远不会被打印，其他东西会吸附到它上面。右键单击实体，选择 “标记中心”、“标记角点” 或 “标记边中点”：点会出现在实体的顶面上（如果选中了多个，则出现在整个选择的顶面上）。 “标记此面的中心” 则把点放在你右键单击的那个平面的中心，例如侧面或端面。设置了旋转中心时，“标记旋转中心”会在其上放一个点，这样另一个零件的中心就能吸附到选择所绕的那个点上。

  • 拖动点可移动它，或单击它查看坐标并输入新坐标；坐标使用你设定的单位。如果卡片挡住了东西，可以抓住它的标题单独拖开：其他卡片留在原处，双击标题即可归位。你最后碰过的卡片显示在其他卡片前面。卡片中的 Delete all，或右键菜单（实体的，或 3D 视图中空白处的）中的 Delete all reference points，会一次删除所有点。“删除” 删除它。
  • 卷尺也能标记点：“将中点标记为参考点”，即测量正中那个半填充的标记，会在测量中间放置一个点，例如圆孔的中心。它也能从一个点开始测量：卷尺吸附参考点就像吸附角一样。
  • 拖动形状时，它的边和中心会吸附到点，就像吸附到其他形状一样（“移动时吸附到其他形状”）。角尺也会吸附到点。
  • 点保存在设计中，不出现在任何导出里，并随备注一起由 “显示便签和参考点”（Shift+N）显示或隐藏。
  • AI 可以用 layerling_add_reference_points、layerling_list_reference_points 和 layerling_remove_reference_points 标记、列出和移除它们。

参考图片

参考图片是用来对齐零件的图片：把电路板的照片放在外壳底部，然后直接在上面放置支柱、孔和接口开口。它是辅助参考，不是实体：永远不会被打印或导出（STL、3MF、OBJ、STEP、SVG），永远不会成为组合、捆绑或切割的一部分，打印估算也不会计入它。

  • 打开 “导入” 并选择 “参考图片”，然后选择一张 PNG、JPG、WebP、GIF 或 BMP 图片。它会放在工作平面上——底板上，或你设置工作平面的那个面上——长边为 100 mm，半透明。
  • 像任何形状一样用控制柄移动、旋转和调整大小。它前面的实体会被优先选中，因此在它上面操作不会抓起图片。
  • 设置中的 “透明度 (%)” 可以把它从不透明淡化到几乎看不见。
  • “校准” 让它恢复真实尺寸，与草图中相同：单击图片上两个你知道实际距离的点——例如电路板的两个安装孔——并在 “实际距离 (mm)” 中输入该距离。图片会保持比例和中心不变。
  • 用设置标题栏中的锁将它锁定，它就会固定不动：点击会穿过它落到底板上。在对象列表中选中它即可解锁。
  • 无论复制或撤销多少次，图片在设计文件中只保存一次。大图片会让文件相应变大；添加时的提示会说明它的大小。
  • AI 可以用 layerling_reference_image 添加、移动、校准、淡化和锁定参考图片。

11. 为 3D 打印做准备

选择自己的打印机，在部件放不下时收到警告，并正确摆放部件。

选择打印机

打开设置（功能区里的齿轮图标，“工作区设置”），切换到 “工作平面” 区域。在 “打印机” 下，可以从 220 多种常见型号的列表中选择自己的打印机，包括 Bambu Lab、Prusa、Creality、Anycubic、Elegoo 等众多品牌。

会有三件事发生：

  • 工作平面采用打印床的尺寸。
  • 工作平面的角落会显示打印机名称及其构建体积。如果这些文字碍事，可以用 “平台标签” 将其关闭，该开关在 “工作平面” 下；位于左前方的设计名称也一样。
  • 部件放不下时，PrintCAD 会警告。

打印机配置来自 OrcaSlicer，因此与你的切片软件所知的完全相同。如果不想使用打印机，选择 “无打印机，自由尺寸”。也可以手动设置工作平面的尺寸。

部件放不下时

伸出打印平台边缘的实体会被标记。消息会说明是哪几侧超出、超出多少。部件过高时同样如此：高度从最低的实体算起，与切片软件放下模型的方式一致。

警告不会阻止你继续工作。它只是一个提示，免得你到了切片软件里才发现部件太大。太大的部件通常可以分割：用 “分割” 切成两半，分别打印。

如果有意把部件停在平台旁边，点击消息中的小叉。警告随即对这些实体消失。一旦其中一个重新放得下、之后又被你移出去，或者有别的实体伸出，消息就会再次出现。隐藏的实体从不计入，所以把停放的部件隐藏起来同样有效。

正确摆放部件

部件在平台上的摆放方式决定其强度和外观。“排列” 区域中的两个工具可以帮忙：

  • “平放于面”：点击一个面，部件就以该面朝下摆放。一键找到最佳打印方向。
  • “落到工作平面”（D）：当部件悬在空中时，将其放到工作平面上。

关于方向，有几条经验法则：

  • 大平面朝下。这样粘得最牢。
  • 细长且受力的部件，摆放时不要让层纹与受力方向垂直。层间结合是最弱的方向。
  • 避免超过 45° 的悬垂，或者在切片软件中为其添加支撑。

查找悬垂

在眼睛图标旁的下拉菜单（“可见性”）中，显示悬垂会开启悬垂标记。所有向下倾斜超过 45° 的面都会显示红白斜线——这些地方打印机需要支撑。贴在平台上的面不会被标记。这样在设计时就能看出球体、拱形或水平孔能否不加支撑打印；泪滴孔正是为此而生。转动部件，或用 “平放于面” 让它以另一个面朝下，斜线会立即随之更新。

打印机能够应付多陡的倾斜，在设置的 “外观” 下设置：从 30°（谨慎）到 70°（适合散热良好的打印机）。搭在另一个实体上的面仍会被标记——PrintCAD 只看面本身。

壁厚、间隙与倒角

  • 壁至少要有两条挤出线宽，即 0.4 mm 喷嘴对应 0.8 mm。结实的部件需要 1.2 至 2 mm。
  • 两个部件互相配合的地方需要间隙：通常为 0.2 至 0.4 mm，视打印机而定。打印大件之前，先做一对小测试件。
  • 很多人会给贴着平台的底边倒一个小角。这样可以防止首层外扩（“象脚”）。

准备就绪时

点击 “导出”，然后选择 STL 或 3MF。STL 是最简单的格式。3MF 会保留各个实体的名称和颜色，因此在多色打印时很方便。导出窗口还会显示该部件按实体打印需要多少克、多少米耗材。更多内容见文件与保存。

12. 文件、保存与分享

设计存放在哪里，如何备份，PrintCAD 能导入和导出哪些格式，以及在自己的共享服务器上能做什么。

设计保存在哪里

PrintCAD 把所有内容保存在你电脑的浏览器里。没有账号，也不会上传任何内容。每次改动都会自动保存。起始页上的预览图，显示的是你用 “起始页” 返回时所看到的最后一个画面。几天后在同一个浏览器里打开 PrintCAD，一切都在。

如果从一个没有任何内容的设计返回起始页，PrintCAD 会问是否保留它。“是” 或 Enter 保留，“否” 移除，这样空设计不会越堆越多。对于服务器共享文件夹里的设计，“否” 会把文件从服务器上删除，所有使用它的人都会失去这个文件。

这有个缺点：清除浏览器存储或换到另一台电脑的人会丢失设计。所以要把重要的工作备份成文件。

设计的文件夹

设计多达几十个时，单一列表就不够用了。在起始页上，“新建文件夹” 会为本浏览器的设计新建一个文件夹；点击文件夹即可打开。文件夹里可以再放文件夹。

  • 移入文件夹： 把设计拖到文件夹上，或在设计菜单里选择 “移动到 …”，菜单会列出所有文件夹。打开某个文件夹时新建的设计，以及打开或导入的文件，都会落在该文件夹里。
  • 再移出来： 文件夹里的第一个磁贴 ..，以及标签下方的那一行，都能返回上一层；也可以把设计拖到它们上面。把一个文件夹拖到另一个文件夹上，就会放进里面。
  • 重命名和删除 在文件夹的菜单里。删除文件夹不会删除任何设计：里面的内容会上移一层。
  • 搜索 会查找所有文件夹；找到的设计会显示它所在的文件夹，点击该文件夹即可打开。

“全部备份” 会保留文件夹：设计连同文件夹一起装进备份文件，恢复备份时会把它们放回原处。本浏览器的文件夹与服务器上的文件夹是分开的。卡片图片也会写进文件，所以恢复后马上就能看到。

备份与转交

在起始页上，每个设计都有一个菜单，可以重命名、复制和删除。标签旁边的那一排按钮在每个标签上都一样。用 “全部备份” 可以把当前打开的标签中的所有设计打包成一个 ZIP 文件。紧挨着它的 “恢复备份”（在新电脑上、还没有设计时也会出现）可以把它们恢复回来，换一个浏览器或换一台电脑也行；“打开设计或导入几何体” 也能打开同一个文件。本浏览器的 “自定义形状” 会随同一个文件一起走，放在 Custom shapes 文件夹里，参见形状。如果把备份恢复到已经有其中一些设计的浏览器，那些设计不会重复添加；提示会说明有多少个已经存在。本浏览器的设计上方有一行简短的提醒，说明它们没有保存在其他任何地方。

只备份部分设计：点击 “Select” 后，“备份” 只把所选设计连同其文件夹打包成一个 ZIP 文件；文件夹菜单中的 “备份” 会打包该文件夹及其中所有设计和文件夹。两者都不包含自定义形状，“恢复备份” 可以像完整备份一样恢复它们。这适用于此浏览器中的设计。

在编辑器里备份单个设计：“导出”，选择 LYL 格式，然后点击 “保存 PrintCAD 设计”。LYL 文件是 PrintCAD 自己的设计格式，包含所有内容：形状、分组、草图、CAD 数据、导入的源文件和历史记录，也就是撤销步骤。在 “保存的操作历史” 下选择带上前多少步；初始值取自设置（功能区里的齿轮）中 “历史记录” 保留的步数。最后一档 “无” 只保存设计的当前状态——这是分享不带撤销步骤的文件的办法。导出的是副本，文件名由你在 “文件名” 中指定；浏览器里的设计仍保留自己的历史记录。旧版本留下的 .skf 文件仍可打开，打开后会存成 .lyl。

保存到自己的文件夹（Chrome 和 Edge）。 在这些浏览器里，按钮会打开系统的保存对话框，你可以自己选择文件夹和文件名，也可以替换已有文件。之后按 Ctrl+S 会把设计再次保存到同一个文件，不再弹出对话框。用 “打开设计或导入几何体” 或导出窗口的打开按钮从 .lyl 文件打开的设计，也会保存回该文件。浏览器可能会询问一次修改文件的权限。页面重新加载后，设计会忘记自己的文件，下次 Ctrl+S 时会再次询问；对话框会从你上次使用的文件夹开始。Firefox 和 Safari 不允许网页这样写入文件。在那里，文件仍会下载到“下载”文件夹，Ctrl+S 会再次下载；Firefox 可以在“设置 > 常规 > 下载”里设为每次都询问文件夹。

导出

点击 “导出”，或按 Ctrl+E。

顶部是文件名，下面选择格式。有选中项时只导出选中的内容，否则导出整个设计。如果选择漏掉了可见部件，窗口里会明确提示，“全选” 可以一键选中所有可见内容。文件写好后窗口会自动关闭；导出失败时，窗口会保持打开并显示消息。

格式用途注意事项
STL切片软件和 3D 打印三角网格。最简单、最通用的格式。STL 没有部件之分：重叠的实体会合并成一个网格。要保留为独立部件，请导出 3MF。在 Chrome 和 Edge 中，第一次导出 STL 会询问保存位置，之后该设计再导出 STL 都会写入那个文件，直到你在文件名字段里输入别的名字，或按 “另存为…”。
3MF带颜色的切片软件每个实体都保持为独立部件，并带有名称和颜色。重叠的实体只有在颜色相同时才会合并；当一个形状位于另一种颜色的实体内部时（比如板子上的标志），先建的那个会给后建的让出空间。适合 PrusaSlicer、Bambu Studio、OrcaSlicer 和 Cura。Bambu Studio 和 OrcaSlicer 打开时会询问如何把颜色对应到你的耗材，并称该文件“不是来自 Bambu”——这条消息没有影响。
OBJ建模与交换支持广泛的网格格式。颜色以顶点色保存在同一个文件里，不需要额外的 .mtl。Bambu Studio 和 OrcaSlicer 能读取颜色，并像 3MF 那样询问如何对应到耗材；其他程序只能看到形状。与 3MF 一样，重叠的实体只有在颜色相同时才会合并。
STEP完整的 CAD 程序把长方体、圆柱体、球体和圆锥体保留为精确几何，因此也包括由轮廓生成的形状（星形、心形、椭圆、管、半球、圆弧屋顶、圆角长方体、燕尾、孔等）、弯管、螺纹、弹簧和齿轮，以及圆角和倒角。一次会话中第一次导出 STEP 会加载一次 CAD 内核（约 22 MB）。
SVG激光切割机和绘图仪以毫米为单位的干净俯视图，包含孔和曲线轮廓。在 “视图” 下，“工作平面上的着地轮廓” 只输出物体立在工作平面上的轮廓。
DXF激光切割加工厂同样的俯视图（“俯视剪影” 或 “工作平面上的着地轮廓”），输出为一条由直线、真正的圆弧和圆组成的轮廓——没有多段线、样条曲线，也没有由短直线段拼成的曲线——位于 0 图层、白色，DXF 2000 格式，单位毫米，不镜像。相互接触的实体合并为一条轮廓，因此没有线会被切割两次。加工厂要求每个文件一个零件：导出前先选中该零件。尚未在激光切割机上实测：欢迎反馈。
PNG论坛帖子、打印站点、提问当前视图的图片，分辨率为两倍，不含手柄、选择框和尺寸。“显示打印平台” 和 “透明背景” 在窗口中设置。先旋转和缩放，直到画面合适；这里选中项无关紧要。
LYLPrintCAD 本身可编辑的设计，包含与之相关的所有内容。
2D工坊、车床和铣床、文档1:1 的图纸，可导出为 PDF 或 SVG：ISO 图纸上的主视图、俯视图和右视图。见下文。

把 STL 保存到自己的文件夹（Chrome 和 Edge）。 在这些浏览器里，第一次为某个设计导出 STL 会打开系统的保存对话框，你可以自己选择文件夹和名称，也可以替换已有文件。之后该设计的每次 STL 导出都会写入同一个文件，不再弹出对话框；导出窗口会显示是哪个文件，导出按钮旁的 另存为… 可以另选一个。对话框会记住自己的文件夹（与设计用的文件夹分开），这样切片文件可以和切片软件放在一起。页面重新加载后，设计会忘记自己的 STL 文件，下次导出会再次询问。Firefox 和 Safari 仍像以前一样下载文件。

没有分组的孔在导出时会从它触及的每个实体上挖掉，与视图显示的一致。所以不必在每次导出前先分组。有选中项时，只有选中的孔才计入。孔不能单独导出；PrintCAD 会提示这一点。

STEP 只携带精确的 CAD 实体。无法精确写出的内容，比如作为 STL 导入的网格，会被略过。导出后的消息会列出这些实体并说明原因。给打印机用时，请选择 STL 或 3MF，它们能携带所有内容。

工坊用图纸

选择 2D 格式（将鼠标悬停在其上会显示“图纸”），并在文件名下方选择 PDF 或 SVG。有选中项时只绘制选中的内容，否则绘制整个可见设计；没有分组的孔仍会切掉它们触及的部件。

PrintCAD 按第一角投影绘制主视图、俯视图和右视图（右视图在主视图左侧，俯视图在主视图下方），使用能容纳的最小 ISO 图幅，从 A4 到 A0，零件需要时可用更大的。比例始终为 1:1。每个视图都标注总宽和总高，看不见的边用虚线表示。与视图方向平行的圆孔会带中心十字和标记（F1、T1、R1），底部的表格列出它们的直径和位置，位置从视图左下角量起。右下角的标题栏包含名称、比例、单位、日期和图号。图纸上的文字跟随界面语言。

按 100 % 或“实际大小”打印，否则长度会对不上。图纸不做的事：螺纹、深度、公差和斜向孔都不标注尺寸，尺寸来自作为网格的模型，因此是名义值。过于复杂的零件（超过 100,000 个三角形）或超过 200 个孔会被拒绝并给出消息；这时请少选一些对象。

需要多少耗材？

对 STL、3MF、OBJ 和 STEP，“材料” 框会显示所导出内容的体积、重量和 1.75 mm 耗材长度。它的计算方式与文件一致：只算可见实体，减去孔，重叠只算一次。右侧选择耗材——PLA、PETG、ABS、ASA、TPU 或 PA（尼龙）——重量随其密度变化。体积是实体本身的体积。重量和耗材是按带壁和填充的打印做出的粗略估计：在标题下设置 “填充率”（初始为 15 %）和 “壁数”（2），框里会说明它计算了什么，以及同一个零件实心时会有多重。真正的数字由切片软件自己的设置决定，所以把它当作参考：适合比较设计，也适合判断线轴够不够用。填充为 100 % 时，框会把零件当作实心计算，这是上限。

导入

用 “导入” 或 Ctrl+I 可以把外部文件带入设计。

  • “打开 PrintCAD 设计”： PrintCAD 设计（.lyl，或更早的 .skf）会作为新设计重新打开。
  • “插入此设计”： PrintCAD 设计的实体会添加到当前设计中。适合那些需要反复使用的基本形状：建一次、保存，然后每次带进来。 把一个或多个 .lyl 文件拖到下方的放置区，也会以同样的方式插入。它的便签会一起进来，以收起状态出现，并接在设计中已有便签之后继续编号；它的参考点也会一起进来。
  • 添加几何体： 把 STL、OBJ、3MF、STEP、SVG、PNG 或 JPG 文件拖到窗口中，或点击选择文件。导入的网格可以旋转、移动、用孔切割，也可以在上面继续建模。SVG 会作为草图实体导入，来自 picsvg.com 或 Inkscape 的“位图描摹”等描摹工具的也一样：它的轮廓变成草图的直线和曲线，高 4 mm，从上方看与图纸方向一致。在属性面板中设置它的 “填充”（区域，或向外、向内、居中的描边），“剪影（无孔）” 会忽略孔，参见草图的“填充与剪影”。点本身要在草图模式下修改。如果要按自己的尺寸导入，先在导入窗口的 SVG 和图片：宽度（mm） 下输入宽度，与 Tinkercad 一样：图纸会缩放到这个宽度，高度和深度随之缩放，这个字段在这一次导入后就会清空；留空时，SVG 按自身尺寸导入，图片则宽 50 mm。只有超过 2500 条直线和曲线的非常复杂的 SVG 才会作为固定网格导入。PNG 或 JPG 图片会被描摹成轮廓，以同样的方式作为草图实体导入，宽 50 mm，之后可以调整大小：图片中不是背景的部分会保留，背景是占据图片边缘更多的部分。只包含一张图片的 SVG 也按同样方式描摹。无法构成实体的形状，比如自相交或在一点处自接触的轮廓，会被略过，导入后 PrintCAD 会说明有多少个。这时可以在绘图软件里把重叠的部分合并、闭合轮廓，然后重新保存文件。在同一页上绘制的图纸（例如把一个文档的各图层分别导出为文件）会重新对齐，只要在导入前打开导入窗口中的 “SVG：保留在图纸页面上的位置”：每个都保留自己在页面上的位置，否则每个都会以自身为中心。用多种颜色绘制的 SVG 同样按颜色各导入为一个实体，各自保持颜色和位置；超过 12 种颜色（如描摹的图片）则仍为一个实体。彩色 OBJ 或 3MF 会按颜色各导入为一个实体，各自在原来的位置。在 OBJ 中，颜色要么在文件本身里（如 PrintCAD 导出的 OBJ），要么在旁边的 .mtl 里。把那个文件也一起选中，或者像 Tinkercad 交付 OBJ 那样导入整个 ZIP。3MF 自带颜色，在 Bambu Studio、OrcaSlicer 或 PrusaSlicer 的项目中，每个部件采用其耗材的颜色。包含多个对象的 3MF（例如每盘一个对象的项目）会按对象各导入为一个实体；切片软件中的修改器、负体积和支撑阻挡器会被略过。切片软件里涂在面上的颜色不会被读取。
  • DXF： 激光切割加工厂或供应商发来的零件轮廓 DXF，会作为可以继续编辑的零件导入：每条闭合轮廓变成一个高 4 mm 的实体，其中的每个孔变成旁边一个独立的孔（圆孔为圆柱），所以在 3D 编辑器中可以像其他孔一样移动孔、改变孔的大小；要移动整个零件，请全部选中。单位为毫米（英寸文件会换算，没有单位的文件按毫米读取），圆弧和圆保持为真正的圆弧。读取直线、圆弧、圆、椭圆、多段线、样条曲线和块；文字、尺寸标注和填充图案会被略过，未闭合的轮廓也会被略过——提示信息会说明有多少个。厚度在属性面板中设置。
  • 来自 Tinkercad： 从 Tinkercad 导出的 STL 或 OBJ 会像其他网格一样作为几何体导入，OBJ 会保留颜色。真正的形状则可以通过社区的一个免费工具带过来：taylormadearmy 的 Export to PrintCAD，这是一个书签，能在你的浏览器里把 Tinkercad 设计转换成 .lyl 文件，然后在这里用 “打开 PrintCAD 设计” 打开。它不属于 PrintCAD，我们自己还没有测试过；作者在 Windows 的 Chrome 上测试过。

用较新版本的 PrintCAD保存的设计，可能包含你这个版本还不认识的内容，比如新形状、新设置或自定义字体。如果 PrintCAD 因此无法打开，消息会写出两个版本号。如果能打开，提示会说明较新的内容在这里可能看起来不同。无论哪种情况，刷新页面都有帮助：the public site 总是提供最新版本。安装版应用会在下次启动时获取更新；在自己的服务器上，你需要自行安装更新。

简化导入的网格

扫描或雕刻得到的网格，三角形数量往往远超其形状所需，而你在移动、切割和保存时，每一个三角形都会被带着走。修改组里的 “简化网格”（或实体的右键菜单里）会把当前网格与你选择保留的三角形比例所留下的结果并排显示；两个视图都会随工作平面的鼠标按键一起旋转和缩放。按百分比或三角形数量设置保留多少，“简化” 会采用更轻的网格。结果是普通网格：对于切割或合并的结果，“编辑分组” 及其原始部件会被放弃。

切割、合并和相交导入的网格是在浏览器里计算的，所以工作区设置限制了这类网格可以有多少个三角形（“剪切导入网格上限为”）。超过限制的网格不会被处理，消息会写出它的三角形数量；请先简化网格，或者在电脑能承受的情况下提高限制。

报告问题

如果 PrintCAD 做出意外的事，可以保存一份 “问题报告”：链接在底部的页脚里，论坛旁边。它是一个 ZIP 文件，因为 GitHub 和许多论坛不接受单独的 .lyl：里面有你的设计（.lyl）和一个简短的文本文件，记录版本、浏览器、屏幕尺寸、最后的消息和任何错误。起始页可以像备份一样打开这个 ZIP，也可以解压后打开其中的 .lyl。里面没有个人信息。把文件附在论坛或 GitHub 的帖子里，这样就能用和你完全一样的设计来追查问题。

如果 PrintCAD 因错误而停止，会显示一个带错误消息的窗口，而不是空白页。你可以从中把浏览器最后保存的设计状态存成 .lyl 文件、返回总览，或新建一个设计。窗口中的错误消息和保存的文件在你报告问题时会有帮助。

服务器上的共享设计

当 PrintCAD 运行在你自己的电脑或 Web 服务器上时，它可以提供一个共享文件夹，所有用户都在里面保存设计。起始页这时会用两个标签显示设计：“服务器” 对应共享文件夹，另一个对应本浏览器，每个标签都标有其中的设计数量；设计较多的那个排在前面并默认打开。你可以在那里创建文件夹、拖动设计来移动它们，并在整个文件夹中搜索。存放在那里的设计会自动保存回该处。本浏览器中的设计，可以通过把卡片拖到 “服务器” 标签上来放到服务器上，也可以使用卡片菜单里的 “放到服务器上”。当 “服务器” 标签打开时，“新建 3D 设计” 和 “恢复备份” 会把设计放进你打开的服务器文件夹，“全部备份” 则会把服务器上的所有设计（连同其文件夹）及其自定义形状打包成一个 ZIP 文件。起始页按文件名显示设计，所以在卡片上或编辑器顶部重命名设计，也会重命名服务器上的文件。删除设计或文件夹会永久删除它，连同本浏览器里的工作副本。保存在服务器上的自定义形状位于其 Custom shapes 文件夹中，参见形状。

有两件事能让这更快：起始页上的 “全部放到服务器上” 可以一次性把本浏览器的所有设计放到服务器上；勾选 “服务器上的新设计” 会让每个新设计都从服务器文件夹开始，因此从第一次修改起就保存在那里。这个勾选状态保存在本浏览器中。无法放上去的设计（比如名字在服务器上已被占用）会留在浏览器里，消息会说明有多少个。

这不是同时编辑：每个打开文件的人都在自己的副本上工作。如果别人在此期间改过该文件，PrintCAD 会拒绝覆盖它。

在 the public site 上，此功能未启用。如何在自己的服务器上设置，见 GitHub 上的 README。

13. 键盘快捷键

所有按键一览，直接取自程序，因此列表始终准确。

只要工作平面获得焦点，快捷键就会生效。在输入框中输入时，它们不会触发。在 Mac 上，此处列出 Ctrl 的地方改为 Cmd。

在编辑器中，“帮助” 区域里的 “键盘快捷键” 会以窗口形式打开同一份列表。窗口中的打印机按钮（“打印或保存为 PDF”）可单独打印这份列表，白底黑字，整份列表分三栏排在一张 A4 或 Letter 纸的一面上，便于随手查阅；浏览器的打印对话框也可以把它保存为 PDF。

窗口顶部的输入框用于搜索列表：只保留说明、分组或按键中包含你输入的每个词的快捷键，例如输入 "ctrl+z" 就只剩下这些行。不区分大小写和重音符号；只输入一个字母或数字时，会找到该按键以及以它开头的单词。输入框末尾的 X 会清空内容；输入框为空时，整份列表会重新显示。打印机按钮打印的是窗口当前显示的内容，因此搜索后只会打印找到的快捷键。

命令搜索

找不到某个工具？按 Ctrl+K，或点击 “帮助” 区域里的放大镜，然后输入你要找的内容：工具（“圆角”“镜像”）、形状（“圆柱体”）或命令（“导出”“撤销”）。用方向键移动，按 Enter，或点击相应条目。

  • 搜索同时认识英文和德文写法，并忽略大小写和变音符号：“aushoehlen” 能找到 “抽壳”。
  • 每条结果都会显示等效的按键，以及它所在的功能区区域，方便你记住它的位置。
  • 置灰的条目目前无法执行，多半是因为没有选中任何东西。它们仍留在列表中，这样搜索依然能告诉你工具在哪里。

你正在阅读的这份指南也有搜索框，位于每一页的顶部：输入一两个词，它就会列出同时包含这些词的章节，并标出匹配的词。点击其中一条，或按 Enter 跳到第一条，即可直接前往。

  • 形状的名称会把该形状添加到工作平面，就像在形状菜单中点击它一样。
  • 搜索框为空时，搜索会把最近用过的命令列在顶部。
  • 设计中的实体名称可以找到并选中该实体，在设计包含许多部件时很有用。实体只在你开始输入后才会出现。
  • 它在草图模式下同样可用，支持草图工具。

交互式帮助

找不到关于某个按钮或输入框的说明在哪？让程序带你过去。点击 “帮助” 区域里的问号，或按 Shift+F1。指针会变成问号，它下面的任何内容都会被框出。

  • 点击按钮、输入框、开关、控制柄、功能区的某个组或窗口的标题栏。它不会执行原本的功能。取而代之的是打开一个小窗口，其中包含该元素的名称、本指南中相关部分的简短摘要、最多还有两处提到它的位置，以及 “在指南中打开”。
  • 帮助针对的是你指向的元素，而不是它周围的整个窗口。没有自己名称的元素会使用离它最近的有名元素；在窗口内部，则回退到该窗口的问号。
  • “在指南中打开” 会在新标签页中打开指南的对应章节。该章节会以彩色框出，从标题一直到末尾，让你看清它的起止位置。
  • 如果指南中没有关于该元素的内容，窗口会说明这一点，并提供 “搜索指南”。
  • 按 Esc 或再次点击问号即可退出该模式。触摸屏上没有悬停：轻点元素会直接打开窗口。

与其他窗口一样，该窗口可通过标题栏移动。程序根据元素名称——按钮上的标签、输入框的名称——找到对应章节，因为本指南中的每个按钮都按程序里的叫法书写。它会用你当前使用的语言，在指南每页顶部搜索框所用的同一套搜索中查找，并且完全在你的浏览器中运行。

14. 用 AI 搭建（MCP）

Gemini、Claude 或 Codex 等 AI 助手如何在已打开的编辑器中创建和修改形状、对它们分组，并为视图拍照。

PrintCAD 自带一个 MCP 服务器。MCP 是一项标准，AI 助手可通过它使用其他程序中的工具。借助它，Gemini、Claude 或 Codex 等 AI 客户端能看到一个已打开的编辑器标签页并在其中工作：创建形状、修改尺寸、分组、切割、给边做圆角、读取场景并为视图拍照。你描述零件，AI 负责搭建，你在旁边观看，随时可以接手。

AI 客户端与编辑器之间的桥梁在你的电脑上本地运行。但要注意：AI 读取的内容，也就是场景和视图图片，会像其他任何输入一样发送给你的 AI 服务商。

重要： MCP 桥梁只存在于你在自己电脑上启动的开发服务器中。在 the public site 以及使用静态托管的安装中，它是关闭的。你自己托管的副本（例如 NAS 上的 Docker 镜像）可以用访问令牌开启它；参见下文“NAS 或服务器上的副本”。

设置

  1. 从 GitHub 获取 PrintCAD，并在项目文件夹中用 npm run dev 启动。必须安装 Node.js。在 Windows 上，README 里的快速开始命令会帮你装好。
  2. 打开一个编辑器标签页，例如 http://127.0.0.1:3000/?editor=1。也可以交给 AI：没有编辑器打开时，第一个需要编辑器的工具会启动你的浏览器并打开编辑器，然后等待它连接。这适用于你自己电脑上的 PrintCAD；NAS 或服务器上的副本需要你手动打开编辑器。把 LAYERLING_MCP_OPEN_EDITOR=0 设给 MCP 服务器即可关闭这一行为。
  3. 把你的 AI 客户端连接到 MCP 服务器。客户端会用 node scripts/layerling-mcp-server.mjs 自行启动它。

Claude Code

无需安装：项目自带一个 .mcp.json 来注册服务器，以及 .claude/skills/layerling-mcp-skill 下的技能。在 Claude Code 中打开 PrintCAD 文件夹，然后这样提问，例如：“用 PrintCAD MCP 工具列出我打开的编辑器并检查场景。”

Claude Desktop

Claude Desktop 不读取项目文件。要在它自己的配置中输入服务器。可以使用项目中的 docs/mcp/claude-desktop-config.example.json 作为模板，把脚本路径换成你电脑上的绝对路径。然后重启 Claude Desktop。

Codex

把 docs/skills/layerling-mcp-skill 中的技能复制到 Codex 的技能文件夹，参照 docs/mcp/codex-config.example.toml 在 Codex 配置中输入服务器，然后重启 Codex。

Gemini & Antigravity

Antigravity 会自动发现 .agents/skills/layerling-mcp-skill 中的工作区技能。对于 Gemini CLI，把 docs/skills/layerling-mcp-skill 中的技能复制到全局技能文件夹（~/.gemini/skills/），参照 docs/mcp/gemini-config.example.json 把服务器加入设置，然后重启客户端。

各客户端的详细说明见 GitHub 上的 README。

NAS 或服务器上的副本

你自己托管的副本可以让 AI 客户端通过网络驱动其已打开的编辑器。它默认关闭，因为任何能驱动桥梁的人都能读取并修改已打开的设计。在服务器上，把 LAYERLING_MCP_REMOTE 设为 true，把 LAYERLING_MCP_TOKEN 设为至少 16 个字符的密钥（Docker 镜像写在 compose 文件的 environment: 下；无需重新构建）。打开该副本的一个编辑器标签页并保持打开，然后把地址和同一个令牌交给 MCP 客户端：LAYERLING_URL=http://nas:3000 和 LAYERLING_MCP_TOKEN=<the token>。

只有持有令牌的客户端才能列出或驱动编辑器。编辑器页面不需要令牌，但只有在仅限你所在网络使用的地址或名称下才计入（IP 地址、不含点的名称，或以 .local 或 .lan 结尾的名称）；反向代理后面的真实域名要写入 LAYERLING_MCP_ALLOWED_HOSTS。请仅在可信网络中使用，跨网络时使用 HTTPS。详情见 README。

示例

你说：“给我做一个直径 60 mm、高 40 mm、壁厚 2.5 mm、顶部开口的圆盒，再加一个平的盖子，上面用弧形排列写出‘Tea’。”AI 会创建圆柱体、把其中一个抽壳、把弯曲的文字放到盖子上，最后拍几张照片看看是否合适。

提示： 给 AI 具体的尺寸，并告诉它零件的用途（“用于 12 mm 圆杆的支架，适配 Bambu Lab A1”）。这样它做出的决定更合理。还要看着它搭建：你随时可以接手，因为用的是同一个编辑器。

15. 安装为应用、离线使用与自托管

像普通程序一样启动 PrintCAD，即使没有网络也可以，以及在自家电脑上运行它的方法。

安装为应用

PrintCAD 可以像普通程序一样安装。安装后它会有自己的图标和窗口，没有地址栏。首次访问之后，即使没有网络也能启动。你的设计保存在自己的电脑上。值得安装：应用启动更快，因为不必每次都重新加载；它无需联网即可使用，还能减轻服务器负担。你不会有任何损失，PrintCAD 仍会在有新版本时通知你。 这也能保护你的设计：Mac、iPhone 和 iPad 上的 Safari 会清除七天未访问的网站所存储的数据，但不会清除已安装应用的数据。

如果你的浏览器支持，起始页上会出现带 “立即安装” 的提示。否则：

  • Chrome 和 Edge： 点击地址栏右侧的安装图标，或在浏览器菜单中选择“安装为应用”。
  • Mac 上的 Safari： “文件”菜单 →“添加到程序坞”。
  • iPhone 和 iPad 上的 Safari： 分享图标 →“添加到主屏幕”。
  • Firefox： 无法安装应用。PrintCAD 仍可在其标签页中离线启动。

起始页上的提示可用 “隐藏此提示” 关闭。在 Chrome 或 Edge 中再次启动已安装的应用时，会把已打开的窗口带到前台，而不是再开一个。

在电脑上，Chrome 或 Edge 中安装的 PrintCAD 还会注册为 .lyl 文件的程序：在文件管理器中双击设计，即可在 PrintCAD 中打开，Ctrl+S 会保存回该文件。在 Android 上这行不通，那里的浏览器不为已安装的 Web 应用提供文件关联；请在起始页用 “打开设计或导入几何体” 打开设计。

更新

当有新版本时，PrintCAD 会在起始页显示。通过 “发行说明与下载” 可以查看变更内容。版本号位于右下角。重新加载页面后便使用新版本。

在 the public site 和其他 Web 服务器上，已打开的页面会自行发现更新。它会不时向服务器询问版本，当你回到该标签页时也会询问；如果它需要的某个程序文件消失了，则立即询问。若期间安装了新内容，右下角的卡片会提示并列出新内容。“保存并重新加载” 会先把当前打开的设计写入浏览器，然后重新加载页面；设计会按你离开时的样子恢复。“稍后” 会让卡片推迟 15 分钟。请尽快重新加载：停留在旧版本的页面可能加载新版本中不匹配的部分。这种情况已经发生时也会出现同一张卡片：CAD 工作进程只在首次需要时加载，它们会说明自己来自哪个构建；如果不是页面自身的构建——更新之后，或使用了旧版本的存储副本——卡片会要求重新加载，以免两者互相误解。

PrintCAD 在多个标签页中打开时，它们会互相照应：如果另一个标签页已在运行较新版本，旧标签页底部会出现提示，请你重新加载它。如果同一个设计在两个标签页中打开，两者都会警告，因为它们会自动保存并相互覆盖。如果已有一个标签页打开，你又在另一个标签页中打开 PrintCAD，新标签页会建议在旧标签页中继续，并主动提出关闭自己。如果你确实想要两个标签页，比如并排查看两个设计，请在那里点击 “在此继续工作”。本指南也会在单独的标签页中打开：当 PrintCAD 在旁边打开时，其右上角的按钮显示为“返回编辑器”，点击会关闭指南，而不是再开一个编辑器。

语言与外观

在右上角从语言列表中选择语言。旁边的配色方案提供 “系统”（跟随操作系统）、“浅色”、“深色” 和 “石墨黑”，一种中性的深灰色。

自行运行

PrintCAD 是自由软件（AGPL-3.0），可以运行在你自己的电脑或服务器上，例如工坊、俱乐部或学校。有几种方式，见 GitHub 上的 README：

  • Windows 快速开始： 在 PowerShell 中输入一行命令即可安装全部内容，并在桌面放置快捷方式。当 PrintCAD 已在运行时，再次双击不会启动第二个服务器，只会打开页面。
  • Docker： 适用于 NAS 设备和家用服务器，无需安装 Node.js。每个版本都提供现成镜像 henmedia/layerling（Docker Hub，也在 ghcr.io/henmedia/layerling），支持 amd64 和 arm64；docker run -d -p 3000:3000 -v layerling-thumbnails:/app/.codex/project-thumbnails henmedia/layerling:latest 可启动它，在 NAS 上可在容器管理器的镜像仓库中搜索。卷 layerling-thumbnails 能让起始页的预览图在更新后保留；没有它，每次重新创建容器后预览图都会缺失，直到你打开相应设计。
  • 静态导出： 结果是普通文件，任何 Web 服务器都能提供。它们应位于地址根目录（https://layerling.example.com/ 或 http://192.168.0.5:8080/），不能放在子文件夹中，也不能从磁盘直接打开；具体步骤见 README。如果 index.html 旁边有可写文件夹 store，并且服务器装有 PHP，它还会成为设计的共享存储。

用于 AI 助手的 MCP 桥接只存在于开发服务器中，见用 AI 构建。

17. 平板与触控

用手指或触控笔操作：选择多个实体、转动与缩放视图、长按菜单，以及在 iPad 上需要知道的事项。

手指与触控笔

PrintCAD 可在平板的浏览器中运行，也可从主屏幕作为应用运行。手指的作用相当于鼠标左键。平板没有的三样东西——鼠标右键、Shift 键和滚轮——各有自己的替代方式：

你想要在平板上
选择一个实体点击它。
选择多个实体手指按住不动半秒，选择 “多选”，然后逐个点击实体。再次点击已选中的实体会将其取消。
全选实体在空白处按住手指不动半秒，选择 “全选”。
打开右键菜单在实体上或空白处按住手指不动半秒。
移动实体拖动它。
调整实体大小、旋转或抬高拖动它的控制柄，即周围的小方块和箭头。手指在稍偏一点的位置也能抓住它们。
转动视图在空白处用一根手指，或拖动视图立方体。
缩放视图两根手指：张开靠近，捏合远离。
移动视图两根手指并拢滑动。
清除选择点击空白处。但在 “用单指旋转视图” 开启时不行，那时单指用于转动视图；而在 “多选” 中，第一次点击空白处只会结束该模式并保持选择不变，下一次点击才会清除。

选择多个实体

没有 Shift 键时，长按菜单中的 “多选” 起到电脑上 Shift+点击的作用。开启期间会有提示说明，每次点击实体会将其加入选择或从中移除。点击空白处，或在键盘上按 Esc，会结束该模式并保持选择不变。与此同时，手指在空白处仍可转动视图。随后 “分组”、“对齐” 或移动操作会作用于你选中的所有实体。

同一菜单中还有 “放置在面上”，即触屏上的 C 键。选中项随后会跟随手指越过其他实体的各个面；点击一下即可将其放到你点击的那个面上，斜面也可以，而且第一次点击就足够。也可以搜索“set down”或“cruise”找到该菜单项（命令搜索，键盘上为 Ctrl+K）。

转动与缩放视图

在空白处用一根手指转动视图，两根手指缩放并移动视图。从实体上开始的手指操作的是实体，而不是视图。如果你更希望它转动视图，请在相机栏中开启 “用单指旋转视图”：此后无论从何处开始，单指都会转动视图而不是选择。该开关仅在带触摸屏的设备上显示。

左上角的视图立方体在拖动时会转动视图，点击它的某个侧面、角或边会跳到该视图。参见视图与工作平面。

控制柄、小点与触控笔

指尖会遮住它所瞄准的东西。PrintCAD 允许手指比鼠标指针伸得更远一点去够控制柄、点、线和边，但触控笔更精细。这适用于平板识别为笔的笔，例如 Apple Pencil 或 S Pen。带橡胶笔尖的普通触控笔会被屏幕当作手指，并不比手指更精细，所以只能像手指一样使用。在 iPad 上悬停于屏幕上方的 Apple Pencil 稍后还会在一个小气泡中显示控件的名称，就像鼠标指针的提示框那样。

如果实体在儿童或匆忙的手触碰时会被挪动，请在设置中开启 “先选中再移动”：这样必须先选中实体，只有下一次拖动才会移动它。

在 iPad 或 iPhone 上

  • 将其安装为应用。 在 Safari 中点击分享图标，选择“添加到主屏幕”。应用会在自己的窗口中打开，没有地址栏，并且无需连接即可使用，参见离线与安装。
  • 你的设计保存在浏览器中。 没有账户，也不会上传任何内容。Safari 有一条自己的防跟踪规则：如果七天内在 Safari 中没有访问过某个网站，它会删除该网站存储的内容。添加到主屏幕的 Web 应用不受该规则限制，WebKit 的文档如此说明。这也是更充分的理由去使用主屏幕上的应用，并备份重要作品：起始页上的 “全部备份” 会把所有设计打包成一个文件。
  • 文件。 Safari 只允许页面通过下载来写入文件，所以 “导出” 会把文件放进“文件”应用的“下载”中，键盘上的 Ctrl+S 会再次下载它；参见文件与保存。
  • 无需键盘。 每个工具在功能区中都有按钮，数字输入框会调出屏幕键盘。iPad 上的键盘还会带来键盘快捷键。 实体旁的数值框要点第二下才会打开数字输入框：第一下只是标记它，所以手指误触到它也不会弹出键盘。

带儿童的课堂

手指与橡胶笔尖的触控笔在这里用法相同。有两项设置能让课堂更轻松：“先选中再移动” 让触摸不会意外移动实体，“用单指旋转视图” 让单指始终转动视图。功能区“帮助”组中的问号按钮会开启 “交互式帮助”：此时点击任何按钮、输入框或控制柄都会给出说明，再次点击该按钮或按 Esc 即可退出。

要让整个班级使用，请在设置中开启 “简易模式”。功能区随后只保留课堂上用到的工具（复制、粘贴、复制副本、删除、撤销、分组、镜像、倒角、圆角、抽壳、对齐、导出），形状库只保留一个短列表，按钮更大，起始页只显示设计，别无其他：没有新闻、没有欢迎文字、没有帮助按钮，也没有指向 PrintCAD 之外的链接。开启只需点击一下；关闭则要按住随后取代它的那个按钮两秒钟。以 ?mode=simple 结尾的链接会为打开它的设备开启该模式，?mode=full 会再次关闭。在服务器上运行 PrintCAD 的人可以用 LAYERLING_SIMPLE_MODE=true 让所有人一开始就处于该模式，或用 always 为所有人固定下来，这样程序就没有退出的开关；参见 README。
